## P1 — (원 목록 보존용) 1차 감사 시점의 남은 최우선 — ✅전부 위에서 처리됨

### 1. 생성 상태 되돌림: `set_status()` 무가드 덮어쓰기
`repo/generations.py:211` — done 보호(CAS)가 없어, 늦은 reconcile 이 완료 카드를 running 으로
되돌린다(사용자 재생성→이중 과금 위험). 호출부 4곳(`usecases/gen_requests.py:179,226,464,522`)
전부 done 보호 없음. 빈 바디 `POST /reconcile` 만으로 재현 가능.
→ 수정: `WHERE status <> 'done'` 가드(형제 함수들과 동일 규약).

### 2. 앵커 유실: `/anchor` 가 미적용도 200 → 에이전트 outbox 삭제
`routers/gen_requests.py:299`(반환값 폐기) + `agent_push.py:1146`(200=성공 간주).
거부된 앵커의 재전송 기회가 사라지고 generation.job_id 영구 NULL → reconcile 전부 rejected,
에이전트 무한 폴링. `force_fail` 도 미적용을 성공형 outcome 으로 보고(`usecases:406-413`).
→ 수정: applied 여부를 응답에 실어 에이전트가 재시도 판단(서버 먼저 배포).

### 3. 무음 발행 유실: fact_blocked 발행을 로컬은 "공유됨"으로 확정
`repo/share.py:394-450`(share INSERT 가 `not fact_blocked` 안) + `routers/publish.py:390-398`
(서버 per-item 결과 무시). uid 미바인딩 상태의 재발행이 조용히 사라짐 — 로컬 뱃지 O/팀 X.
→ 수정: 서버가 blocked 를 구분 반환, 클라이언트는 반영된 것만 마킹+사용자 고지.

### 4. Comfy 업로드 파일명 충돌 → 타 잡 입력 혼입
`services/comfy_client.py:181-201` + `routers/comfy.py:452-514` — `image1.png` 식 이름을
`overwrite=true` 로 올려 병렬 배치에서 잡 A 가 잡 B 의 이미지로 실행됨(무오류 오답).
→ 수정: 업로드 이름에 잡 uuid 접두(노드 주입 문자열 동기 변경).

### 5. Resolve Z:↔UNC 불일치 → 중복 가져오기+거짓 실패
`services/resolve_bridge.py:440-527` + `MVHub_Importer.py:308-318` — 매핑 드라이브 정규화
부재로 성공한 가져오기가 실패로 보고되고 재시도마다 Media Pool 중복.
→ 수정: `_normal_path` 에 드라이브→UNC 정규화(win32 WNetGetConnection 또는 net use 파싱).

### 6. DB 복원 제자리 교체 (라이브 파일 덮어쓰기)
`routers/db_transfer.py:123-153` — `-wal` unlink 실패 가능(Windows), `flush_pool()` 이 교체
**후**라 진행 중 요청이 복원본을 오염 가능. 복원 테스트 0건.
코덱스 합의 방향: 유지보수 게이트(새 요청 차단→활성 작업 종료 대기→전 풀 close→교체→재개)
+ 전역 커넥션 레지스트리(holder WeakSet). 테스트 플레이크의 운영측 반쪽이기도 함.

### 7. 이벤트 루프 블로킹 SQLite
`main.py:449-459`(auth 미들웨어)·`:772,809`(WS 재인증)·`routers/gen_requests.py` 전 핸들러
(async def 안 동기 repo 호출). busy_timeout 5초에 걸리면 서버 전체 정지 → 워치독 연쇄.
→ 수정: `asyncio.to_thread` 이관 또는 계정 캐시(45초 TTL), gen_requests 는 `def` 전환 검토.

### 8. 부팅 중 포트 LISTEN → 워치독이 부팅 중 서버 kill
`serve.py:74-77`(bind 먼저) + 매 부팅 generation 전체 UPDATE 마이그레이션(`db_migrations.py:218-236,455-476`).
DB 커지면 부팅 10분+ → kill → 재부팅 루프.
→ 수정: 마이그레이션 완료 후 listen(soft), 백필 마이그레이션에 완료 표식(1회만), watchdog
startup-grace 상향. (이번 busy/dead 분리로 '응답 없는 부팅'은 여전히 dead 로 셈 — 주의)

### 9. facets 가 worker 전체(이메일 포함) 무필터 노출
`repo/facets.py:57-62` + `routers/library.py:638-654` — members 마스킹 통제 우회.
→ 수정: 표시이름만 반환(이메일 폴백 제거)하거나 members 와 같은 마스킹 적용.
