## 최신 전체 검증 1회분

**10-03 커밋된 `dev`(`672bc001` — 그 뒤 `020f59f4` 는 기록 문서만)에서 사전 게이트를 통과했다**(`-AllowDirty`, 백업 연습은 사본).

  60초 × 2(작업 p95 70/73ms · SQLite locked 0). 100명 동시 로그인 p95 8.0초(기준 10초 — 비밀번호 확인을 코어 수만큼만 동시에 도는 설계).
- 격리 실측(data_test 사본·CLI 차단): 화면 한 바퀴 41단계 · 생성 요청 0 · 새로고침 첫 카드 463→417ms · 가만히 둔 앱 CPU 0.05%.

**검증 한계 — 이 게이트가 보장하지 않는 것.**

- 부하는 목록·집계·상세·미디어·색 저장 중심이다. **Comfy·공유 변경·Resolve·백업/업데이트·제출의 동시 부하는 포함하지 않는다.**
- **유료 생성 · 실제 Resolve · 실제 NAS 지연 · 운영 적용 · 장시간 운용과 RTO는 미검증이다.** 10-03 의 NAS 지연 수정은 지연 주입 시험으로만 확인했다.

## 지금 상태

- **개발 기준선은 안정적이다**(10-03 게이트 기준). 잘못된 데이터 표시·오귀속으로 분류한 미해결 P0 는 없다.
  10-03 점검이 찾은 저장값 결함(관리 편집·소수 칸·메모)은 dev 에서 고쳤고 **배포판에는 아직 남아 있다**.
- **Resolve 전송 = 직접 전송이 현행이다.** 서버 영구 큐 없이 요청 한 건 안에서 준비·반입·결과 저장을
  끝낸다(2026-08-25 `aa0985b9`). 큐 v3 는 이력이며 **현재 확인된 재도입 계획은 없다.**
  전송 파일명은 `<폴더경로>_<번호 2자리>`, 번호는 "그 폴더에 남아 있는 마지막 번호 + 1" 하나가 전부다
  (2026-09-02 Jay 규칙 확정). 스틸 이미지는 **한 경로씩** 반입한다(여러 장을 한 번에 넘기면 Resolve 가
  이미지 시퀀스로 묶는다 — 실측). 큐 제거·잔존 모듈·수동 복구 제거·시간제한 없는 반입의 한계는
  [ARCHITECTURE §7.6 — 현행 구조·알려진 한계](ARCHITECTURE.md) 에 보존돼 있다.
- **미해결 — 백로그 잔여 1건.** 휴지통 교차-WAL 전원손실(구조 재설계급, **보류 확정**). 나머지는
  실측으로 종결하거나 처리했다.
- **미해결 — 부분 해결 위험은 RL-23 하나다.** 실제 다른 물리 장치 복원 훈련 전에는 완료로 올리지 않는다.
- **미해결 — 크레딧 추적 잔여 3건.** 2026-09-12 에 소수 보존·공간별 수집·애매한 매칭 보류를
  넣었지만 다음 셋은 **미실시**다.
  ①**과금 당시 공간 스냅샷** — 현재 귀속 공간(`generation.workspace_id`)은 `##` 명령으로 보정할 수
  있어 그 자체가 과금 증거가 아니다. 다만 [워크스페이스 계약](WORKSPACE_DATA_CONTRACT.md) 의
  `gen_request.payload.workspace` 는 요청 당시 값을 보존하므로 **복원 가능 범위는 미확인**이다.
  ②**과거에 정수로 저장된 크레딧 되살리기** — 재매칭이
  [`manage_transactions.py`](../backend/app/repo/manage_transactions.py) 의 `m.real_credits IS NULL`
  만 보므로 **자동으로 안 고쳐진다**. 개발 DB 에서 과거 정수값 오차를 관측했고 **팀 전체 영향은
  미확인**이다(측정 시점·질의·분모는 기록 노트의 09-18 절).
  ③**그룹 한도에 환불 되돌리기** — 공간을 옮긴 생성물 때문에 엉뚱한 공간에 돌아갈 수 있고 힉스필드
  실제 규칙이 미확인이다.
  **담당 미배정 · 다음: 복원 가능 범위와 힉스필드 외부 규칙을 확인한 뒤 담당·우선순위를 정한다.**
  근거는 [status/최근작업_2026-09-18.md](status/최근작업_2026-09-18.md).
- **미해결 한계 — Gate 6 통합 검증이 남아 있다.** 실제 유료 Comfy Cloud 작업, NAS 물리 복원, 운영
  업데이트·자동 재시작을 한 번에 잇는 검증을 하지 않았다. 따라서 **운영 배포 완료를 선언한 상태가 아니다.**
