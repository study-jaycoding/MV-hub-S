## 방금 완료한 작업

- **RL-06 — 캔버스 생성 재시도 멱등성**

  같은 캔버스 생성 시도를 먼저 `preparing` 상태로 예약하고 placeholder와 명령 내용이 준비된 뒤에만
  에이전트가 가져갈 수 있는 `pending`으로 바꾼다. 동시에 두 번 눌러도 생성·요청·신호는 한 번만
  만들어지고, 저장 중 종료되면 직접 재시도나 서버 재시작 복구가 같은 생성 ID를 이어간다.
  상세 계약은 [CANVAS_GENERATION_IDEMPOTENCY.md](CANVAS_GENERATION_IDEMPOTENCY.md)를 따른다.

  대상 기능과 전체 회귀를 모두 통과해 위험 표에서 ✅로 닫았다.

- **RL-25 — Windows 업데이트 bootstrap 자립성**

  `Get-FileHash` 자동 로딩이 빈 임시 폴더에서 실패하던 의존성을 제거하고 Windows PowerShell이
  기본 제공하는 .NET SHA-256으로 바꿨다. 공백이 있는 경로, 작업 중 스크립트 교체, 새 작업자로
  한 번만 재시도, 실패 코드 전달, 임시파일 회수까지 실제 cmd/PowerShell 프로세스로 확인했다.

## 운영 배포 전 남은 확인

- 실제 Higgsfield 생성 1건의 제출 → 직접 상태 조회 → 결과 URL → 서버 자산 저장 전체 왕복
- 공유 서버에서 서로 다른 두 계정의 publish → 조회 → unpublish 왕복
- 실제 Comfy 실행과 Resolve 가져오기·내보내기
- NAS 백업 복제와 content·trash·manage DB 세트 복원
- 운영 설치본의 업데이트 → 자동 재시작 → ready → 로그인 → 주요 화면 확인
