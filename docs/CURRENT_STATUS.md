## 방금 완료한 작업

- **RL-05 — 생성 제출 중단 복구**

  유료 CLI 호출 전 `claimed`와 호출 후 `submitting`을 구분한다. 제출 여부가 불명확하면
  `recovery_required`로 격리하고, 일반 재생성 API·버튼·lease 만료·서버 재시작으로 자동 재실행되지
  않게 했다. 기존 외부 작업을 찾으면 같은 `job_id`로 추적하고, 사람이 미제출을 확인한 경우에만
  기존 요청을 다시 대기열에 넣는다. 상세 계약과 검증 근거는
  [GENERATION_SUBMISSION_RECOVERY.md](GENERATION_SUBMISSION_RECOVERY.md)를 따른다.

## 운영 배포 전 남은 확인

- 실제 Higgsfield 생성 1건의 제출 → 직접 상태 조회 → 결과 URL → 서버 자산 저장 전체 왕복
- 공유 서버에서 서로 다른 두 계정의 publish → 조회 → unpublish 왕복
- 실제 Comfy 실행과 Resolve 가져오기·내보내기
- NAS 백업 복제와 content·trash·manage DB 세트 복원
- 운영 설치본의 업데이트 → 자동 재시작 → ready → 로그인 → 주요 화면 확인
