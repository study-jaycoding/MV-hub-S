# Content Hub 사용 설명서

Higgsfield CLI로 만든 영상·이미지 생성물을 **한 곳에 모아 보고, 정리하고, 팀과 공유**하는
로컬 우선 도구입니다. 이 저장소(`MV-hub-S`)를 서버 PC 한 대에서 돌리면 팀원들이 브라우저로
접속해 함께 쓰고, 각자 PC 에서는 릴리스 설치본의 `MV_agent.bat` 으로 로컬 허브+에이전트를 켭니다.

---

## 1. 빠른 시작

서버 PC에서:

```
.\MV_server.bat
```

이 한 줄이 백엔드를 띄웁니다. 프론트엔드 빌드(`dist`)가 이미 있으면 설치·빌드를 건너뛰고,
없을 때만 처음 한 번 의존성 설치로 몇 분 걸립니다.

> ⚠️ 부팅 자동시작(`register_autostart.bat`)을 등록한 서버에서는 `MV_server.bat` 을 **수동으로
> 실행하지 마세요**(포트 충돌). 상태 확인·로그는 `MV_logs.bat`, 상세는
> [SERVER_RECOVERY.md](SERVER_RECOVERY.md).

접속:
- **같은 PC**: http://127.0.0.1:8010 (`localhost` 는 IPv6 폴백으로 느릴 수 있음)
- **같은 네트워크(팀원)**: `http://<서버 PC의 IP>:8010`
  - IP는 서버 PC에서 `ipconfig` → IPv4 주소로 확인

> 필요 조건: Python(`pip install -r backend/requirements.txt`), Node.js, 그리고 본인 PC에
> 로그인된 Higgsfield CLI(생성·동기화는 본인 계정으로 동작).

## 1-b. 작업자 PC 처음 설정 (온보딩 체크리스트)

새 팀원 PC 는 이 순서대로 한 번만 설정하면 됩니다:

1. **릴리스 설치**: 서버 담당자가 준 `MVHub_Install.bat` 실행 (설치 폴더가 만들어짐)
2. **Higgsfield CLI 로그인**: 터미널에서 `higgsfield auth login` (본인 계정 — 생성 크레딧의 주인)
3. **허브 계정 가입**: 브라우저로 `http://<서버IP>:8010` 접속 → 회원가입 → 관리자 승인 대기
4. **에이전트 시작**: 승인 후 설치 폴더의 **`MV_agent.bat`** 더블클릭
   - 브라우저가 열리면 팀 서버 로그인 → 이후엔 자동
   - 이 창을 닫으면 생성·push 가 멈춥니다(탐색·정리는 브라우저만으로 가능)
5. **확인**: 하단 프롬프트에 한 줄 적고 **`Alt+Enter`** (그냥 Enter 는 줄바꿈입니다) → 카드 상태가 **생성중 → 완료**로 진행(대기·실행 단계는 카드 툴팁과 정보창에서 구분)되면 성공

> 이후 업데이트는 **설정(⚙) → 프로그램 업데이트** 버튼 하나입니다.

## 2. 기본 화면

```
┌──────────────────────────────────────────────────┐
│ ⬡ MV Hub  작업 공간 공유 & 리뷰 캔버스  검색 ⬚Assets ▦ 🔔 👤 │ ← 상단바
├────────────┬─────────────────────────────────────┤
│ 프로젝트    │                                      │
│ 컬러        │        결과물 썸네일 그리드           │  ← 라이브러리
│ 전역태그    │                                      │
│ 생성자      │                                      │
│            │  │ 프롬프트 입력 (하단 도크)        │ │
└────────────┴──┴────────────────────────────────┴─┘
```

- **상단바**: 좌측 로고(⬡ MV Hub) → 탭 → 검색 → **Assets 버튼**(파일 브라우저 분리창) →
  **보드 아이콘**(PM 관리창) → **알림 벨** → 이니셜 아바타(계정 메뉴 — 워크스페이스·크레딧 게이지·설정·업데이트)
  - **작업 공간**: 내가 만든 결과물 라이브러리 · **공유 & 리뷰**: 팀이 공유한 것
  - **캔버스**: 결과물을 자유 배치하는 **씬 캔버스**(카드·연결·태그, 로컬 저장 + 자동 DB 백업)
    와, 원본→파생을 트리로 보는 **히스토리 보기**가 함께 있는 탭
- **좌측 사이드바**: 프로젝트 · 컬러 · **전역 태그** · **생성자** 필터
  (공유 여부 필터는 사이드바가 아니라 **상단 툴바의 S 버튼**)
- **가운데**: 결과물 그리드 (**클릭 = 선택 · 더블클릭 = 미리보기**, 휠클릭 = 정보 팝업.
  리스트 보기에서는 클릭 = 미리보기)
- **하단 도크**: 프롬프트 입력 → 생성

### 자주 쓰는 동작
- **생성**: 하단 프롬프트에 입력 + 모델 선택 → 생성. `Ctrl/⌘+K`로 프롬프트 입력바 표시/숨김(표시될 때 자동 포커스)
- **다중 선택**: 카드 클릭으로 선택(여러 개) → 하단에 선택 바 등장
- **컬러/태그 분류**: 선택 후 단축키 `r`·`g`·`b`(컬러), `#`(태그), `c`(코멘트), `h`(히스토리).
  (`s` 소스 등록은 **Assets 분리창에서만** 동작하고 생성 라이브러리에서는 비활성)
- **정보 보기**: 카드 휠(중간) 클릭 → 프롬프트·소스·크레딧·**소속 프로젝트** 팝업

## 3. 프로젝트 (작업 묶음)

여러 작업이 섞이지 않게 결과물을 **프로젝트 단위로 묶는** 기능입니다. (개인 태그·컬러와 다른,
팀 공통의 분류입니다.)

| 하고 싶은 것 | 방법 |
|---|---|
| 프로젝트 만들기 | **보드 아이콘 → 관리창 → 대시보드**의 프로젝트 관리 패널 |
| 그 프로젝트만 보기 | 사이드바에서 프로젝트 이름 클릭 (다시 클릭 = 해제) |
| 미분류만 보기 | **미분류** 항목 클릭 |
| 결과물 담기 | 카드 여러 개 선택 → 하단 **📁 프로젝트에 담기** → 프로젝트 선택 |
| 생성과 동시에 담기 | **특정 프로젝트로 필터한 상태에서 생성** → 자동으로 그 프로젝트에 들어감 |
| 한 개만 옮기기 | 카드 선택 → **📁 담기** 메뉴(정보 팝업은 소속 표시 전용) |
| 이름변경·보관·삭제 | **관리창 → 대시보드**의 프로젝트 관리 패널 |

> 프로젝트를 삭제해도 **결과물은 지워지지 않고 '미분류'로 돌아갑니다.**
> 재생성한 결과물은 원본과 같은 프로젝트에 자동으로 들어갑니다.

## 3-b. 일상 작업 흐름 (권장 루틴)

```
생성 ──▶ 정리 ──▶ 공유 ──▶ 검수(골드) ──▶ 완료본 저장 ──▶ 편집(Resolve)
```

1. **생성**: 프로젝트로 필터한 상태에서 프롬프트 입력(자동 귀속). `@`=소스 피커, `#`=태그 피커.
   여러 번 돌릴 땐 캔버스에서 카드로 배치해 배리에이션 관리.
2. **정리**: 좋은 것에 `g`(초록), 버릴 것 `r`(빨강). 태그는 `#`.
3. **공유**: 고른 것 선택 → **↗ 팀에 공유**. 공유 & 리뷰 탭에서 팀이 코멘트(C 뱃지).
   등급 조정은 공유 & 리뷰 탭 선택바의 **↓/↑** (일반 ↔ 공유 ↔ 최종).
4. **검수**: 그 프로젝트의 **Supervisor**(또는 전역 `admin`)가 **골드(최종)** 지정 — 카드 S 더블클릭.
   프로젝트 관리자(PM)는 최종 지정 권한이 없다.
5. **완료본 저장**: 관리창(보드 아이콘) → 완료 탭 → 최종본 원본을 렌더 폴더에 저장.
6. **편집**: 선택 → **◆ Resolve로 보내기** → DaVinci Resolve Media Pool 의 `MV Hub` 빈에서 편집.

## 4. 멤버 등급 · 관리자 창

좌측 상단 **"⬡ MV Hub" 로고를 클릭**하면 관리자 창이 열립니다.

- **멤버 · 전역 역할**: 생성물 작성자(멤버) 목록과 역할
  - 전역 역할: `admin` / `product_manager` / `production_director` / `member`
  - 프로젝트 역할: `project_manager` / `supervisor` / `creator`
  - 역할은 **역할 칩을 눌러** 켜고 끕니다(드롭다운 아님)
  - 관리자 창에서는 **전역 역할만** 줍니다. 프로젝트 역할은 **관리창 → 대시보드 →
    프로젝트 관리 패널의 👥** 에서 부여합니다.
- (프로젝트 생성·이름변경·보관·삭제는 관리자 창이 아니라 **관리창 → 대시보드**의 프로젝트 관리 패널)
- **승인**(아래 보안 모드일 때만): 가입 대기 계정 **승인 / 거부**, 등급 부여
- **공유 서버**(관리자만): 서버 이름·주소 저장 → **[팀에 공지]**(서버 이사 안내 발송), 업데이트 공지 등록·재공지.
  절차는 [SERVER_RELOCATION.md](SERVER_RELOCATION.md)·[UPDATE_ANNOUNCEMENTS.md](UPDATE_ANNOUNCEMENTS.md).

## 5. 팀 서버 — 로그인 보안

**`MV_server.bat` 은 로그인 모드를 기본으로 켭니다**(CONTENT_HUB_AUTH 미지정 시 1).
끄고 싶을 때만(개인 PC 단독 테스트 등) 명시적으로 끕니다:
```powershell
$env:CONTENT_HUB_AUTH = '0'
.\MV_server.bat
```

cmd 라면:

```
set CONTENT_HUB_AUTH=0
.\MV_server.bat
```

로그인 모드에서는:
1. **첫 가입자 = 관리자**가 됩니다(서버를 처음 띄운 사람이 회원가입).
2. 이후 가입자는 **승인 대기** 상태 → 관리자가 관리자 창에서 **승인**해야 로그인 가능.
3. 로그인하지 않으면 아무것도 못 봅니다(결과물·미디어·실시간 갱신 전부 차단).
4. 우측 상단 계정 칩을 클릭하면 로그아웃.

> 비밀번호는 안전하게 해시 저장되고, 세션은 위조 불가한 서명 토큰을 씁니다.
> 끄려면 bat 의 `CONTENT_HUB_AUTH` 를 **`0` 으로** 바꿔 실행합니다(변수를 빼면 기본이 `1` 이라 켜집니다).
> 데이터는 그대로입니다.

## 6. 공유 & 리뷰

- **번들 내보내기 / 가져오기**: 팀 공유를 발행으로 하게 되면서 불필요해 **제거**됐습니다.
  사용자가 쓸 수 있는 번들 내보내기·가져오기 화면이나 API 는 없습니다.
- **동기화 경로는 둘**: ①각자 PC 의 에이전트(`MV_agent.bat`)가 내 결과물을 **내 허브(로컬)** 에
  넣습니다(즉시). 팀에게 보이는 것은 **내가 발행한 것만**입니다.
  ②서버 자체의 주기 동기화 — `MV_server.bat` 으로 띄우면 **기본 꺼짐**(`CONTENT_HUB_SERVER_SYNC=0`). 켜면 20초 간격으로 Higgsfield 잡(다른 기기·웹 포함)을 흡수
- **코멘트**: 공유된 결과물에 누구나 의견을 남길 수 있습니다(C 뱃지 = 안 읽은 코멘트)

## 7. 데이터 · 백업

- 서버 PC 의 데이터는 `backend/data/`에 모입니다(DB·미디어·공유).
  각자 PC 의 로컬 허브도 자기 `backend/data/`(계정별 DB 포함)를 따로 가집니다.
- **DB는 자동 백업**됩니다(하루 1회 + 서버 시작 시. 다만 **직전 백업이 1시간이 채 안 됐으면 시작 백업은
  건너뜁니다** — 재기동이 잦아도 백업이 쌓이지 않게. 기본 설정 기준이며, 백업 주기를 1시간보다
  짧게 바꾸면 그 주기가 기준이 됩니다. 최근 7개 보관). 수동 백업은 관리자가
  `POST /api/backup`으로도 가능.
- 백업은 가능하면 다른 디스크/NAS로: `set CONTENT_HUB_BACKUP_DIR=\\NAS\backup`

## 8. 더 있는 기능들

자세한 사용법은 [기능설명서.md](기능설명서.md) §14 를 보세요. 요약:

- **프로그램 업데이트**(작업자 PC): 설정 → 프로그램 업데이트 버튼 한 번으로 안전 종료→교체→재시작
- **DaVinci Resolve 연동**: 선택 결과물을 렌더 폴더로 저장하고 Resolve Media Pool 로 가져오기
- **ComfyUI 연동**(캔버스): 워크플로 JSON 을 카드로 불러와 파라미터 노출·실행
- **PM 관리창**(상단바 보드 아이콘): 작업 칸반·일정·완료본 저장·팀 크레딧 대시보드
- **Assets 분리창**: 내 PC 폴더를 마운트해 파일 브라우징 + 개인 메타(소스·태그·컬러)

## 8-b. 문제 해결 (증상별)

| 증상 | 원인·해결 |
|---|---|
| 생성 버튼을 눌렀는데 **생성중**에서 안 움직임 | 내 PC 의 `MV_agent.bat` 이 꺼져 있음 → 켜면 즉시 실행됨 |
| 생성이 "생성중"에서 오래 멈춤 | 에이전트 창의 로그 확인. Higgsfield 쪽 지연이면 자동 재확인이 돌고 있으니 대기 — 완료를 실패로 뒤집지 않게 설계돼 있음 |
| 목록이 비고 "불러오지 못했습니다"가 뜸 | 서버 순단 — **다시 시도** 버튼. 반복되면 서버 PC 상태 확인(`MV_logs.bat`) |
| 팀에 공유했는데 팀원이 못 봄 | 공유 결과 메시지 확인 — "N건은 서버가 반영하지 않았습니다"가 떴다면 작성자가 다른 항목의 재공유(원 작성자만 발행 가능) |
| 워크스페이스가 프로젝트와 다르다는 오류 | 계정 메뉴에서 그 프로젝트의 워크스페이스로 전환 후 생성(잘못된 크레딧 과금 방지 게이트) |
| 프로젝트 드롭다운에 같은 이름이 2개 | 등록부 유령 행 — 서버에서 `.\run_py.bat tools\cleanup_workspace_registry.py` 미리보기 후 `--apply` |
| 업데이트 버튼이 "생성 N건 · Resolve 전송 N건 완료 후"로 잠김 | 진행 중 유료 작업·Resolve 전송 보호 — 끝나면 자동 해제 |
| Resolve 로 보냈는데 Media Pool 에 없음 | Resolve 안 **Workspace → Scripts → MVHub_Importer** 실행(무료판 수동 가져오기). 이미 가져온 파일은 중복되지 않음 |
| 화면이 10초쯤 하얗다가 로그인 화면 | 서버 응답 지연 — 자동 폴백. 서버가 정상 복귀하면 재로그인 |
| 서버 PC 재부팅 후 접속 안 됨 | 자동시작 등록돼 있으면 1~2분 대기(자동 복구). 안 되면 `MV_logs.bat`·`logs/watchdog_ALERT.txt` 확인 |

## 9. 자주 묻는 것

**Q. 팀원이 자기 PC에 설치해야 하나요?**
브라우저 접속만으로 탐색·정리·공유는 됩니다. **본인 결과를 올리거나 생성을 돌리려면**
본인 PC 에 릴리스 설치본을 깔고 `MV_agent.bat` 을 켭니다(§1-b 온보딩).

**Q. 생성은 누구 계정으로 되나요?**
각자 본인 PC의 Higgsfield CLI 계정으로요. 서버는 결과를 모아 보여줄 뿐, 토큰을 갖지 않습니다.

**Q. 화면이 안 떠요 / 갱신이 안 돼요.**
서버가 켜져 있는지, 방화벽에서 포트(기본 8010)가 열렸는지 확인하세요. 백엔드는 항상 켜둡니다.

**Q. 실서버로 옮기려면?**
이 폴더를 그대로 서버에 복사 → `MV_server.bat`(또는 동등 명령). 상대경로 기반이라 무변경
작동합니다. 자세한 건 `SERVER.md` 참고.
