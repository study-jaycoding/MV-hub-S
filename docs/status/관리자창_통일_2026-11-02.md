## 구현 메모

- `.admin-window` 는 transform 이라 안쪽 `position: fixed` 창의 기준이 된다 — `overflow: hidden` 을 넣으면 프로젝트 설정 창이 잘린다(시안에서 실측). 왼쪽 메뉴의 모서리는 메뉴 칸에 직접 준다.

- 시안과 다른 점: 에셋 리스트의 상태는 별도 줄로 남겼다(시험·기존 문구를 그대로 두기 위해). 설명 문구 일부는 시안보다 길다.
- 줄인 안내는 잃지 않았다: 첫 훑기 약 30분 안내는 [지금 훑기] 말풍선, 큰 파일 수동 대기는 칸 말풍선으로 옮겼다. 자동 훑기 초당 5MB·옛 앱 안내 문구는 지웠다.
