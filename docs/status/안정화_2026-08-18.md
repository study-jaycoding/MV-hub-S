# 2026-08-18 추가 안정화

> [!NOTE]
> 현재 상태 요약은 [CURRENT_STATUS.md](../CURRENT_STATUS.md) 를 본다. 이 문서는 그날의 기록이다.
> 해당 날짜의 결과이며 새 배포를 자동 보증하지 않는다.

- **비공개 코멘트 경계:** 공유 서버의 공개 코멘트 수와 계정 로컬 비공개 코멘트 수를 정확히 합치고,
  다른 계정으로 바뀌면 이전 계정의 코멘트 캐시를 재사용하지 않는다. 비공개 코멘트는 팀 공유·발행·
  통계에서 제외된다는 실제 보존 범위로 안내 문구도 바로잡았다.
- **캔버스 생성물 제거 복구:** 카드에서 생성물을 뺀 의도를 계정별 영속 대기열에 네트워크 전부터
  기록한다. 전송 실패·오프라인·앱 재시작과 늦은 서버 조회 뒤에도 자동 백필이 제거 항목을 되살리지
  않는다.
- **원격 다운로드 상한:** 크기를 미리 알 수 없는 원격 파일이 각인 상한을 넘으면 임시 디스크 사용을
  제한한 채 각인 없이 전체 원본을 스트리밍한다. 중단·완료 뒤 upstream과 임시파일을 회수한다.
- **예상 크레딧 폴백:** 가격 갱신용 CLI가 순간 실패하더라도 검증된 이전 가격이 있으면 화면과 로그에
  502를 남기지 않고 그 값을 일시 재사용한다.
- **릴리즈 생성·종료 로그:** 빈 격리 폴더에 설치하는 릴리즈 빌드에서는 작업 PC에 설치된 선택적
  패키지의 충돌 경고를 오인하지 않게 했고, Python 3.14에서 정상 종료 뒤 `KeyboardInterrupt`
  스택이 다시 출력되는 현상을 막았다. 시작 실패와 비정상 종료 판정은 그대로 유지한다.
- **릴리즈 해시·임시폴더 자립성:** 관리된 Windows에서 `Get-FileHash`를 찾지 못해 첫 설치가
  중단되는 현상을 실제 재현했다. 설치·업데이트·빌드·릴리즈 선택의 해시를 .NET 구현으로 통일하고,
  `TEMP`가 비어 있어도 LocalAppData 임시폴더로 안전하게 이어지도록 했다.
- **외부 도구 연결 정확성:** 설정 창의 첫 Resolve 확인이 끝나기 전에 재확인을 눌러 8초 검사 프로세스가
  겹치던 경계를 막았다. Comfy는 저장하지 않은 대상·주소·키를 이전 저장값으로 검사하지 않으며 저장·
  확인 중 입력과 버튼을 잠근다. 실제 Comfy Cloud health 성공과 Resolve 미실행 8초 제한 종료를 브라우저에서
  확인했다. 연결 확인 뒤 값을 바꾸면 과거 성공 문구를 지우고, Resolve 재확인 중에는 과거 결과를 숨겨
  현재 상태처럼 오인하지 않게 했다. UNC/매핑 경로 중복 방지가 추가된 Resolve Importer는 `0.1.1`로 올려
  공용 공식 경로에 설치했다.
- **공유 변경 감사 추적:** 실제 공유 상태가 바뀐 발행·해제와 공유 서버의 번들 수신을 장기 감사 이력에
  남긴다. 같은 요청을 재시도해도 발행·해제 이력은 중복 생성하지 않으며 프롬프트·결과 URL·이메일은
  기록하지 않는다. 격리된 계정 2개로 발행 → 다른 계정 조회 → 해제 → 재조회 `0건`을 10회 반복했고,
  전체 백엔드 회귀 939개와 21개 하위 검증을 통과했다.
