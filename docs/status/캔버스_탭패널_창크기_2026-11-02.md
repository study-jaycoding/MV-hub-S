# 씬 패널 — 창을 좁혀도 안 잘리게 (2026-11-02)

owner: Claude · reviewer: (배포 후보 묶음 리뷰) · status: 구현 완료(dev 커밋 · Jay 화면 확인 남음) · touched_paths: 아래 계약 · updated: 2026-11-02

배포 후보 독립 리뷰(Codex 세션 01a19a4c)가 `2b409c4e` 의 P2 로 지적했고, 배포 검토 세션이 후보에 잇도록 작은 커밋을 부탁했다.

재현: 격리 허브·헤드리스 크롬, 탭 12개에서 오른쪽 끝 탭을 휠 클릭(보드 1384px, 패널 894~1158) → 창을 1000px 로 좁히면 보드 800px 인데 패널 왼쪽이 894 에 남아 267px 밖으로 나간다.

원인: `SceneBoard.tsx` 의 패널 자리 계산이 패널을 열 때·씬이 바뀔 때만 돌고 보드 크기 변화를 보지 않는다. `sceneIoPanelLeft` 도 탭이 보드 밖에 있으면 패널을 보드 안으로 넣지 않는다.

확인: 같은 실측에서 고친 뒤 보드 800px 에 패널 89~353 으로 보드 안에 남고, 패널 폭은 264 그대로다(이번 회차는 탭이 21개라 좁히면 탭 줄이 접혔다 — 탭이 한 줄로 밖에 남는 경우는 시험 값으로 본다).
