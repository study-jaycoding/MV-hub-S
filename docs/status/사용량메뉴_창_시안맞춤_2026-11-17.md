# 계정 메뉴 Usage 숫자·'내 사용량' 창을 고른 시안대로 (2026-11-17)

owner: Claude(시안·구현) · reviewer: Codex(묶음 리뷰 때) · status: 구현 중 · updated: 2026-11-17

## 요청과 결정 (Jay, 2026-11-17)

- 2단계(힉스필드 사용량 API 기준)로 dev 에 들어간 계정 메뉴 단추·'내 사용량' 창이 고른 시안(https://claude.ai/artifact/NmJhau2k2c6SreQ3RHUHjM)과 달랐다 — 설계 문서가 '구성'만 적고 모양을 적지 않았다(`hf_org_usage_phase2_2026-11-17.md:347`).
- 메뉴: "작은 글씨들 없앤 시안" → "사용이나 사용량 영어로 하고 사용량 버튼은 없애고 사용량 누르면 되게" → "숫자 부분 누르면 사용량 나오게, 호버하면 라임색" → "사용량 앞에 ≈ 마크, 글씨 크기는 위 글씨들이랑 맞춰서".
- 창: "이 시안이랑은 다르네?" → 시안대로 맞춘 그림 → **"b로 하고 시안대로 화면도 같이 진행"**.
- 시안 그림: 세션 스크래치 `final_menu_v2.png`(메뉴)·`usage_window_v5.png`(창).

## 바꾸는 것

- 계정 메뉴 Limit 칸: `Limit` 아래에 `Usage` 줄(영어 이름표, Limit·User group 과 같은 굵은 흰 글씨). 값 = `≈`(집계 전 견적이 있을 때) + 사용량 + `›`, 크기 12.5px(위 값과 같음). **숫자를 누르면 '내 사용량' 창**, 마우스를 올리면 숫자·`›` 가 라임(줄 배경 그대로).
- 메뉴에서 빠지는 작은 글씨: 기준 줄(`힉스필드 기준 · 기간 · 수집 시각`)·`사용 ≈ N` 줄·`오류 보고 후 전액 환불 N건`·`사용량 미확인 N건` → 모두 Usage 숫자의 풀이 글(title)로. `내 사용량 보기` 단추는 없앤다.
- 미배정·옛 서버: 창을 열 수 있으면(새 서버) 값이 없어도 `— ›` 로 누를 수 있게, 옛 서버(기준 없음)는 Usage 줄 자체를 숨긴다(지금 계약 유지).
- '내 사용량' 창: 제목 줄에 `내 사용량 · M/D ~ M/D` + 오른쪽에 기간 칸(오늘·이번 주·이번 기간·지난 기간)·공간 고르기·×. 숫자 칸 4개(실제 사용(환불 뺀 값) · 환불된 크레딧 · 실패 N건(라임) · 생성 수 · 아직 집계 전(견적 ≈ N)). 만든 곳 막대 색 구분(MV 라임 · 웹 파랑 · Claude Code·MCP 보라 · 차감·기타 회색). 표 = 짧은 시각(KST)·색 알약·한국어 상태(완료·실패 빨강·차감·집계 전·취소·진행 중).
- 창에서 빠지는 작은 글씨: 기준 줄 → 제목 풀이 글, 환불·견적 안내 → 칸 설명으로 합침. 'MV 기록에는 동기화로 가져온 기록도 포함될 수 있습니다'(2단계 D8)는 MV 막대 이름의 풀이 글로 남긴다. 드물게만 나오는 안내(미확인·오래된 미매칭·순값 남은 오류·1,000건 제한)는 그럴 때만 표 위 한 줄.
- 키가 없거나 연결이 안 됐을 때(facts·unavailable): 칸·표 없이 "힉스필드 사용량이 아직 연결되지 않았습니다" + 이유·대체 합계(0 으로 꾸미지 않는 2단계 계약 유지).

## 바꾸지 않는 것

- 숫자 계산·서버 응답(my-quota·my-usage)·권한·늦은 응답 버리기·Esc/초점 처리.
- 관리 화면(MemberTable·CreditPoolSection·ConsoleSubView)의 기준 줄 `.credit-usage-basis` 스타일 — 이 규칙이 `my-usage.css` 에만 있어 그대로 둔다.
