# 어셋 왼쪽 폴더 트리 — 폴더 우클릭 → 원본 위치 열기 (2026-11-20)

## 요청

Jay 11-20(어셋 창 왼쪽 폴더 트리 화면): "어셋에서 사이드 폴더 트리에서 마우스 우클릭하면 폴더로 가는 버튼 시안 보여줘" → 시안 A·B 중 "B안으로 만들어".

## 정한 것 (시안 B)

- 폴더 줄을 우클릭하면 작은 메뉴가 뜬다. 위에 폴더 이름(흐린 글자), 아래에 '📂 원본 위치 열기' 줄 하나.
- 누르면 그 폴더 **안**이 윈도우 탐색기에서 열린다. 공유 & 리뷰·편집 탭의 '원본 위치 열기'와 같은 동작이다.
- 이 PC 에서 켠 앱(localhost·127.0.0.1·[::1])에서만 메뉴가 뜬다. 서버 주소로 접속한 화면에서는 브라우저 기본 메뉴 그대로다(다른 탭과 같은 기준, 최종 판정은 백엔드 로컬 가드).
- 메뉴 틀은 폴더 우클릭 메뉴(`.folder-ctx-menu`), 줄은 크게 보기 우클릭 메뉴 줄(`.preview-menu-item`)을 그대로 쓴다.

## 고친 곳

- `frontend/src/components/assets/FolderTree.tsx` — 공통 트리(`FolderTreeView`)의 우클릭 콜백을 넘겨준다.
- `frontend/src/components/assets/AssetsSidebar.tsx` — 메뉴 상태·그리기. Esc(초점은 그 줄로 복귀)·바깥 누름·Tab 으로 닫힌다.
- `frontend/src/styles/assets.css` — 메뉴 간격·이름 글자만.
- `backend/app/routers/assets.py` `reveal_file` — 대상이 폴더면 그 안을 연다(전엔 파일·폴더 모두 상위 폴더에서 골라 둔 채 열었다. 지금 화면에서 폴더를 넘기는 곳은 이번 메뉴뿐이다 — 파일 쪽 동작은 그대로).

## 확인

- 프런트: `assetsTreeMenu` 새 시험 2개 + 어셋·폴더 트리 기존 시험 16개 파일 통과(시험 기록 `d91d7b62`) · 타입 검사·경계 검사 통과.
- 백엔드: `test_assets_reveal_folder`(폴더 3개 OS·파일 1) + `test_mutation_notify` 통과(시험 기록 `4f99eb20`).
- 화면 눈 확인은 아직이다(5173 은 로그인이 필요). 프런트는 Vite 가 바로 반영하지만, 폴더 '안'을 여는 백엔드 변경은 `test_dev.bat` 을 다시 켜야 적용된다 — 그 전엔 상위 폴더에서 골라 둔 채 열린다.
