# 캔버스 탭 폴더 — '+' 우클릭으로 폴더 추가, 끌어 넣고 빼기 (2026-11-11)

owner: Claude(구현, 세션 `ab4597ba`) · reviewer: 미정(묶음 검토 때) · status: 검증 중(dev `06a3eb91` — Jay 5173 확인 남음) · touched_paths: 아래 계약 · updated: 2026-11-11

Jay 요청(11-11): 캔버스 탭 줄의 '+' 를 우클릭하면 [씬 추가 · 폴더 추가]. 폴더를 만들면 거기에 탭을 넣을 수 있게. 넣고 빼기는 **끌기로만**(폴더에 넣는 단추 없음 — Jay "내가 끌어다 넣거나 끌어다가 다시 탭에 복귀시키면 된다").
시안: 세션 스크래치 `tab-folder-mock-v4.png`(A·B안 → 크롬 방식 → '+' 우클릭 → 끌기만, 4번째 판에 Jay "만들어").

## Jay 확정(시안 v4)

- '+' 그냥 누름 = 지금처럼 씬 추가. 우클릭 = 메뉴 두 줄 [씬 추가 · 폴더 추가].
- 폴더 추가 = 줄 맨 끝('+' 앞)에 빈 폴더, 이름 글칸이 바로 열림(Enter·바깥 = 저장, Esc = '새 폴더' 그대로). 나중엔 더블클릭·우클릭으로 이름 고침.
- 탭을 폴더 위에 끌어 놓으면 들어감(그 탭은 줄에서 빠짐). 폴더 누름 = 안의 탭 목록, 줄 누름 = 그 탭 열기.
- 목록의 탭을 끌어 탭 줄에 놓으면 그 자리로 돌아옴(삽입선). 다른 폴더 위면 그 폴더로. 엉뚱한 곳이면 취소.
- 지금 보는 탭이 폴더 안이면 폴더 바로 옆에 라임 탭으로 남음(폴더 테두리도 라임).
- 폴더 우클릭 = 이름 · 폴더 풀기(안의 탭은 줄로). 폴더에는 × 없음(탭 × 는 씬 삭제라 헷갈리지 않게).
- 폴더 색은 한 가지 · 폴더 안 폴더 없음 · 탭 우클릭 메뉴는 그대로.
