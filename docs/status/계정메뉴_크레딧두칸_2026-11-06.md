# 계정 메뉴 크레딧 — 힉스필드식 두 칸 (2026-11-06)

Jay 11-06: 힉스필드 계정 메뉴처럼 우리도 내가 속한 그룹과 나에게 할당된 크레딧을 보여야 한다 → 시안 4번(비공개 시안 페이지 Version 4) "이 시안대로 만들자".

확정한 모양(Jay):
- 위 칸 **Credits** — 워크스페이스 잔액 `N left`(값은 회색, 소수 그대로), 점 게이지는 모두 이 칸. 누를 수 있는 계정이면 `›`(대시보드, 지금처럼).
- 아래 칸 **Limit** — 한도 있는 사람 `남은 몫 / 내 한도`, 한도 없는 그룹 `∞`, 그룹에 안 든 사람 `—`. 그 밑 줄 **User group** — 그룹 이름, 없으면 `None`.
- 이름표는 영어(Credits · Limit · User group). 그룹을 옮긴 경우에 따로 붙는 글·색은 없다.

계산은 그대로다(서버·DB 무변경): 점·아바타 고리 = 한도 있는 사람은 남은 몫 ÷ 내 한도, 그 밖은 워크스페이스 잔액 ÷ 이번 달 충전(`pool_total`, 09-29 결정 — 충전량은 몫 없는 사람에게만). 그룹 이름은 서버가 이미 보내는 `my-quota.group_name`. 견적·미확인 사용량 안내(`quotaUncertainty`)는 있을 때만 Limit 밑에 남기고, 기간·사용량·할당 출처는 Limit 줄의 풀이 글(title)로 옮긴다.

그룹을 옮기면 새 그룹 몫에서 옮긴 뒤 사용만 빼는 규칙은 이 작업 밖이다(그룹에 들어온 날을 남기는 DB 칸이 필요 — 설계·Codex 검토·서버 업데이트, Jay 결정 대기).
