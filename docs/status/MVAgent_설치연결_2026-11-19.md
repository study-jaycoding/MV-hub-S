## 3. 완료 조건

1. 설정 > 연결의 Claude·Codex 줄이 '설치 안 됨'이면 오른쪽 단추가 **[설치하고 연결]** 이다.
2. 누르면 다음이 이어서 일어난다.
   - ① 공식 설치기가 창 없이 돈다.
   - ② 끝나면 바로 로그인 단계로 간다. Claude 는 지금 로그인 창, Codex 는 새 로그인 창이다.
   - ③ 로그인이 확인되면 Codex 는 켜기 점검을 자동으로 한 번 돈다.
   - ④ 줄에 '연결됨'이 보인다.
3. 진행 상태가 줄에 보인다: 설치하는 중 · 로그인 창 기다리는 중(스피너).
4. 실패하면 까닭 한 줄 + [다시 시도] + '직접 설치하려면'(접힘, 명령 복사)을 보인다.
5. 단추로 누른 설치는 24시간 재시도 대기를 무시한다. 자동 설치(앱 켤 때)의 대기 규칙은 그대로다.
6. 공유 서버·관리자 권한·서비스 계정·대화형이 아닌 로그인에서는 설치하지 않고 까닭을 보인다(Claude 판정 재사용).
7. 허브가 공식 설치본 Codex 를 찾는다. npm 판과 둘 다 있을 때 고르는 규칙은 Codex 검토 뒤 정한다.
8. 이미 연결된 PC(Jay)의 화면·동작은 바뀌지 않는다.

## 4. 설계

### 4-1. 설치를 누가 돌리나 — A안(추천): 실행기가 돌린다

- 화면 [설치하고 연결] → 허브 `POST /api/agent-chat/{claude|codex}/install`.
  - 허브는 자격(릴리스·공유 서버 아님)만 보고 **요청 표식**을 쓴다: `%LOCALAPPDATA%\MVHub\<엔진>-install.request`.
  - 표식에는 nonce·시각을 담는다.
- 실행기(`run_agent_session.py`)가 요청을 알아채고 지금 Claude 설치와 **같은 장치**로 설치한다: 파일 잠금·토큰 판정·설치 전용 Job·0개 확인·표식.
  - Codex 는 설치 명령·확인 경로·표식 이름만 다르다.
  - 요청으로 시작한 설치는 `recent_failure` 대기를 건너뛴다.
- 허브·화면은 지금처럼 **표식만 읽어** 상태를 낸다: running·failed·skipped·ok.
- 까닭: 7판 합의는 '허브는 설치하지 않고 표식만 읽는다'로 정했다(`run_agent_session.py:1455-1458`). 그 구조와 리뷰로 굳은 잠금·Job 정리를 그대로 쓴다.
- **Codex 판단 요청**:
  - 실행기가 요청을 알아채는 방법: 요청 파일을 2초마다 보는 스레드 vs 이름 있는 이벤트.
  - 실행기가 없는 dev(`test_dev.bat`) 경로에서 어떻게 되는가.

B안: 허브가 직접 설치한다. 코드는 짧다. 하지만 허브가 다시 켜지면 설치가 끊기고, 허브 프로세스 아래에서 원격 스크립트가 돌아 7판 구조와 어긋난다. 그래서 추천하지 않는다.

### 4-2. 로그인으로 이어 가기

- **Claude**: 설치가 끝나 엔진 상태가 `not_logged_in` 이 되면, 화면이 지금의 [연결] 흐름(로그인 창)을 **자동으로 한 번** 부른다. 이미 로그인돼 있으면 바로 '연결됨'이 된다.
- **Codex**: 새 '로그인 창'을 만든다.
  - `codex login`(브라우저로 ChatGPT 로그인)을 Claude 로그인 창과 같은 규칙으로 띄운다: 일반 사용자 토큰만·같은 사용자·Job 탈출 규칙.
  - 로그인이 끝나 `codex login status` 가 'Logged in using ChatGPT' 가 되면 화면이 `codex/enable`(켜기 점검)을 자동으로 부른다.
  - **Codex 판단 요청**:
    - 콘솔 창을 보이게 띄울지, 창 없이 띄워 브라우저만 열지.
    - `codex login` 이 쓰는 로컬 콜백 포트가 이미 쓰이고 있을 때.
    - 기다리다 그만두기와 끄기.

### 4-3. Codex 찾기

- `find_codex` 가 보는 순서:
  - ① 지금의 npm 경로
  - ② 공식 설치의 **정확한 경로** `%LOCALAPPDATA%\Programs\OpenAI\Codex\bin\codex.exe`. 허브가 켜진 뒤 설치하면 허브 PATH 에는 없다(Claude 와 같은 까닭).
- 둘 다 있으면 판이 높은 쪽, 같으면 공식 쪽(Claude `find_claude` 와 같은 규칙) — 초안이다.
- 공식 설치본은 `node` 없이 실행 파일을 바로 부른다(`[codex.exe]`).
- 11-14 켜기 점검(가짜 check_connection + nonce, `--disable hooks`, 작업 폴더 검사)이 독립 실행 파일에서도 같게 통과하는지 시험한다. 점검이 판 차이를 막는 관문이다.
