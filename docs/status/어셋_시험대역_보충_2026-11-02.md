## 결과

- 세 파일의 API 대역에 `projects` 를 더했다. `lateResponses` 는 대역 묶음 전체를 `mockReset` 하는 시험이라 묶음 밖에 뒀다.
- 고치기 전 6건 실패를 재현했고, 고친 뒤 3개 파일과 훅·`assetProjects` 를 쓰는 10개 파일이 모두 통과했다.
- 전체 시험은 이 세션에서 돌리지 않았다. 전체 범위 실패는 이 6건이라는 것은 다른 세션의 보고다.
- 놓친 까닭: 시험을 `AssetsView` 이름으로만 찾았다. 호출을 더한 곳은 훅이라 훅·API 이름으로 찾아야 했다.
