# 캔버스 탭 — 설명 창을 앱 창으로 (2026-11-02)

owner: Claude · reviewer: (묶음 리뷰) · status: 구현 완료(dev 커밋 · Jay 화면 확인 남음) · touched_paths: 아래 계약 · updated: 2026-11-02

Jay: 캔버스 탭에 올렸을 때 나오는 정보를 더 보기 편하게. 지금은 브라우저 기본 말풍선이라 조작이 한 줄로 이어지고 모양을 바꿀 수 없다.

시안을 비교한 뒤 Jay 가 고른 모양: 노드 설명 창과 같은 앱 창 · 이름 옆에 워크스페이스 표식과 이름('워크스페이스' 글자 없음) · 조작은 한 줄에 하나로 휠 클릭·우클릭 두 줄만(클릭·끌기 뺌).

고친 것: `NodeTip` 에 범위(`within`)·제목 고정(`data-tip-head`)·표식(`data-tip-ws-*`)을 더해 `SceneBar` 에서 쓴다. 버튼을 누른 채 지나갈 때는 창을 띄우지 않는다 — 탭을 끄는 동안 뜨지 않게 한 것으로, 노드 설명 창에도 같이 적용된다.

확인: 실제 `scene.css` 로 다섯 상태(기본·지정 안 함·긴 이름·다른 공간·찾을 수 없음)를 그려 봤다. 앱 화면에서 재 본 것은 아니다.

남은 한계: 워크스페이스 이름에 ` = ` 가 들어 있으면 줄 규칙이 조작 키로 읽어 조작 줄에 한 줄 더 나온다(화면 표시만, 동작은 그대로).
