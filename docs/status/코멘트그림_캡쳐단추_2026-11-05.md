# 코멘트 그림 — 이미지 캡쳐 단추 · 영상 무대 크기 되돌리기 (2026-11-05)

Jay 11-05: 이미지 코멘트 창에도 여러 장을 붙이게 — 도구 캡슐 끝 캡쳐 단추(시안 2차 확정: **아이콘만**, 캡쳐하면 **빨간 숫자** = 붙은 장 수). 같이 "영상 일부러 비율 맞췄던 것 원래대로"(정사각형 이미지도 꽉 차지 않으니 영상만 따로 맞출 까닭이 없다) → **"함께 구현"**.
앞 작업: [크게보기_코멘트그림_설계_2026-11-05.md](크게보기_코멘트그림_설계_2026-11-05.md) (dev 통합 7c8c33b5). 서버는 이미 이미지 그림을 한 코멘트에 12장까지 받는다(획 v1 `idx` 0~11) — 화면만 바뀐다.

## 정한 동작

- 이미지 코멘트: 그리고 캡쳐 → 그린 것이 아래 붙는 그림 칸에 한 장으로 붙고 그림판이 빈다 → 다시 그리고 캡쳐… 12장까지. 붙은 그림을 누르면 그 그림을 그림판에 다시 불러와 고친다(그때 그리던 것은 붙은 장으로 남는다), 올리면 ×.
- [코멘트 달기] 때 캡쳐 안 한 그림판도 마지막 장으로 같이 붙는다(빠뜨림 방지). 순서 = 처음 그린 순서.
- 영상: 지금처럼 프레임마다 한 장(캡쳐 단추 없음). 무대 높이 제한을 수정 창과 같은 값(`50vh − 124px`)으로 되돌린다(시안 3차에서 `56vh − 106px` 로 바꿨던 것).
