## 1. 다른 탭에서 복사해 붙인 레퍼런스가 '서버에 없음'

Jay: "다른 탭에 있는 레퍼런스를 복사해서 다른 탭에 붙여넣기를 했는데 … 서버에 없음으로 나온다. 확인해보니 레퍼런스는 서버에 있다." (원본: 뻘뻘뻘 `Assets/CH/대하/대하.png`)

원인(코드 확인, Jay 브라우저의 판정 저장값은 직접 못 봄 — 추정 포함):
- 서버 판정은 `(캔버스 탭의 공간, 토큰, 지문, 대장 번호)` 열쇠로 브라우저에 저장되고 만료가 없다(`lib/sceneAssetRelink.ts`). 자동 복구는 판정이 저장된 참조를 다시 묻지 않는다.
- 노드 붙여넣기(`useSceneClipboardDrop.pasteCopiedNodes`)는 카드를 그대로 복사할 뿐 다시 묻지 않는다. 공간이 다른 탭에 붙이면 그 공간 열쇠에 남아 있던 옛 '서버에 없음'(그 그림이 없던 때의 답 등)이 곧바로 보인다. 지금 다시 물으면 서버는 이 PC 에서 열리는 토큰을 `open` 으로 답한다(`assets.locate_legacy_assets` — 열리면 판정 없이 open).
- '서버에 없음' 칸은 썸네일을 부르지 않아 '그림이 깨지면 다시 묻기'(`recheckBrokenRef`)도 돌지 않는다.

고침: 붙여 넣은 카드의 에셋 참조는 붙인 탭 공간의 판정을 지우고 다음 자동 복구에서 한 번 묻는다(그림 놓기와 같은 길 — `onLocalRefsAdded`).
