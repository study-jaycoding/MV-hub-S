# 캔버스 탭 — 더블클릭으로 이름 바꾸기 (2026-11-02)

owner: Claude · reviewer: (묶음 리뷰) · status: 구현 완료(dev 커밋 · Jay 화면 확인 남음) · touched_paths: 아래 계약 · updated: 2026-11-02

Jay: 캔버스 탭이나 탭 설명 창의 이름을 더블클릭하면 이름을 바꿀 수 있게 한다. 시안에서 A안(어두운 글칸)을 골랐다. 지금 이름 바꾸기는 우클릭 메뉴에만 있고, 그 칸은 그대로 둔다.

고친 것: 글칸 `SceneNameInput` 을 탭과 설명 창이 같이 쓴다. 설명 창에서 고치는 동안은 `NodeTip` 의 `pin` 으로 붙들어, 글을 치거나 마우스가 나가도 닫히지 않고 글칸이 끝날 때 닫힌다. 바깥을 누르면 글칸이 초점을 잃어 스스로 저장한다.

확인: jsdom 시험으로 두 자리의 저장·취소·빈 이름·같은 이름·한 번만 저장·창 붙들기를 봤고 빌드를 통과했다. 실제 브라우저에서 한글을 쳐 본 것은 아니다.

문서: `docs/CODE_MAP.md`·`docs/기능설명서.md` 도 고쳤다. 다른 세션의 미커밋 변경이 있어 계약 범위에서 빼고 내 줄만 커밋했다.

남은 한계: 글칸의 폭은 `field-sizing: content` 로 맞춘다(크롬 123 이상). 그보다 옛 브라우저는 기본 폭으로 뜬다.
