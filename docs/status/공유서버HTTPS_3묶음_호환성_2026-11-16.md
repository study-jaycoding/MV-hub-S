## 이번 묶음의 판단

- **스킴만 다른 같은 서버는 저장된 신원을 바꾸지 않는다**(DB·대기열 일괄 이전 없음). 같은 서버 판정 = 소문자 호스트 + 스킴 기본값으로 채운 명시 포트(+경로) — `http://h:8010` ≡ `https://h:8010`, `http://h`(80) ≢ `https://h`(443), 다른 호스트·포트는 절대 합치지 않는다. 이 판정을 주소 입력(로그인·가입·`set_shared_url`·저장)과 이전 공지(제안·적용·'옮겨짐' 알림)의 입구에만 둔다 — 그래서 대기열·키·프런트 비교는 손대지 않아도 신원이 그대로다.
- **전송 주소는 2묶음 그대로**(`TLS_REQUIRED` 일 때 https). 화면에는 따로 '보여 줄 주소'(전송 주소)를 내려 보내 보인다.
