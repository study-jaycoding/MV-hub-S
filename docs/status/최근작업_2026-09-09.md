## 교훈 (재발 방지)

- **`pytest -x` + `| tail` 은 실패를 가린다** — 첫 실패에서 멈춘 "1 failed" 가 파이프 뒤 종료 코드 0 으로 보였다.
  전체 회귀는 `-x` 없이 돌리고 종료 코드를 파일로 받는다.
- **경계 테스트는 지역 import 도 간선**(`ast.walk`). "지역 import 로 순환 회피"는 여기서 통하지 않는다 —
  공용 헬퍼가 저장소 모듈을 필요로 하면 호출자(라우터)가 값을 읽어 내려준다.
- **권한 검사는 "실제로 저장될 것"에**. 후보 전체에 걸면 정상 요청(잉여 조상 포함 선택)을 깨뜨린다(리뷰 ①).
