# 오디오 크게 보기에서 [History] 빼기 (2026-11-06)

Jay 11-06(오디오 크게 보기 화면): 오디오의 [History] 를 누르면 캔버스에 탭도 안 보인다 → "오디오만 빼기"(두 안 중 선택 — 다른 안은 크게 보기 [History] 를 격자 카드 ⧉ 처럼 레시피 씬 탭으로 통일).

확인(코드): 크게 보기의 [⧉ History] 는 예전 '구성에서 보기'를 11-05 에 이름만 바꾼 것이라(`크게보기_Ctrl카드단추_2026-11-05.md`) 계보 트리(`HistoryBoard`)로 간다 — 트리를 그리려고 활성 씬을 내려놓아 씬 탭이 선택되지 않는다(`App.tsx` `onOpenInBoard` 주석, 설계대로). 오디오는 계보가 거의 없어 트리에 볼 것이 없다(실제 화면은 미확인). 격자 카드의 ⧉ History(레시피 → 새 씬 탭)와 생성 정보 창의 ⧉ 히스토리(계보 트리)는 그대로 둔다. 수정 단추를 종류에 맞는 것만 두는 규칙(Jay 10-28)과 같은 방향.
