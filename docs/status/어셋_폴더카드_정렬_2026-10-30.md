# 어셋 폴더 카드 정렬 — 폴더 정렬을 따로 기억 (시안 B안) — 2026-10-30

owner: Claude(구현 — 세션 0d796f46) · reviewer: 없음(화면 동작, 데이터 쓰기 없음) · status: 구현 중 · touched_paths: 아래 계약 · updated: 2026-10-30

요청: 격리 실측에서 어셋 폴더 카드 화면의 [정렬]이 카드 순서를 바꾸지 못한다는 것을 찾았다. 시안 A·B안을 그림으로 보였고 Jay 가 "추천대로"(B안)를 골랐다.

## 왜 B안인가

어셋 파일 정렬의 기본값이 날짜 최신순이라, 폴더 카드가 이 값을 그대로 따르면(A안) 어셋 탭을 열자마자 폴더 순서가 지금과 달라지고 작업할 때마다 자리가 바뀐다. B안은 폴더 정렬을 따로 기억하고 기본을 이름 오름차순으로 둬서 처음 화면은 지금과 같고, 직접 고를 때만 바뀐다.

## 규칙

- 폴더 카드 화면의 정렬 창 = 이름·날짜 / 오름·내림. 폴더에는 유형이 없어 유형을 뺀다.
- 파일 화면의 정렬과 따로 기억한다(`folderSortField`·`folderSortDir`). 기본 = 이름 오름차순.
- 날짜 = 폴더 안에 든 가장 최근 파일. 폴더 자체에는 날짜 값이 없다. 필터가 켜져 있으면 걸러진 파일 안에서 고른다.
- PR 을 Reference 앞에 두는 순서·프로젝트별 맨 아래 폴더는 이름 오름차순에서만 지킨다.
- 폴더 이름 비교는 서버 순서처럼 영문이 한글보다 앞이다. 파일 정렬의 비교기를 그대로 쓰면 한국어 환경에서 한글 폴더가 앞으로 와서 처음 화면이 달라진다(이 PC 시험에서 실측). 번호만 2 다음 10 으로 자연스럽게 줄 선다. 서버 순서에서는 10 이 2 앞이었다.
- 카드 안 작은 폴더 줄·폴더 화면에 같이 나오는 직접 파일도 같은 정렬을 따른다. 정렬 창이 화면 전체에 맞는 말을 하게 하기 위해서다.
- 카드 표지 그림은 지금처럼 파일 정렬의 첫 파일이다.
- 왼쪽 폴더 트리는 바꾸지 않는다.
