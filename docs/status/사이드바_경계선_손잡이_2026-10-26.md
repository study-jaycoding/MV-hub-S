## 한 것

- `common/SidebarEdgeToggle`(새 부품) — 단추 하나: 열림 = `‹`·`.open`, 닫힘 = `›`. 제목·`aria-expanded` 는 부르는 쪽 글.
- `LibraryToolbar` — 옛 ▢/▷ 단추(`lib-filter-ic`·`FilterPanelIcon`) 대신 손잡이. 배선(`filtersOpen`·`onToggleFilters`·`showFilterToggle`)은 그대로.
  App 의 폴더 창 도구 줄·캔버스 '생성 결과' 창 도구 줄은 `showFilterToggle: false`(떠 있는 창이라 사이드바 옆이 아니다). 뒤에 남기는 눌리지 않는 사본에는 그대로 보인다.
- `generations.css` — `.lib-toolbar` 에 `position: relative`, `.side-edge-toggle`(열림 top 14·left -11·22px 동그라미 / 닫힘 top 12·left 0·16×26 반달, z-index 3 = 사이드바 폭 손잡이 위).
- `AssetsView` — `treeOpen`(`ch.assets.treeOpen`, 처음 = 열림)으로 `AssetsSidebar` 를 그리거나 빼고, `main.assets-grid-wrap` 맨 앞에 같은 손잡이('폴더 사이드바 닫기/열기').
- 편집 탭 풀의 ▢/▷ 단추(`EditPool` — `lib-filter-ic`·`FilterPanelIcon`)는 그대로다(위 결정).

시험: `tests/sidebarEdgeToggle.test.tsx`(도구 줄 열림·닫힘 모양·누름·옛 단추 없음 / 떠 있는 창·보드는 없음·캔버스는 있음 / 어셋 창 여닫기·기억·다시 열기) ·
