## 설계

1. **트리 = 공용 `FolderTreeView`**(공유·편집 탭과 같은 것) — 누르기 = 고르기(가지 = 에피소드, 잎 = 컷) · 두 번 누르기·폴더 아이콘 = 펴고 접기 · 위 폴더 ★·R·새 수 · 글자 15/13 · `genRows` 로 고른 줄 라임, 다빈치 지금 빈 = `viewedPath`(빨간 ▶). 줄 표 설명 글은 패널용으로 바꿔 넘긴다(`markTitles` — 공용 트리에 선택 속성 하나, 안 주면 지금 글 그대로).
2. **프로젝트 고르기** — 사이드바 맨 위 '프로젝트' 단추(마크·이름·생성물 수·▾) → 볼 수 있는 프로젝트 목록 펼침. 맨 아래 프로젝트 줄 목록은 없앤다.
3. **사이드바** — `ResizableSidebar`(앱 사이드바와 같은 손잡이, 패널 전용 저장 키, 160~420px) · 닫기 = `SidebarEdgeToggle`(미디어 풀 머리줄과 컷 타일 머리줄 둘 다 — 닫아도 다시 여는 단추가 늘 보임).
4. **다빈치 빈 자동 순서 = 보내기와 같은 `_reconcile_folder_tree`** — `target` 의 `create_paths` 처리를 이것으로 바꾼다: 없는 빈 만들기 + 자연 정렬이 깨졌으면 **프로젝트 저장 + DRP 백업 → 시험 통과 판(21.1.1.10)은 빈만 옮기는 빠른 길, 아니면 클립을 옮겨 MV Hub/<프로젝트> 를 다시 짓기**(보내기와 같음 — 이때 빈 ID 가 바뀐다). 복구 기록 관문(`_settle_recovery_record`)·`_ProjectChanged`·`_RebuildRecoveryNeeded` 도 보내기와 같게 — 정렬에 넘기는 guard 는 `_ProjectChanged` 를 던지고(지금 패널 guard 는 일반 오류), `resolve=`·`project_label=` 을 넘기며(안 넘기면 빠른 길이 꺼진다), `MV Hub/<프로젝트>` 빈을 먼저 만든다. 프로젝트 바뀜·복구 대기(code `project_changed`·`rebuild_recovery_*`)는 정렬 오류로 삼키지 않고 남은 것(leftover)과 함께 멈춘다. 그 밖의 오류로 정렬만 실패하면 빈은 지금처럼 하나씩 만들고 `order_error` 로 알린다. 보내기·타임라인 보내기와의 배제는 **이미 있는 `resolve_mutation_slot`**(패널 자식이 30초 기다리고 못 잡으면 busy — Claude 설계 검토가 확인)으로 하고 새 잠금은 만들지 않는다. **다시 짓기(느린 길)는 `MV Hub/<프로젝트>` 아래 모든 빈의 ID 를 바꾼다** → 자식이 정렬 전후 ID 를 견줘 `ids_changed` 를 돌려주고, 서버는 그 MV 프로젝트의 컷 빈 기억(`_cut_bins`·`_episode_bins`·`_owner` 빈)을 버린 뒤 새 bins 만 기억, 화면은 모든 에피소드 빈 표·따라가기(via)를 버린다(옛 ID 로 stage·정리·따라가기를 하지 않게).
5. **새로 활성이 된 컷(실시간)** — 고른 에피소드의 빈 표에 없는 활성 컷이 트리에 생기면 `target(keep_current=true, episode_path, create_paths=그 에피소드의 활성 컷 전부)` 한 번(진행 중이면 합침, 지금 선택의 seq 를 그대로 — 사람의 cache·stage 를 stale 로 만들지 않게, 사람이 새로 고르면 자동 target 이 stale). 자식은 **첫 쓰기 전에 지금 빈의 ID·경로를 적어 두고**, 만들고 줄 세운 뒤(정렬만 실패해 하나씩 만든 때도) **지금 빈을 되돌리고 되읽는다**(ID 로, 다시 짓기로 바뀌었으면 경로로). 프로젝트 바뀜·복구 대기로 멈췄으면 더 쓰지 않는다. **되돌리지 못하면 성공(ok)으로 돌려주지 않는다**(`restore_failed`). 돌려주는 `bin_id` 는 되돌린 실제 지금 빈이고, 라우터는 이것으로 `remember_bin` 하지 않으며 화면은 lastBin 을 에피소드 빈으로 바꾸지 않는다. `keep_current` 일 때 folder_path = episode_path 여야 한다. **자동 target 이 busy·stale 이 아닌 실패로 끝나면 같은 활성 컷 묶음으로는 다시 자동 부르지 않는다**(사람이 다시 누르거나 묶음이 바뀔 때만 — 실패마다 저장·백업이 되풀이되지 않게). 사람이 누른 에피소드·컷 target 은 지금처럼 그 빈을 지금 빈으로.
6. **다빈치 프로젝트별 기억** — 저장된 선택을 다빈치 프로젝트 ID 마다(`byResolveProject`) + 마지막 것. 패널은 선택이 없어도 2초 `current-bin` 으로 열린 다빈치 프로젝트 ID 를 안다. 그 ID 가 바뀌면 그 프로젝트의 저장된 선택으로 바꾸고, **앞 프로젝트의 정리(leftovers)·빈 표·따라가기는 버린다**. Selection 에 다빈치 프로젝트 ID 를 싣고, **모든 패널 쓰기(target·stage·unstage)에 기대 다빈치 프로젝트 ID(`expect_project`)를 실어 자식이 첫 쓰기 전에 실제 ID 와 대조**한다(다르면 쓰기 0 으로 `project_changed`). 실행 중에는 지금처럼 guard 가 쓰기마다 본다. 화면은 늦게 온 응답의 다빈치 프로젝트 ID 가 지금 것과 다르면 버린다.
7. **실시간** — 앱과 같은 실시간 연결(`connectProgress` → `/ws`)의 `synced`·완료(`status: done`)를 받으면 1초 묶어 목록·트리 수를 다시 읽는다. 15초 다시 읽기는 안전망으로 남긴다.
8. **빠른 전환** — 프로젝트 전체 공유 목록을 한 번 받아(목록 훅에 `wholeProject` — 폴더 없이 프로젝트 전체, 2,000 상한 그대로) 에피소드·컷을 바꿀 때는 다시 받지 않고 거른다. 2,000 을 넘으면(capped) 지금처럼 에피소드마다 받는다.
