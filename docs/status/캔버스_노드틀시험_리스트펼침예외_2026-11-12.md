# 캔버스 노드 틀 시험 — 펼친 리스트를 텍스트 편집과 같은 예외로 (2026-11-12)

위 속성의 `active`는 이 작업의 진행 기록이라는 문서 위상이며, 구현 완료·검토 완료·배포 승인을 뜻하지 않는다.

## 문제

`frontend/tests/scenePortRingAlign.test.ts` 의 '노드 틀 통일(Jay 2026-10-29, 10-30 2px)' 시험이 `d670d568`(리스트 그 자리에서 키우기) 뒤로 늘 실패한다.
실패 줄은 `.scene-card.scene-card-list[data-list-expanded] { border-color: transparent }` 하나다. 그래서 dev 프런트 전체 시험이 깨끗하지 않아 다른 작업의 회귀를 가린다(11-12 저장 입구 모양 지킴이 작업에서 7,060개 중 2개 실패로 드러남).

## 판단 — 규칙 위반이 아니라 시험이 모르는 의도된 예외

- [노드 테두리 통일 기록](캔버스_노드테두리_통일_2026-10-29.md)의 시험은 처음부터 "종류별 규칙이 틀 색을 따로 칠하지 않음 — 빨강·**편집 중 숨김만 예외**"로 정했다. 텍스트 노드는 편집하는 동안 노드 테두리를 숨기고(`[data-text-editing]`), 떠 있는 큰 편집 창(`.scene-textfloat`)이 자기 색 2px 틀을 대신 그린다.
- [리스트 그 자리에서 키우기 기록](캔버스_리스트_그자리키우기_2026-11-11.md)은 Jay "텍스트 노드 작동 방식처럼"(2026-11-11)에 따라 그 방식을 그대로 옮겼다. `scene.css` 의 펼친 리스트 규칙은 텍스트 편집 규칙과 한 글자도 다르지 않은 짝이고(`border-color: transparent; box-shadow: none; background: transparent`), 떠 있는 칸 `.scene-listfloat` 이 `0 0 0 2px var(--pc, var(--accent))` 로 노드 자기 색 2px 불투명 틀을 그린다.
- 그래서 보이는 틀은 여전히 '2px · 자기 색'이다. 노드 틀 통일을 어기지 않으며, 시험이 텍스트 편집 예외만 알고 펼친 리스트 예외를 모를 뿐이다. CSS 는 그대로 두고 시험만 고친다(작은 쪽). Jay 결정이 필요한 갈림이 아니다.

## 고칠 것

- 예외 목록에 `data-list-expanded` 를 더한다.
- 예외가 헛되지 않게, 텍스트 큰 편집 창 틀 확인(시험 66행)과 같은 줄로 `.scene-listfloat` 틀이 자기 색 2px 인지 함께 본다 — 노드 테두리를 숨긴 대신 떠 있는 칸이 틀을 그린다는 약속.
