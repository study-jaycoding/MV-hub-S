## 결과

- 구현: `TableView` 에 `workTableTotals`(보이는 줄의 합계) + `<tfoot>` 두 줄(격자 빈 줄 `.work-gap-row`, 계산 줄 `.work-calc-row`). `<tbody>` 는 그대로다. CSS 는 테이블 보기일 때만(`:has(.work-table)`) 관리 창을 세로 flex 로 나눠 표 칸(`.manage-table-wrap`)이 세로 스크롤을 맡고, 계산 줄 칸은 `position: sticky; bottom: 0`(바탕 `--bg`, 위 선은 inset 그림자 — 접힌 테두리는 sticky 칸을 따라가지 않는다). 표 칸 최소 높이 160px — 그보다 작은 창은 예전처럼 창이 스크롤한다. 좁은 창(900px 이하)은 숨는 열과 같이 숨긴다.
