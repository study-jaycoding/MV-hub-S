# 폴더 트리 기본 테마 — ▸/▾ 칸을 빼고 폴더 아이콘이 펴고 접는다 (2026-11-06)

Jay 11-06: "사이드 필터 아이콘앞에 접기 부분을 폴더 아이콘으로 대신하고 폴더 연결구조 보여주는 선은 v1테마선이 적용된 시안" → 시안(아이콘 + v1 선) → "시안에서 앞에 선빼고 보여줘" → H1(선 모두 뺌)·H2(연결선만) → 동작 확인 질문("선 모두 빼고 폴더를 누르면 접기누른것 처럼 열리고 접히고 글씨부분은 더블클릭으로 접히고 열리는건가?") → "진행". 시안 그림: 세션 스크래치 `tree_mock\시안H_폴더트리_선빼기.png`(앱의 실제 FolderTreeView + 빌드 CSS).

바꾸는 것(필터 테마 '기본'만 — v1 은 그대로):

- 줄 앞 ▸/▾ 칸(`.folder-tree-caret`)을 없애고 그 자리에 폴더 아이콘을 담은 칸(`.folder-tree-fold`)을 둔다. 하위 있는 폴더는 이 칸을 누르면 펴고 접는다(고르지 않음 — 옛 ▸/▾ 와 같음, 설명 '접기'·'펴기', 마우스를 올리면 둥근 밝은 판). 하위 없는 폴더·펴고 접기가 없는 트리는 아이콘을 눌러도 줄처럼 그 폴더를 고른다.
- 줄 글씨 한 번 누름 = 고르기, 더블클릭 = 펴고 접기(11-04 A안), → / ← = 펴기 / 접기 — 그대로.
- 선은 넣지 않는다(H1) — 펼친 폴더 아래 세로선·고른 줄 연결선 없음(지금 기본 테마와 같음).
- 자리: 들여쓰기 8+깊이×10(v1 과 같은 자리) · 아이콘 칸 14px · 이름과 간격 8px · 고른 줄 색 바탕은 아이콘 4px 앞에서. 아이콘 색·열린 폴더·회색 규칙(③·B안)은 그대로, 대상만 `.folder-tree-fold > .folder-tree-icon`.
- 옛 화살표 색(펼침 라임·고른 줄을 품고 접히면 그 색)은 화살표와 함께 없어진다. 접혀도 고른 줄을 품은 위 폴더의 아이콘이 색으로 남는 규칙(B안 `.anc`)은 그대로다.
- 설정 필터 테마 목록의 '기본' 설명 "화살표 + 폴더 아이콘" → "폴더 아이콘"(영어 "Folder icons").

시험: 기본 테마 시험을 새 모양으로(▸/▾ 대신 `.folder-tree-fold`, 들여쓰기 8/18px, 아이콘 누름 = 펴고 접기·하위 없는 줄은 고르기, 아이콘 규칙 선택자) · 옛 '화살표 색' 시험은 화살표와 함께 뺌(접힌 위 폴더 아이콘 색은 B안 시험이 지킨다) · 편집 탭·Resolve 라이브러리 시험은 펴고 접는 자리를 `.folder-tree-fold` 로.
