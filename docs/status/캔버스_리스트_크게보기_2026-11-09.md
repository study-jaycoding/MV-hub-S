- 시안 A(격자 창)·B(가로 줄) 중 **A 격자 창**: 화면 가운데 창, 칸 4열, 칸마다 번호 알약(노드와 같은 색 — 이미지 파랑·영상 라임·오디오 보라)과 여러 장 레퍼런스의 "N장". 칸을 끌어 순서를 바꾸면 노드에 바로 반영. 끄는 중 = 원래 자리 흐림 + 놓을 자리 세로 막대.

## 내가 정한 것 (Jay 미확인 — 시안에 넣어 보였고 Jay 는 A 만 골랐다)

- 막대·테두리 색 = 리스트 색(`--lc`, 레퍼런스 파랑 등). 칸 더블클릭 = 크게 보기(레퍼런스 카드와 같은 동작). 칸을 고르고 **Ctrl**+←/→(텍스트 줄은 ↑/↓도) = 한 칸씩 — 시안엔 Alt 로 적었으나 앱 규칙상 Alt+←/→ 는 브라우저 뒤로/앞으로라(`ThumbnailGrid`·`FolderCardGrid` 등 같은 주석) Ctrl 로 바꿨다.
- 생성물·텍스트 리스트도 같은 창(생성물 = 같은 격자, 텍스트 = 큰 줄 목록). 비었거나 섞인 리스트는 더블클릭해도 열지 않는다.
- 노드 안 썸네일·행을 누르는 기존 동작(행 미리보기·결과 수·복사 단추·연결점·크기 손잡이)에서 시작한 더블클릭은 창을 열지 않는다.
- 새 파일을 만들지 않고 창을 `ListCard.tsx` 에 둔다 — 같은 노드의 본문과 도우미(종류 색·오디오 칸·썸네일)를 같이 쓰고, 다른 세션이 올려 둔 `docs/CODE_MAP.md` 와 겹치지 않게.
