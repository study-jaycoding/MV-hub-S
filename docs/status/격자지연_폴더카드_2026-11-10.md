# 어셋 폴더 카드 격자 — 화면 밖 카드는 그리지 않기 (2026-11-10)

owner: Claude(실측·구현) · reviewer: 묶음 검토 때(Jay '검토') · status: 구현 중 · touched_paths: 아래 계약 · updated: 2026-11-10
위 속성의 `active`는 이 작업의 진행 기록이라는 문서 위상이며, 구현 완료·검토 완료·배포 승인을 뜻하지 않는다.

## 근거 (격리 실측, 4배 CPU, 하위 폴더 300개 × 그림 3장 가짜 폴더)

- 지금: 300장을 전부 그린다(요소 약 6,400·그림 1,200). 열 때 가장 긴 멈춤 1.0~1.3초(마운트 직후 첫 레이아웃 읽기가 요소 8,500개를 한 번에 계산, 217~254ms + 스타일 7,200개 114~120ms), 스크롤 60걸음 끊긴 프레임 78~84.
- 실측 페이지에서만 `content-visibility: auto`(자리 높이 300px 고정)를 넣은 실험: 열 때 가장 긴 긴 프레임 0.32~0.34초 · 스크롤 끊긴 프레임 3~32.

## 설계

- CSS: `.assets-folder-grid > .assets-folder-card` 에 `content-visibility: auto` — 화면에서 먼 카드는 스타일·레이아웃·그리기를 건너뛴다(DOM 은 그대로라 선택·방향키·끌기·`querySelector` 는 그대로). 자리 높이 = `contain-intrinsic-block-size: var(--folder-card-h, 320px)`.
  - `auto`(브라우저가 마지막 높이를 기억)는 쓰지 않는다 — 격자 key 가 크기 슬라이더에 묶이지 않아, 크기를 바꾸면 화면 밖 카드에 옛 높이가 남아 스크롤 막대가 틀린다.
  - 고른 카드(`.sel`)는 늘 그린다 — 바깥 그림자 테두리가 잘리지 않게(생성 카드 `.gen-cell:has(> .card.selected)` 와 같은 이유).
- 격자(`AssetFolderGrid`): 지금 그려진(건너뛰지 않은) 카드 하나의 높이를 재서 `--folder-card-h` 로 준다. 크기·보기·맞춤·목록이 바뀔 때와 격자 폭이 바뀔 때(ResizeObserver) 다시 잰다. 표 보기(`AssetFolderTable`)는 카드가 없어 아무 일도 안 한다.
- 남는 차이: 띠가 없는 폴더처럼 높이가 다른 카드는 화면 밖에 있을 때 잰 높이로 자리를 잡으므로, 처음 지나갈 때 스크롤 막대 길이가 조금 바뀔 수 있다(브라우저 스크롤 고정이 보던 자리는 지킨다).
