## 결정 (Codex 동의 — Jay 결정 대기)

- **카드마다 canvas(a)는 하지 않는다.** 그림판을 한다면 보드 한 장(b)뿐이다.
- **먼저 '멀리 볼 때 가벼운 몸통'(DOM)을 만든다.** 이 PC 목표(축소 0~2)와 CPU 4배 축소 '절반 이하'를 같은 사본에서 거의 맞췄다. 보드 한 장 그림판(b)은 상한이 '몸통 없음'이지만 그리기 비용을
  재지 않았고 겹침(예외 카드 가림)·여유 영역·해상도·그림 보관·메모리로 일이 크다 — **가벼운 몸통을 팀 PC 에서 써 보고 부족하면 다음 단계**로.
- 지금 자료에는 (b)로 바로 갈 성능 근거가 없다. 다만 Jay 의 "그림판 필수"를 자동 철회한 것으로 다루지 않는다 — **단계 변경(가벼운 몸통 먼저 → 필요하면 보드 그림판)은 Jay 가 정한다**(Codex).
- 느린 PC 의 남는 몫(카드 0장에도 ~1.3초)은 별도 과제 — 원인 분리부터.

## 가벼운 몸통의 계약 (구현 전 설계 — 초안 v1 에 대한 Codex 지적 10개 반영)

- **구조는 그대로, 무거운 것만 바꾼다.** 몸통 컴포넌트·포트·크기 손잡이·이름표·상태 표시·`.linb-node` 껍데기(선택·glow·최종·흐림 class — 범위 선택 미리보기가 직접 바꾼다,
  `SceneBoard.tsx` 1043·`scene.css` 1242)는 남긴다. 감싸개 div 를 새로 끼워 틀 직속 자식 CSS 를 바꾸지 않는다.
- 그림: `MediaThumbnail` 의 멀리 볼 때 길을 가볍게 — **상태 처리는 없애지 않고 줄인다**(서버 누락·판정 보류, 썸네일 실패 → 원본 대체 → 최종 실패 구분).
  포스터 없는 영상·오디오는 지금 몸통 그대로.
- 히스토리 노드의 마우스 올림 덮개(`.linb-ov`)를 뺀다면 그 안의 코멘트·공유 단추로 가는 **Tab 경로를 먼저 보장**한다(남기거나, 키보드로 원래 몸통에 들어가는 길).
- 상태 표: shared/held/final·사용자 색·unshared·폴더 필터 흐림·sConfirm 중 흐림·코멘트 수와 읽지 않음 구분·'이 PC 에만'·빨간 빗금 — 판정은 기존 함수
  (`matchesBoardFilters`·`inBoardFolder`·공유·최종 판정 등)를 그대로 부르고, 컴포넌트 안에만 있는 필수 판정은 작은 함수로 뽑아 같이 쓴다.
- 모드: 툴바 % ≤30 '가벼운 영역', ≥36 '지금 몸통 영역'(사이는 직전 유지). **카드마다 실제로 붙은 모드를 유지**하고 쉴 때만 한꺼번에 바꾼다.
  제스처 도중 새로 붙는 카드는 그때의 영역을 따른다(처음 줄일 때도 들어오는 카드가 무거운 몸통으로 붙지 않게). 생성 완료는 내용 갱신이지 모드 재선정이 아니다.
  씬 전환·삭제·컬링 뒤 재진입을 구분하고, 직전 집합·모드는 렌더 중 공유 ref 가 아니라 커밋된 결과로 관리한다.
- 쉼 계약: 지금 150ms 정리(`useSceneViewport.ts` 143·184)는 줌 갱신을 건너뛴 때만 걸리고 컬링 집합이 같으면 끝난다 — **컬링과 독립된 '입력 끝·카메라 전환(F 250ms) 끝' 알림**을 새로 둔다.
- 예외(지금 몸통): 마우스 올림·포커스·편집·끄는 중·Comfy 대기·높이 낡음·안을 스크롤한 카드·태그 편집/확인 창이 열린 카드·영상 재생. 바꿔 끼울 때
  안쪽 스크롤·영상 재생·열린 편집 창이 초기화되지 않고, 첫 클릭·휠클릭·첫 휠 스크롤이 보존되는지 확인한다.
- 높이: 캐시는 '있음'이 아니라 '지금 내용에 유효함'(같은 개수의 다른 그림으로 바꿈도 낡음, `structSig` 는 개수만 본다 — 1104). 낡으면 지금 몸통으로 재고 바꾼다.
  가벼운 몸통일 때 잰 값을 다시 캐시에 쓰는 순환을 막는다.
