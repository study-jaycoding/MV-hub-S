# 머리줄 — 알림 종을 아이콘 알약(편집·Assets·관리)의 끝 칸으로 — 2026-10-26 (Jay 지시)

Jay(머리줄 그림): "여기 알림도 알약에 넣어도 되나?" → 오전 머리줄 아이콘 작업([머리줄_아이콘단추_2026-10-26.md](머리줄_아이콘단추_2026-10-26.md))에서
알림은 범위에서 뺐을 뿐 기각한 적 없음. 시안(앱 CSS·아이콘 코드로 그림): 지금 · B 알약 끝 칸 + 배지 걸침 · C 알약 끝 칸 + 배지 안쪽, 열림 = 금색 투톤 종 →
Jay: "B안(알약 끝 칸 + 배지 걸침, 열림 = 금색 투톤 종)으로 알림 종을 알약에 넣어라".

한 것: `TopIcon`·`Grad` 를 `TopIcon.tsx` 로 옮김(내용 그대로) · `NotificationCenter` 가 캡슐(`.top-ic-group`) 안 끝에 그려지고 종 단추 = `top-ic-btn notification-bell`(열림 = `.lit`,
옛 `.on` 바탕 칠하기 없앰) · `BellIcon`(선 = 옛 종 그림 · 투톤 = 금색 앞면 + 꼭지·추 뒤판색) · CSS: 옛 종 모양 규칙(36px 투명 동그라미·회색·19px 선) 지우고
`.notification-bell` 은 배지 기준(position)만 · 종은 `.notification-center` 안 하나뿐인 단추라 캡슐의 `:first/:last/:only-child` 가 다 걸려 끝 칸 모양으로 덮음.
그림 가운데: getBBox 로 잰 선 11.5·투톤 11.8 → 옮김값으로 12 · 실제 CSS 칸 4배 캡처로 잉크 치우침 x 0 y 0(그림 칸 36 기준 — 끝 칸 37 은 바깥 테두리 1 포함, 다른 끝 칸과 같음).
시험: `topBarIconButtons`(캡슐 순서 = 셋 + 알림 · 종도 선·투톤 · 그라데이션 id 넷 모두 다름 · 관리·편집 없으면 Assets + 종 · 종을 누르면 종만 켜지고 다시 누르면 꺼짐) ·
알림 시험 둘 · tsc -b · lint:architecture. 실제 앱 창에서는 아직 안 봄(Jay 5173 핫 리로드로 확인).
