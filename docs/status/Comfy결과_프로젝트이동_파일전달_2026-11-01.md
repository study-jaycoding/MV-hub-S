## 실측

위임을 켠 격리 허브 + 격리 서버 + 실제 ComfyUI. 다른 사람은 서버에 직접 로그인해 파일을 받아 봤다.

| 조작 | 고치기 전 | 고친 뒤 |
|---|---|---|
| 프로젝트를 고르고 만들어 공유(대조) | 200 | 200 |
| 프로젝트 없이 만들어 옮긴 뒤 공유 | 404 | 200 |
| 공유한 뒤 프로젝트로 옮김 | 재지 않음 | 200 |
| 프로젝트 A 에서 B 로 옮겨 공유 | 재지 않음 | 200 |
| `#+` 로 프로젝트가 정해진 뒤 공유 | 재지 않음 | 200 |

고친 줄 14곳을 되돌려 시험이 잡는지 봤다. 13곳을 잡고, 남은 1곳(미분류도 호출)은 `project_id` 가 NOT NULL 이라 `INSERT OR IGNORE` 가 무시해 결과가 같은 등가 변이다. 첫 번째 돌림에서 `#+` keep 이 빠져 시험을 보강했다.

- 프로젝트 없이 공유한 결과는 그대로 서버에 파일이 없다. 다른 사람에게는 프로젝트 소속이 없어 보이지 않고 전체 열람 권한자만 본다(Codex 코드 확인, 재현 안 함).
- 고치기 전에 옮긴 결과는 다시 옮기면 이어진다. 일괄 보정은 하지 않았다.
- 업로드가 끝나기 전에는 다른 PC 에서 잠깐 404 일 수 있다(Claude 합의자 코드 확인).
