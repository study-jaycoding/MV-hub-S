# 설정 창 — 묶음은 밑으로 펼치고, 자료 관리·DaVinci·MCP 를 단순하게 (2026-11-16)

owner: Claude · status: 완료(dev 커밋 — 묶음 리뷰 전) · touched_paths: 아래 계약 · updated: 2026-11-16

> 앞 판: [같은 창에서 목록, 항목은 옆 창](설정창_목록과옆창_2026-11-16.md)(dev bbef2732). Jay 가 시안 v3(`mvhub_settings_final_v3`)를 보고 "시안대로 수정진행"(2026-11-16).

## Jay 요청(시안 v3)

- 처음 창에서 [기본 설정]·[외부 프로그램]을 누르면 **그 밑으로** 항목이 펼쳐지고, 항목을 누르면 옆 창(같은 창이 목록으로 바뀌던 앞 판을 바꿈).
- '리졸브 안 MV 창' 이름 → **MV Resolve**.
- 자료 관리를 단순하게: 숫자 요약(백업·복원 보류·전송 대기) + 주 단추 둘, 복원 보류는 경고 상자, '파일로 주고받기'·'생성물 점검', 나머지는 '백업 자동 설정 · 고급' 접기.
- 'MV 업데이트' 제목 없애고 단추 하나 **MV Hub Update** — 새 버전이 있으면 라임, 없으면 회색.
- DaVinci Resolve: 맨 위 연결 상태 상자, 그 밑 설치 목록(MV Resolve · Script — 각 상태와 [다시 설치]), 실시간 체크는 스위치.
- MV·MCP 연결: [한 번에 연결] 하나 + 앱마다(Codex·Claude Code·Claude 데스크톱 채팅) 상태와 작은 [해제]/[다시 연결]. MV Agent 칸은 이 연결과 별개라고 적는다.

## 확인한 것

- 백엔드 API 는 이미 있다 — 여러 앱 한 번에 등록 `POST /api/mcp/v2/app/configure`, 목록 `GET /app/clients`, 해제 `POST /app/clients/{id}/revoke`(`backend/app/routers/mcp_v2.py:335-357`). 데스크톱 앱이 없거나 켜져 있으면 백엔드가 `skipped` + 이유 문구를 돌려준다(`tools/mcp_adapter/local_setup.py:303-306`). → 백엔드는 고치지 않는다.
- 기존 MCP 창(`McpConnection`)은 옛 6자리 연결·계획 실행·MCP 업데이트·캔버스 대기 작업도 맡는다 → 그대로 두고, 설정 옆 창의 '고급'에 [MV·MCP 연결 열기]를 남긴다.
- 바꾸는 칸(BackupSection·MetadataContinuitySection·DbFileTransfer·AssetTransferLine·ResolveScriptSettingsSection·ReleaseUpdateSettingsSection)은 SettingsPanel 에서만 쓰인다(grep).

## 구현·검증

- 묶음 줄(`SettingsGroup`) = 펼침(aria-expanded·hidden 상자). 안 항목은 접혀 있어도 붙여 두고, 묶음을 접으면 그 안 옆 창을 닫는다(`SettingsGroupOpen` 문맥 → `SettingsFold`). 앞 판의 같은 창 목록 화면·‹ 뒤로는 뺐다.
- 자료 관리 = `BackupSection` 이 뼈대: 숫자 칸(백업·복원 보류·전송 대기) → 상태 한 줄 → [지금 백업][서버 백업 가져오기] → 복원 보류 경고 상자(긴 설명·되살리기 단추는 [자세히])·파일로 주고받기·생성물 점검([재점검][HF 생성물][HF 삭제물]) → '백업 자동 설정 · 고급'(보관 설정·서버 백업 고르기·DB 파일·과거 생성물). 단추·동작은 그대로 옮겼다. 전송 줄은 대기만 있으면 숫자 칸에 맡기고, 실패·확인 필요가 있을 때만 [다시 시도]와 함께 보인다.
- DaVinci = 연결 상자(연결됨·프로젝트·프로그램 + [다시 확인](연결만, 새 `recheckResolveConnection`)·[Resolve 진단]) → 설치 목록(MV Resolve · Script, 상태 알약·[다시 설치]/[설치], 상태별 자세한 문구는 그대로) → 실시간 체크 스위치(체크 상자에 role=switch — 시험·보조기기 그대로) → '설치 경로 · 진단 상세' 접기. 이름 '리졸브 안 MV 창' → MV Resolve.
- MV Hub Update = 제목 없이 넓은 단추, 새 버전이면 라임 `MV Hub Update · 판`, 아니면 회색. 버전 줄 '새 버전 X · 지금 Y' / '최신 버전입니다 · Y'(서버 문구와 겹치면 한 줄).
- MV·MCP 연결 = 새 `McpQuickConnect`(기존 API 그대로): 앱 세 줄(Codex·Claude Code·Claude 데스크톱 채팅) 상태 알약 + [해제]/[연결]/[다시 연결](건너뛴 까닭은 백엔드 문구), [한 번에 연결](세 앱·계정 기준·생성 허용), 고급에 [MV·MCP 연결 열기](옛 창).
- Jay 추가 요청(작업 중): 설정·내 계정 창이 창 오른쪽 끝(CSS 고정 `top:56px; right:14px`)에 떠서 아바타와 떨어져 보였다 → `AccountMenu` 가 메뉴 자리 재기(아바타 바로 밑)를 두 창이 열린 동안에도 하고 `anchor` 로 넘김(`SettingsPanel`·`ManageAccount`).
