# 캔버스 — '생성 결과' 창 Draft 메뉴가 안 눌림 · 텍스트 편집칸 알약을 누르면 편집이 끝남

owner: claude · reviewer: (Jay 지시 때) · status: 구현 중 · touched_paths: frontend/src/components/scene/SceneBoard.tsx, frontend/tests/sceneVariantWindow.test.tsx, frontend/tests/canvasBoardPressFocus.test.tsx

## 증상 (Jay, 11-18 dev)

1. 캔버스 카드의 '생성 결과' 창에서 Draft 를 골라 [Draft 1080p] → 메뉴의 [1080p로 생성](또는 4K)을 누르면 메뉴만 닫히고 아무 일도 없다. 라이브러리(워크스페이스)에서는 된다.
2. 텍스트 카드 편집칸에서 알약(@image1)을 누르면 글자로 풀려 번호를 고칠 수 있어야 하는데, 편집이 끝나 선택이 풀린 것처럼 된다.

## 원인 (확인한 것)

둘 다 보드의 누름 처리 `SceneBoard.tsx` `onBoardMouseDownCapture` 다.

- 1: Draft 메뉴는 `document.body` 에 그린다(`SelectionActionBar.tsx` `DraftFinishPicker`, 포털). 포털의 누름도 React 트리를 따라 보드의 잡는 단계 처리를 지난다. 보드가 초점을 가져가면 메뉴가 '초점 잃음'(`useOutsideMouseDown` 의 `closeOnFocusOut`)으로 닫혀 누른 단추가 클릭 전에 사라진다.
  - 격리 허브(빈 DB·CLI 없음) 실측: 누르는 순간 메뉴가 사라지고 초점이 BODY, 요청 0건. 보드의 `focus()` 만 막고 다시 누르면 메뉴가 남고 클릭이 실행되어 카드 결과 수가 ▤2 → ▤3.
  - dev 로그: 그 시간대에 Draft 완성 요청(regenerate)이 한 건도 없었다.
- 2: 편집칸 알약은 `contentEditable=false`(`textNodeTokens.ts` `buildTextTokenPill`)라 `isSceneTextEntryTarget` 가 글 칸으로 보지 않는다. 그래서 보드가 편집칸을 `blur()` 하고, 편집칸 `onBlur` 가 편집을 끝낸다(코드 읽기 + 아래 시험).

## 고침

`onBoardMouseDownCapture` 두 줄.

- 초점이 있는 글 칸이 누른 곳을 품고 있으면(편집칸 안의 알약) 아무것도 하지 않는다.
- 누른 곳이 보드 DOM 밖(포털)이면 보드로 초점을 가져오지 않는다.

  - `frontend/tests/sceneVariantWindow.test.tsx` 마지막 시험 — 실제 `SceneBoard` + '생성 결과' 창.
  - `frontend/tests/canvasBoardPressFocus.test.tsx` — 실제 `SceneBoard` 의 레퍼런스→텍스트 카드. jsdom 에 없는 `isContentEditable` 은 그 시험 안에서만 브라우저 규칙대로 채운다.
