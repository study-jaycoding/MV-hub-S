# 폴더에서 뒤로 오면 들어갔던 카드가 골라져 있게 — 2026-10-30 (Jay 요청)

owner: Claude(세션 c3e522cc) · reviewer: 없음(작은 화면 수정 — 묶음 검토 때) · status: 완료(dev `84d96b96`, 미푸시 — Jay 5173 확인 남음) · touched_paths: 아래 계약 · updated: 2026-10-30

Jay: "어셋에서 예를 들어 매튜 안으로 들어갔다가 백스페이스로 다시 이미지 화면으로 돌아왔다. 그러면 전에 선택한 매튜에 선택이 남아 있어야 하는데 지금은 선택이 남아 있지 않다. 뒤로 갔을 때 선택이 남아 있게 수정하자. 어셋 탭과 워크스페이스·공유 탭에서도 똑같아야 한다."

## 지금 동작(코드 확인)

| 탭 | 들어감 | 뒤로 | 선택이 사라지는 곳 |
|---|---|---|---|
| 어셋 | 폴더 카드 두 번 클릭·Enter → `enterFolder` | Backspace → 위 폴더 | `AssetFolderGrid` 는 `key=project\|dir` 라 폴더마다 새로 서고 `selected` 는 그 안의 상태 |
| 공유 & 리뷰 | 에피소드 카드 두 번 클릭 → `enterFolderCard`, 컷은 사이드바 | Backspace · 브라우저 뒤로 | `App.tsx` 의 `cutScopeKey` 가 바뀌면 `cutSel` 을 비운다(Backspace 처리도 직접 비운다) |
| 워크스페이스 | 사이드바 | Backspace | **폴더 카드가 없는 화면이다** — `cardsScope` 가 `filters.tab !== "team"` 이면 null 이라 낱장 격자뿐. 고를 폴더 카드가 없어 해당 없음 |

어셋의 폴더 경로는 브라우저 기록에 없다 — 어셋 탭의 뒤로는 Backspace 하나다.

## 고친 것

- 규칙 하나: **뒤로 오면 지나온 폴더 카드를 고르고 보이게 한다.** 어디까지가 '지나온 폴더'인지는 `lib/folderCards` 의 `passedFolder(from, to)`.
- 어셋: Backspace 가 `backTo` 를 적고 `AssetFolderGrid` 가 `initialSelected` 로 고른 채 선다. 스크롤 복원이 뒤에 돌아 먼저 보이게 하면 덮이므로 복원 효과 안에서 복원 뒤에 보이게 한 다음 비운다. 코멘트 확인을 취소하면 `enterFolder` 가 false 라 적지 않는다.
- 공유: Backspace 와 브라우저 뒤로·앞으로(`restoreLocation` 의 adopt)가 `cutBackRef` 에 적고, `cutScopeKey` 가 그 자리로 바뀌는 효과에서 `cutSel` 을 채운다. 묶음 응답이 늦으면 key 가 null 을 거치므로 맞는 자리가 설 때까지 들고 있는다.
- 방향키·Shift 의 출발은 새로 만들지 않았다 — `FolderCardGrid` 는 이미 '고른 것 중 마지막 카드', `AssetFolderGrid` 는 이미 `selected` 에서 출발한다.

## 남은 것

- **워크스페이스 탭은 바뀌지 않는다.** 폴더 카드 화면 자체가 없다(위 표). 낱장 생성 카드의 선택을 뒤로 왔을 때 되살리는 것은 이번 요청의 규칙과 다른 일이라 넣지 않았다.
- 어셋에서 위 폴더가 '전체' 보기(파일 격자)면 폴더 카드가 없어 고를 것이 없다.
