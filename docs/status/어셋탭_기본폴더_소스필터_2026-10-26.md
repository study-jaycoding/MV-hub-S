# 어셋 탭 — S(소스만 보기)를 눌러도 보던 폴더에 머물고, 기본 자리는 assets 폴더 — 2026-10-26 (Jay 지시)

owner: Claude · reviewer: (Jay 가 검토를 지시할 때 묶음으로) · status: 완료(dev 커밋 · Jay 화면 확인 남음) · touched_paths: 아래 계약 · updated: 2026-10-26

Jay(그림 1 = S 를 누른 뒤 프로젝트 맨 위 '뻘뻘뻘' · 그림 2 = assets 폴더): "어셋탭에서 소스로 등록된것만 보기 버튼을 누르면 이미지1처럼 정보가 나온다.
기본적으로 내가 봤던 폴더가 보여야한다. 그리고 기본적으로 이미지2처럼 assets폴더가 보여야한다. 그위에 폴더들은 내가 일부러 뻘뻘뻘이라는 프로젝트를 눌러야지만 보여야한다."

원인(코드 확인): `AssetsView` 의 S 단추가 켤 때 `setDir("")` — 일부러 맨 위로 보냈다(옛 주석 "프로젝트 전체 소스 표시(생성탭 @피커와 동일 범위)").
프로젝트를 바꿀 때도 `setDir("")`(맨 위), 처음 열 때 기억한 폴더가 없을 때도 맨 위. 숨긴 폴더(@davinci 안 등)를 기억하고 있었을 때의 되돌림도 맨 위.

한 것: S = `setSourceOnly` 만(폴더 그대로) · `wantDefaultDir` ref(처음 기억 dir 없음 · 프로젝트 바꿈 · 숨긴 폴더 되돌림[@davinci 밖])가 켜져 있으면 그 프로젝트 트리가 왔을 때
dir 이 비어 있는 동안 한 번 맨 위의 'assets'(대소문자 무시) 폴더로 · 없으면 맨 위 그대로 · 트리 머리·Backspace·탭으로 간 맨 위는 손대지 않음.
재현: 새 시험 둘(S 를 누르면 '' · 기억 없이 열면 '')이 고치기 전 실패 → 고친 뒤 통과. 시험: `assetFolderTabs`(S 켜고 꺼도 폴더 그대로 · 기억 없이 열면 assets ·
트리 머리 누르면 맨 위에 머묾·그때 S 도 그대로 · 프로젝트 바꾸면 assets · assets 깊이로 등록된 프로젝트는 맨 위 · 기존 Backspace 맨 위 그대로) · `assetFolderTable` · tsc -b · lint:architecture.
달라지는 점(Jay 에게 알림): S 는 이제 보던 폴더 안의 소스만 — 프로젝트 전체 소스는 맨 위(프로젝트 이름)를 누르고 S.
