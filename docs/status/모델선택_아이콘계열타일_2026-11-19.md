# 모델 선택 창 — 계열 아이콘 타일 + 줄 아이콘 (2026-11-19)

## 요청

Jay 11-19: 생성 창 [Model] 선택 목록을 힉스필드 아이콘으로 꾸민다. 아이콘은 기본 흰색, 고른 것은 라임.
같은 계열(Nano Banana·GPT Image·Seedance)은 위 줄의 큰 아이콘 타일로 묶고(글씨·점 없음), 타일을 누르면 그 계열 모델이 아래에 나온다(C안).
이미지·영상 둘 다. 시안: 대화의 `model_icon_mockup_C.html`·`model_icon_mockup_video_C.html`.

## 정한 것 (Jay 답)

- 처음엔 선택창만(모델 그대로)이었으나 같은 날 Jay 가 추가를 지시: 이미지 목록에 GPT Image 2.6·2.6 Flare, Seedream 5.5·5.0 Pro·5.0 Flash·5.0 Lite 를 더했다(Pro 는 Jay 가 '권장대로' — 정책 면제 유지, 결정 참조). 영상 목록은 그대로.
- 위쪽 계열 타일은 40px(아이콘 20px)로 작게.
- GIF 크기(11-19 Jay 1-A안): GPT 2.6(·Flare)에서 output_format=gif 면 해상도 칸이 "288×288 🔒" 잠긴 칸으로 바뀐다(`isGifFixedSize`). 옵션값 resolution 은 그대로라 png 로 돌아오면 원래 칸. **SVG+참조 막기(Jay A안, 11-19 구현)**: 프롬프트 창(펼친·접힌 모두) 바로 위에 띠 `SvgReferenceBand`(메시지 + [png 로 바꾸기] — 출력 형식만 png 로, 참조는 안 건드림), Generate 잠금(툴팁에 이유), 참조가 있으면 Set 창에서 svg 잠금. 판정 = `isSvgWithReferences`(GPT 2.6·Flare, output_format=svg, 이미지 참조 ≥1 — 트레이+프롬프트 안 칩). 제출 가드(`modelBlockedMessage`)에도 같은 문구가 걸려 단축키로도 못 보낸다. **캔버스(Jay 11-19 구현)**: 모델 노드에 'SVG + 참조 불가' 알약(`svgReferenceConflicts` — svg 인 노드만 계산·제출과 같은 함수로 참조 수), 모델 창에 띠([png 로 바꾸기])·저장 잠금·Set 창 svg 잠금(`svgRefCount` = 그 노드가 먹이는 생성카드의 이미지 참조 최대 수), 렌더·생성 제출(`submitGenJobs`)에서 그 카드를 건너뛰고 이유를 알림(유료 제출 전 거름). 판정은 가벼운 `lib/svgReference.ts` 로 뺐다(씬 보드가 무거운 useModels 를 끌어오지 않게). 캔버스에서 프롬프트 창이 열려 있으면 위 띠도 뜬다. **미구현: 창이 없는 화면의 위쪽 알림(문구만 있는 시안 ③) · 모델 노드 없이 하단 프롬프트 모델을 폴백으로 쓰는 카드는 노드 알약이 없다(그때는 프롬프트 창 띠·제출 가드가 막는다).**
- 오디오 선택창(11-19 Jay A안): 설명을 이름 아래 한 줄로, 목록 너비 330px 고정(가장 긴 설명이 겨우 들어가는 값 — 계열 타일을 바꿔도 안 흔들림)·줄 오른쪽 여백 12px. 앱의 실제 CSS 로 정적 화면을 만들어 눈으로 확인(5173 은 로그인이 필요해 못 열었다).
- R&D 3차 실측(11-19): GPT 2.6 **jpeg+transparent 는 사유 없이 실패**(webp·gif+transparent 는 정상) → jpeg 일 때 background 의 transparent 를 막음(`MODEL_CONSTRAINTS`). **svg+참조 이미지는 CLI 가 "SVG output is only supported without reference images" 로 거절**(오류는 화면에 뜸 — 앱이 참조 유무를 몰라 미리 막지는 못함). GIF frame_count 1~32·frame_duration_ms 50~10000 모두 견적 통과, png 인데 frame_count 를 주면 거절(→ GIF 일 때만 보이게 한 게이트가 맞음).
- R&D 제이/101 2차 실측(11-19, 견적 합 약 114크레딧): ① 영상 7종 기본 생성(앱 기본값) — 6개 정상, **MiniMax H3(2K·4초) 1건 힉스필드 쪽에서 실패(사유 없음, 재시도 안 함)** ② 이미지 미시험 옵션 35건 전부 정상 — 품질 단계(GPT 2.6 medium·high·xhigh·max·auto)·해상도 2k/4k(4k=2880)·비율 16:9·21:9·auto·투명 배경(PNG 알파 채널 확인)·jpeg/webp·참조 1·2장·auto+참조·Seedream 해상도 1.5k/2k·Lite high 모두 완료.
- R&D 제이/101 실측(11-19, 모델별 1장씩 + SVG·GIF + 참조 + 크기·배경제거 · 견적 합 약 15크레딧): 기본 생성·참조 이미지 6개 모두 정상, GPT 2.6 SVG·GIF 정상(GIF 는 해상도와 무관하게 288×288). 문제: Seedream 5.0 Pro width·height 지정은 **실패**, Flash 는 **무시**됨, Pro remove_bg=true 는 전송돼도 **배경이 안 지워짐** → 이 칸들을 해당 모델에서 숨긴다(`MODEL_HIDDEN_PARAMS`). GPT 2.6 frame_*는 gif 일 때만(`PARAM_GATES`), size 는 미확인이라 숨김.
- Seedance 아이콘은 폴더(`higgsfield-model-icons`)에 없다 → **Seedream 아이콘 임시 사용**(같은 ByteDance 계열). 진짜 아이콘을 구하면 `ModelFamilyIcon.tsx` 한 곳만 바꾼다.
- 아이콘은 이미지 모델용만 받았다(README). 쓰는 것: Nano Banana(구글 G)·GPT Image(OpenAI)·Seedream 모양 3종.

## 동작

- 이미지·영상 목록에서만(오디오 목록은 그대로). 계열이 2개 이상일 때 위에 아이콘 타일 줄이 생긴다. 계열이 1개(영상은 지금 Seedance 뿐)면 타일 없이 줄 아이콘만.
- 타일을 누르면 그 계열 줄만 보인다. 처음엔 지금 고른 모델의 계열.
- 줄 앞의 체크 칸(`::before`) 대신 아이콘. 고른 줄과 보고 있는 타일은 라임.
- 모델 칩의 초록 점 자리에 고른 모델의 아이콘(계열 없는 모델은 점 그대로).
- 모델 선택 동작·변형(Seedance 2.0 Fast)·막힌 모델 표시는 그대로.
