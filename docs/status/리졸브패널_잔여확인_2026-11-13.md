## 실제 확인 절차 — 아직 실행하지 않음

현재 열린 프로젝트를 바꾸거나 패널을 임의로 열지 않는다. 사용자가 정한 독립 시험용 Resolve 프로젝트와 NAS 시험 하위 폴더, 허브 연결·실행 소스 버전을 먼저 확인한다. 설치본·실사용 프로젝트에 수정 코드를 반영하거나 프로세스를 재시작하는 것은 이 절차에 포함하지 않는다.

1. 사용자가 시험 프로젝트를 열고, 독립 시험 미디어로 구성한 에피소드/컷·생성자 두 명과 예상 개수를 준비한다. 기존 mv test의 E2/E3/S01·59클립·로컬2파일·시험판 플러그인은 삭제하지 않는다.
2. 최초 열기와 같은 컷 재선택을 나누어 패널 진입→트리 표시→클립 표시 완료 시간을 기록한다. 미리 받음 여부·영상/스틸·개수·조회와 화면 표시를 구분한다. 속도 합격 수치는 아직 정하지 않았으며 측정 전 체감 개선을 보장하지 않는다.
3. 생성자 A/B/해제를 선택해 카드·컷·에피소드·프로젝트 합계를 예상 수와 대조한다. UID가 있는 생성자로 우선 확인하며, 늦은 응답이 선택을 거꾸로 덮는지 본다.
4. 안 쓴 시험 클립의 ID·경로·개수를 기록한 뒤 에피소드 이동·맞추기·재열기를 관찰한다. 이 단계에서 [저장]을 누르지 않는다. 자동 정리와 명시 저장 정리를 구분한다. 사용된 항목은 NAS 전환·저장이 일어날 수 있으므로 이 단계의 쓰기 범위에도 포함한다.
5. [저장]은 기본·진행 단계·성공 시각·3초 복귀를 확인한다. 막힘은 독립 프로젝트의 시험 항목으로만 만들며 실사용 NAS 연결을 끊거나 원본 파일을 바꾸지 않는다. 저장 오류·프로젝트 ID 변경·예상 밖 삭제가 보이면 후속 쓰기를 멈추고 대상·오류를 기록한다.
6. 허용된 시험 항목을 타임라인에 쓰고 NAS 전환 결과의 경로·ID와 저장 성공을 확인한다. 사용자가 해당 시험 프로젝트만 닫고 다시 연 뒤 경로·미디어 온라인 상태·재생을 대조한다. 검증 후 시험 흔적의 삭제는 별도 사용자 결정이며 자동 정리하지 않는다.

## 공통 저장 계층에 전달할 소비 요구

회색 표시 위치는 J2(내 PC 개인 허브), 저장 통합 5단계로 결정됐다. 위치를 다시 묻거나 공통 저장 파일·DB·인증을 이 세션에서 수정하지 않는다. 현재 `useResolvePanel.ts`의 nas Set으로 이번 창의 '쓰임 · NAS' 표시를 만들며, 재열기 뒤 회색의 영속 복원은 기존 총괄의 저장 계층 작업과 연결할 항목이다. NAS Set과 사용자 회색 표시의 영속 계약을 임의로 같은 것으로 확정하지 않는다.
