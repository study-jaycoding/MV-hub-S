# 리졸브 패널 화면 — 다빈치 미디어 풀 모양 (2026-11-11)

owner: Claude(설계·구현, 이 세션) · reviewer: 없음(작은 화면 묶음 — Jay '빠르게 고치고 검토는 지시 때') · status: 검증 중(Jay 화면 확인 남음) · updated: 2026-11-11

결과: 시험 기록 5개 — 패널 화면 49 통과(새 시험 4: 빈 트리·보기 셋/크기/정렬/검색/생성자 거르기·S·T 연결과 C·ⓘ 숨김·15초/초점 갱신과 같은 컷 새 카드만 캐시) · 빌드·경계 검사 통과 · 편집 탭 미디어 풀·패널 API 시험 39 통과 · 코드 지도 빠짐 0.
미확인: 실제 화면 모양(라이브러리 카드를 16:9 칸에 넣은 모습)은 브라우저로 보지 못했다 — 개발 허브는 로그인이 필요하고 격리 허브 준비는 이번에 하지 않음. 시험은 카드 속을 가짜로 바꿔 연결만 본다.

Jay 결정(11-11 저녁): 패널 화면 = **다빈치 미디어 풀 모양**(편집 탭 모양·리졸브 미디어 풀에 전부 미리 넣기는 기각) · 카드 보기 바꾸기(메타데이터·썸네일·목록 + 크기) ·
색·태그·생성자 거르기 · 카드 단추 T(색·태그)·S(공유·보류·최종) — C(코멘트)·ⓘ(정보)는 새 창이라 뺌 · 공유가 늘면 저절로 반영. "화면부터 구현".
바로 끌기(로컬로 넣고 NAS 로 바꿔 끼우기)는 이 묶음 밖 — `ReplaceClip` 실측 뒤 따로.

## 화면

- 왼쪽 = 빈 트리: 프로젝트(펼침) › 폴더(펼침) › 컷. 컷 옆 공유 수·★최종 수, 0 인 컷은 흐리게. 하위가 있는 폴더는 누르면 펼치고, 끝 폴더(컷)를 누르면 그 컷을 고른다(목록 = 그 컷의 공유물, 시퀀스 = 부모 폴더).
  아래 접는 칸 '컬러 · 전역 태그 · 생성자'(편집 탭과 같은 거르기 — `poolFilterPass`·`poolFacets`·`ColorFilterDots`).
- 오른쪽 머리 = 경로(프로젝트 / … / 컷) · 보기 메뉴(메타데이터·썸네일·목록 + 크기 막대, 편집 탭과 같은 범위) · 검색 · 정렬(최신·오래된). 보기·크기·정렬은 이 창 저장소에 기억.
  그 아래 지금처럼 리졸브 빈 상태 줄·다름 줄 [맞추기]·판 불일치·다리 없음 안내.
- 썸네일 보기 = 격자 칸: 편집 탭 카드(`EditCard` → 라이브러리 카드)를 그대로 써서 색 띠·★·보류·태그 표시와 **S·T 단추**가 앱과 같이 동작(앱의 `useGenerationTagActions`·`useGenerationCardActions`, 최종 권한 = `api.myFinalizeRoles`).
  C·ⓘ·끌기 손잡이·덮개 단추는 CSS 로 숨긴다. 칸 아래 이름(작성자 · 모델 길이) · 상태 한 줄.
- 메타데이터 보기 = 썸네일 + 작성자·모델 · 날짜·길이 · 프롬프트 2줄 · 상태 줄(편집 탭 줄 모양). 목록 보기 = 한 줄(색 막대·이름·모델·길이·날짜·상태).
- 세 보기 모두 카드를 누르면 준비(지금과 같음), `dragstart` 는 지금의 끌기(다섯 조건·판 전달)를 그대로 부른다. 글자 끝 "..." 없음.

## 자동 갱신

- 패널이 보이는 동안 15초마다(공유 & 리뷰 탭과 같은 간격)와 창으로 돌아올 때(3초 안 중복은 건너뜀) 지금 시퀀스 목록과 폴더 개수를 다시 읽는다.
- **같은 컷을 다시 읽을 때는 컷 선택(target·순번)을 다시 하지 않는다** — 새로 생긴 카드만 이 PC 캐시로 받는다(`addCards`). 컷이 바뀔 때만 지금처럼 컷 선택(리졸브 지금 빈 맞추기).
  다시 읽는 동안(loading) 목록을 비우거나 선택을 풀지 않는다.
