# MCP 한 번에 연결 — Codex·Claude Code·Claude 데스크톱 채팅 (2026-10-29)

owner: Claude(설계·구현) · reviewer: Codex(사전 검토·독립 리뷰) · status: 검증 중(실사용 확인 대기) · updated: 2026-10-29

  - [Codex·Claude Code 연결 허용] 은 `~/.codex/config.toml`·`~/.claude.json` 만 쓴다(`tools/mcp_adapter/local_setup.py` `configure_client`).
    Claude 데스크톱 채팅 설정 `%APPDATA%\Claude\claude_desktop_config.json` 에는 쓰지 않는다 → 데스크톱 채팅에 mvhub 없음.
  - 이 PC 는 앱이 둘(설치본 8010·dev 8012)이다. 기존 등록이 `mvhub`=설치본, `mvhub-test`=dev 로 손으로 나뉘어 있어
    dev 앱에서 누르면 `mvhub` 이름 충돌 → `_known_entry` 거부 → codex·claude 모두 "수동 등록 필요"(Jay 화면 10-29).

    (설정 파일이 오늘 15:34 에 실제 경로에서 갱신됨, `%LOCALAPPDATA%\Packages\Claude_…\LocalCache\Roaming\Claude` 사본 없음).
  - 데스크톱 설정 파일에만 있는 comfyui·filesystem 이 데스크톱 앱 Code 탭 세션 도구에도 보인다(관측).
    공식 문서(https://code.claude.com/docs/en/desktop 「MCP servers from the Claude Desktop chat app」, 10-29 직접 확인):
    데스크톱 앱은 `claude_desktop_config.json` 의 MCP 를 로컬 Code 탭 세션에도 넣고, **같은 이름이 `~/.claude.json` 에도 있으면
    Code 탭은 한 번만 연결하며 데스크톱 설정 쪽을 쓴다.** 독립 CLI 는 데스크톱 설정을 읽지 않는다.
  - 공식 문서: 데스크톱 설정 파일로 켠 로컬 MCP 에서도 MCP Apps 가 뜬다(https://claude.com/docs/connectors/building/mcp-apps).
    단 이번 범위는 등록만이며 표시 방식은 바꾸지 않는다.

## 설계

1. **이름 규칙(설치본·dev 공존)**: `GET /api/mcp/app/setup` 이 이미 쓰는 판정(`VERSION.txt` 또는 `runtime/python` 존재)을
   `release: bool` 로 함께 돌려준다. `local_setup` 은 `release is True` 면 `mvhub`, 아니면 `mvhub-test` 이름으로
   codex·claude·claude_desktop·other 설정을 만든다. 이 PC 의 기존 손 등록과 이름이 같아, 같은 실행 파일·어댑터인 기존 항목은
   그 자리에서 바뀌고(`_known_entry` 그대로), 다른 것이 그 이름을 쓰고 있으면 지금처럼 수동 등록으로 멈춘다(덮어쓰지 않음).
   팀원 PC(설치본 하나)는 지금과 같은 `mvhub`.
2. **데스크톱 채팅 = 별도 클라이언트 `claude_desktop`**: 큰 단추가 `["codex","claude","claude_desktop"]` 을 보낸다.
   - 경로 `%APPDATA%\Claude\claude_desktop_config.json`. `%APPDATA%` 가 비어 있으면 상대경로로 쓰지 않고 오류
     ("Windows 사용자 저장 폴더를 확인할 수 없습니다."). `%APPDATA%\Claude` 폴더가 없으면(데스크톱 앱 미설치·미실행)
     **프로필을 만들기 전에** `skipped` 를 돌려주고, 백엔드는 새로 발급한 그 연결만 회수해 결과 `skipped`(오류 아님)로 보인다.
     폴더만 있고 파일이 없으면 새 설정 파일을 만든다.
   - 항목은 `{"command","args"}`(데스크톱 형식, `type` 없음), 표시 모드 플래그 없음(native, 지금 기본).
   - 갱신은 `update_claude` 와 같은 방식: JSON 읽기(빈 파일·UTF-8 BOM 허용) → 최상위 객체·`mcpServers` 객체 확인 →
     같은 이름 `_known_entry` 확인 → 그 키만 교체 → 나머지 최상위 키(`preferences` 등)·다른 서버 보존.
     잘못된 JSON·최상위 배열·`mcpServers` 비객체·다른 실행 파일의 같은 이름 항목은 원본을 그대로 두고 `manual`
     (수동 설정용 새 연결은 유지 — 지금 codex·claude 의 manual 과 같다).
     기존 파일이 있을 때만 원본 바이트 사본 `.mvhub-original`(첫 번)·`.mvhub-backup`(매번)을 남긴다.
     교체 직전 비교(`_atomic(..., compare=True)`)는 **그 비교 시점에 발견한 변경만** 보존한다 — 비교와 교체 사이의 외부 쓰기,
     등록 뒤 데스크톱 앱의 덮어쓰기는 막지 못하며 재시작 뒤 실사용으로 확인한다. 등록 잠금은 같은 허브 프로세스 안에서만 직렬화한다.
   - 별도 클라이언트로 둔 이유: 독립 CLI(`~/.claude.json`)와 데스크톱(채팅 + 로컬 Code 탭)의 설정·회수 단위를 나눈다.
     데스크톱 쓰기가 실패해도 이미 성공한 Codex·Claude Code 등록은 그대로다. 다시 등록하면 앞의 `claude_desktop` 만 회수한다.
     공식 문서대로 로컬 Code 탭은 같은 이름의 데스크톱 정의를 쓰므로 **`claude_desktop` 연결을 쓰고, 그 연결을 회수하면
     데스크톱 채팅과 로컬 Code 탭이 함께 영향을 받는다.** 참조·생성 계획은 `client_id` 별이라 다른 연결로 이어받는다고 가정하지 않는다.
   - 이름 규칙과 회수는 별개다: 회수는 서버 설정 이름이 아니라 클라이언트 종류(codex·claude·claude_desktop)로 한다. 그래서 예전에
     dev 가 `mvhub` 로 등록돼 있었다면 그 항목은 파일에 남지만 그 프로필은 회수될 수 있다(자동 정리는 범위 밖, 문서화).
3. **백엔드**: `ConfigureIn.clients` 에 `claude_desktop` 추가(최대 4). `skipped` 는 `store.revoke` 후 그대로 반환.
   `configured` 일 때 같은 이름 앞 연결 회수 대상에 `claude_desktop` 추가.
4. **화면**(작은 문구 변경): 큰 단추 글자 "Codex·Claude 연결 허용", 머리 안내 "Codex·Claude Code·Claude 데스크톱 채팅",
   결과 줄 이름을 쉬운 말로(Codex · Claude Code · Claude 데스크톱 채팅 · 다른 프로그램), 상태 `skipped`=“건너뜀”.
   데스크톱 등록 완료 문구 "Claude 앱을 트레이에서 완전히 종료한 뒤 다시 켜야 채팅에 나타납니다."
   더보기의 "Claude Desktop 등 다른 로컬 앱은 ‘다른 MCP 프로그램 설정’" 문장을 새 동작에 맞게 고친다.

## 제외

- 웹(claude.ai)·휴대폰 Claude 앱의 일반 채팅(원격 HTTPS 커넥터가 필요 — 허브가 127.0.0.1 전용).
- 데스크톱 채팅 결과 카드(MCP Apps) 연결 — 10-16 Jay A안 유지. 실사용 표시 확인 뒤 Jay 가 따로 정한다.
- 데스크톱 채팅의 첨부 그림 바로 쓰기(`import_reference`) — Claude Code 첨부 폴더·세션 ID 전제라 거부된다(안전한 실패, 문서화만).
- MSIX 가상화 경로(`%LOCALAPPDATA%\Packages\Claude_…\LocalCache\Roaming\Claude`) 지원 — 이 PC 는 실제 경로를 쓴다. 코드에 한계 주석.
- 예전 연결 코드 방식 화면(`frontend/src/components/mcp/McpConnection.tsx` 「이전 방식 연결 · 고급 호환 설정」)의 수동 안내 —
  `mvhub` 이름 고정·"Claude Desktop 은 mvhub 항목을 추가" 문구는 이름 규칙을 적용하지 않고 그대로 둔다(Claude 합의 세션 P2, (a)안).
- 설치본 앱 반영(릴리스 절차 별도) · 기존 손 등록 정리.
