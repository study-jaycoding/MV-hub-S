# 캔버스 탭 — 설명 창에 단추 넣기 (2026-11-02)

owner: Claude · reviewer: (묶음 리뷰) · status: 구현 완료(dev 커밋 · Jay 화면 확인 남음) · touched_paths: 아래 계약 · updated: 2026-11-02

Jay: 탭에 올렸을 때 나오는 창의 윗부분은 그대로 두고 그 밑에 보관·불러오기·Import·Export·레퍼런스 찾기를 넣는다. 시안 비교 뒤 고른 모양: 휠 클릭 패널과 같은 칸 묶음, 휠 클릭·우클릭 안내 줄은 없앤다.

11-02 오전의 "패널은 호버로 뜨지 않는다" 결정을 Jay 가 이번 요청으로 바꿨다(알린 뒤 진행 지시). 휠 클릭 패널은 없애라는 말이 없어 그대로 둔다.

고친 것: 단추 묶음을 `SceneIoButtons` 로 뽑아 패널과 설명 창이 같이 쓴다. `NodeTip` 에 `actions` 를 더해 창을 요소 밑에 붙이고, 마우스가 건너가는 180ms 동안 닫지 않으며, 창 안 누름에는 닫지 않는다. 눌린 단추는 App 의 `ioRequest` 로 SceneBoard 에 전한다 — 씬을 바꾸는 틈이 끝난 뒤 한 번 실행한다. 설명 창에서 누른 '레퍼런스 찾기'는 진행 표시와 '대기 중단'을 위해 패널이 탭 밑에 뜬다.

확인: jsdom 시험으로 자리·건너가기·누르기·닫기·다른 씬 대기·한 번만 실행을 봤고 빌드를 통과했다. 실제 브라우저에서 마우스로 건너가 본 것은 아니다.

문서: `docs/CODE_MAP.md`·`docs/기능설명서.md` 도 고쳤다. 다른 세션의 미커밋 변경이 있어 계약 범위에서 빼고 내 줄만 커밋했다.

남은 한계: 탭 위를 지나갈 때마다 창이 떠 캔버스 일부를 가린다(Jay 에게 알림). 휠 클릭 패널이 열린 채 그 탭에 올리면 설명 창이 패널 위에 겹친다.
