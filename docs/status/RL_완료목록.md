현재 부분 해결 위험은 RL-23 하나다. RL-02는 프로젝트 이동 전 작업에 생성 당시 워크스페이스를
스냅샷으로 보존하고, 기존 DB 멱등 마이그레이션·과거 공간 권한 게이트·두 워크스페이스 왕복,
100명 읽기·무쓰기 부하와 최종 브라우저 재실측을 통과한 뒤 목적별 커밋까지 마쳤다.
RL-23은 자동 업로드·세트 저장·재시도·운영 상태까지 구현했지만 실제 NAS/다른 물리 장치의 복제본만
사용한 예비 PC 복원 훈련 전에는 완료로 올리지 않는다.
