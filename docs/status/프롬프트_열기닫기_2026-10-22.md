# 프롬프트 열기·닫기 단추 — 2026-10-22 (Jay 요청)

owner: Claude 총괄 · reviewer: Codex(묶음 검토 때) · status: 완료(dev 커밋 — Jay 화면 손 확인·Codex 검토는 묶음 때) · touched_paths: 아래 계약 · updated: 2026-10-22

고침: `ServerConsolePanel` 의 상태줄 끝에 `.sl-status-toggle` 칸(`common/ViewIcons` 의 `PromptIcon`) — 누르면 App 이 `usePromptDock` 의 `setPromptVisible` 로 뒤집는다(Ctrl+K 와 같은 상태). 설명(`title`·접근 이름)은 '프롬프트 접기/열기 (지금 단축키)'. 편집 탭에서는 넘기지 않아 칸이 없다. 설명은 앱의 다른 단추처럼 브라우저 기본 말풍선이다(모의 이미지의 검은 말풍선과 모양이 다름).
검증: 새 시험 2(끝 칸·설명이 상태를 따름·누르면 호출 / 없으면 칸 없음) · 프런트 전체 412 파일·4,900 통과(종료 코드 0)·구조 lint·빌드 통과 · 격리 S 서버(dev 빌드) 실제 브라우저: 칸이 상태줄 테두리 안쪽 위·아래·오른쪽 끝에 닿음(상태줄 859~887px, 칸 860~886px), 누르면 접힘·설명 '열기', 다시 누르면 열림, 칸으로 접은 뒤 Ctrl+K 로 열림 — 5/5. 이 변경은 GitHub 후보 `0be464b8` 에 들어 있지 않다.
Jay 추가: "프롬프트가 접혔을 때는 아이콘이 (라임으로) 보이고 접히지 않으면 회색으로" → 열려 있으면 `.open`(회색 `var(--muted)`), 접혔을 때만 라임. 마우스를 올리면 둘 다 라임 바탕·검은 아이콘. 시험에 상태별 클래스 확인 추가.

Jay: "Ctrl+K 를 누르면 프롬프트 창이 숨겨지는데, 숨겨질 때 프롬프트 아이콘이 생기고 그걸 누르면 다시 나오게 — 지금은 단축키만 있어서 모르는 사람은 이 기능을 쓸 수 없다. 디자인부터." → 모의 이미지 세 차례(접기 단추를 창 모서리에·복사 단추 모양으로, 열기 단추를 Host 상태줄 옆·모서리 안쪽에) → 결정: **"아이콘은 이미지1(Host 상태줄 오른쪽 끝 모서리 안쪽에 붙인 칸)을 사용한다. 프롬프트 닫기도 이 단추를 누르면 되는 걸로 — 프롬프트 창에 따로 단추를 만들 필요는 없다."**

지금(코드 확인): 숨기기·보이기는 `lib/usePromptDock` 의 `promptVisible` 하나이고 단축키(`focusPrompt`, 기본 Ctrl+K)만 바꾼다. 숨겨도 Host 상태줄(`spotlight/ServerConsolePanel` 의 `.sl-status`)은 화면 오른쪽 아래에 남는다. 편집 탭에는 프롬프트가 없고 상태줄만 남는다.
