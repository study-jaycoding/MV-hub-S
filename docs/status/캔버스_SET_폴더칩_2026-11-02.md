# 캔버스 SET 카드 — 폴더가 잘리지 않게 (2026-11-02)

owner: Claude · reviewer: (묶음 리뷰) · status: 구현 완료(dev 커밋 · Jay 화면 확인 남음) · touched_paths: 아래 계약 · updated: 2026-11-02

Jay: SET 카드에 폴더를 넣으면 `뻘뻘뻘 › e060/c` 처럼 끝이 흐려지며 잘려 전체가 안 보인다.

시안을 비교한 뒤 Jay 가 고른 모양(C안 변형 1안): 프로젝트 칩 하나를 위에 크게(금색 채움), 그 아래에 폴더 한 단계마다 칩 하나(금색 선). 폴더 칩은 넘치면 줄을 바꾼다.

확인: 실제 `scene.css` 로 헤드리스 크롬에서 칩을 그려 짧은 경로·긴 프로젝트·긴 폴더 이름 모두 잘리지 않는 것을 봤다. 앱 화면 실측은 아니다. 높이는 짧은 경로 + 빈 태그 칸 기준 156px 이다(MCP 가 만드는 SET 의 처음 높이).

남은 한계: 이미 폴더가 든 옛 SET 카드는 높이가 130px 그대로라 처음엔 태그 칸 아래가 가려진다. 씬을 열기만 해서 저장이 나가지 않게 자동으로 늘리지 않는다. 폴더를 다시 끌어 놓거나 크기 손잡이로 늘리면 된다. MCP 가 만드는 SET 은 경로가 길어 칩이 두 줄이 되면 같은 상태가 된다.
