## 1단계 범위

- `text2speech_v2` 의 `variant` 를 모델 목록의 줄 3개로(ElevenLabs·MiniMax·Seed Speech). 제출·DB·견적은 지금과 같은 모델 키와 `variant` 값.
- `vibe_voice`·`cozy_voice` 는 새 선택지에서 빼고, 저장된 값으로 열리면 "기존 설정" 줄로 보이며 값을 바꾸지 않는다.
- 복원값에 `variant` 가 없으면 기본값으로 채우지 않고 "엔진 선택" 상태로 둔다 → 고를 때까지 제출·씬 저장을 막는다(Codex B1).
- 목소리 기본 목록 상자 → 검색되는 목록 창(전체 preset). 저장된 선택을 자동으로 바꾸지 않는다.
- 개별 생성물(카드·정보 창·비교·커버·씬 복구)의 모델 이름은 엔진 이름, 크레딧 집계·그룹 정책은 모델 키 단위 "Text to Speech V2"(Codex B2).
- 대본 글자 수 / 엔진 한도 표시(제출 검증과 같은 값). 표시할 고급 옵션이 없으면 고급 단추는 원래대로 숨는다.
