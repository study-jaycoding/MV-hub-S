# MV Agent 머리글 정보 칸 — 지금 화면을 입력칸에서 정보 칸으로 (2026-11-12)

## 2. 설계

- 머리글 오른쪽 [새 대화] 와 [새 창] 사이에 **정보 단추**(`aria-pressed`). 누르면 정보 칸이 열리고, **다시 누를 때만 닫힌다**(바깥 누름·Esc 로 닫지 않음). 열린 채인지는 이 브라우저에 기억(`STORAGE_KEYS.agentInfoOpen`, 실패해도 닫힘으로 시작).
- 정보 칸(머리글 오른쪽 아래 카드):
  - **지금 화면**: 화면 요약(`contextLabel`)·공간·프로젝트·폴더·고른 카드 수·(캔버스면) 열린 씬 + **'AI 에게 보내기' 스위치**(`role="switch"`) — 지금의 입력칸 칩 ×/＋ 를 대신한다. 끄면 다음 차례부터 빈 문맥(지금과 같은 `NO_SCREEN`), 새 대화·지난 대화 열기에서 다시 켜짐(지금과 같음).
  - **이 대화에서 만든 것**: 이 대화 계획 카드에서 끝난(`generation_status = done`) 생성물 썸네일 — 누르면 기존 크게 보기. 앱 카드에 없는 것은 기존 복원 묶음 조회에 같이 넣는다.
  - **붙였던 자료**: 이 대화의 내 말에 붙였던 자료(중복 없이) — 이름·종류.
- 안 보냄이면 정보 단추에 회색 점, 입력칸 안내문이 "지금 화면 없이 물어보세요 — 어디인지는 직접 알려 주세요".
- 입력칸에는 붙인 자료 칩·고칠 계획 칩만 남는다(지금 화면 칩·'＋ 지금 화면' 단추 없앰). 칩이 없으면 칩 줄도 그리지 않는다.
- 서랍이 열리면 서랍 덮개가 정보 칸 위에 온다(z 순서).
