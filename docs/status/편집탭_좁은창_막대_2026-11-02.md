## 검증

- 커밋 고정 사본 `627ffc18`·위임 켠 격리 허브·실제 크롬에서 타임라인을 연 편집 탭을 폭 1,600·1,280·1,200·1,100·900 으로 쟀다: 문서 전체 넘침 0 · 막대 높이 44 그대로 · 1,200 이하에서 막대 안 넘침이 생기고 끝 단추까지 밀어서 보인다.
- 넓은 창(1,600·1,280)은 막대 안 넘침도 없어 고치기 전과 같다. 메뉴는 포털이라 잘리지 않는다(코드 확인 — `EditTrackMenu.tsx` 의 `createPortal`).
- 같은 때 발견: 스모크의 리스트·그리드 두 단계가 10-30 보기 단추 창 개편 뒤 낡아 그 조작을 재지 못했다. `tools/browser_measure/smoke.py` 를 새 화면에 맞춰 41단계 실패 0·낡은 단계 0 을 확인했다(옛 앱과 섞어 재도록 옛 단추도 그대로 누른다).
