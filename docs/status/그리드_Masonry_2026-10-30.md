# 워크스페이스 그리드 — Layout: Square · Masonry — 2026-10-30 (Jay 지시)

요청(Jay): "이 전체 보기에서 마우스 우클릭을 하면 지금처럼 스퀘어로 카드가 보이던지 이미지2처럼 보이던지 정하는게 나오면 좋겠다. 이미지로 먼저 보여줘봐" · "힉스필드에 이런 옵션이 있네"(Layout: Square / Masonry) → 모의 그림(스크래치 `palette\layoutmenu.png`) → "이대로 만들어".

정한 것(모의 그림 그대로):
- 툴바 '전체 보기' 단추 **우클릭** = Layout 메뉴(Assets 정렬 메뉴와 같은 부품) — ● Square「정사각 카드 · 지금」 · Masonry「그림 비율 그대로 · 줄마다 꽉 채움」 · 구분선 · 안내「왼쪽 클릭 = 전체 보기 ↔ 꽉 채우기(Square 일 때)」. 왼쪽 클릭은 지금 그대로.
- Masonry = 줄마다 폭을 꽉 채우는 원래 비율 줄(목표 줄 높이 170px × 카드 크기 배율 · 간격 4px · 모서리 8px). 꽉 차지 않는 날짜의 마지막 줄은 목표 높이 그대로(늘리지 않는다).
- 그림 비율 = 생성 설정의 `aspect_ratio`(예 16:9) → 없거나 auto 면 썸네일이 뜰 때 잰 값 → 그것도 없으면 1. 서버 썸네일은 비율을 유지해 만든다(`services/thumbs.py` — `thumbnail((w, w))`·`scale=w:-2`).
- 저장 = 다른 보기 설정처럼 **자리(폴더)마다**(`placeViews` 의 `masonry`) — 처음 들어가는 자리는 방금 보던 것을 물려받는다.
- 리스트 보기·Assets·폴더(컷) 카드·캔버스 보드는 그대로. 캔버스 '생성 결과' 창은 라이브러리와 같은 보기 설정이라 같이 따른다.

## 결과 (2026-10-30)

- 줄 계산 `lib/gridVirtualRows.ts`: `buildGridRows(..., justify)` — 목표 높이로 쌓다가 폭을 넘기면 끊고 높이를 (폭 − 간격) ÷ 비율 합으로(목표 이하). 끝난 줄은 목표 높이. `navCenters` 로 위·아래 = 가로로 가장 가까운 카드. `paramAspectRatio` · `gridContentWidth`(열 수 계산과 같이 씀).
- 격자 `ThumbnailGrid.tsx`: `masonry` 이면 줄 폭을 재고 칸을 `width·height` 인라인으로. 비율 = 설정 → 잰 값(load·loadedmetadata 를 잡기 단계로 듣고 한 프레임에 한 번 다시 짬 · 설정 비율이 있으면 다시 짜지 않음) → 1, 0.25~4 로 묶음. Masonry 는 썸네일 512.
