# 오디오를 레퍼런스로 쓰는 경로 검수

요청 근거: Jay 2026-10-28 "캔버스에서 오디오 레퍼런스를 불러오거나 생성한다음에 그걸 다른 모델에 적용할떄 지금 오디오로 들어가지지 않는거 같다. 우리 영상 모델들과 오디오 모델에서 오디오를 레퍼런스로 잘 사용할수 있는지 프롬프트와 캔버스에서 모두 잘 적용될수 있는지 하나씩 검수해서 제대로 사용되는지 확인해보자. 실제 생성과 실측을 통해서 구현하자."
진행 방식: Codex 크레딧 문제로 Claude 단독([Codex 사후 점검 대기](Codex_사후점검_대기_2026-10-28.md)). 작은 작업(minor) — 제출 전 검사 한 줄과 시험만 더한다.

## 확인한 사실(2026-10-28, CLI 1.2.3 `.mvhub-runtime\higgsfield\higgsfield.exe`)

- **오디오 입력 칸이 있는 모델**(`model get` 의 `audio_references`): 앱에 보이는 것 중 Seedance 2.5·2.0·2.0 Mini, Seed Audio 1.0. ElevenLabs v4·v4 Turbo·Text to Speech V2·Qwen 은 레퍼런스 칸이 없고, Voice Change·Translate 는 영상(`input_video`)만 받는다.
- **CLI 규칙**: Seedance 2.0·Mini 는 "audio_references require at least one image, video, start_image, or end_image" · 오디오 3개까지. Seedance 2.5 는 오디오만 있어도 된다(omni_reference). Seed Audio 는 이미지·오디오 동시 불가, 목소리를 고르면 오디오 2개까지.
- **무료 견적(R&D)**: Mini 이미지+오디오 480p 4초 2 · 2.0 같은 조건 12 · 2.5 omni 12 · 2.5 오디오만 12 · Seed Audio 오디오 참고 0.1 · **Mini 오디오만 = CLI 거부(exit 4)**.
- **dev DB(읽기 전용)**: `reference` 표에 오디오 형식이 한 줄도 없다(이미지 3,495·영상 211). 앱에서 오디오 레퍼런스가 제출된 적이 없다. 7월 동기화 한 건(role audio·`.wav`)이 image 로 저장돼 있으나 지금 `media_type_from_url` 은 `.wav` 를 audio 로 본다(옛 코드의 흔적 — 고치지 않음).
- **에이전트 인자(가짜 CLI, 과금 없음)**: 2.5·2.0·Mini 는 이미지 `--image-references <업로드 id>` + 오디오 `--audio-references <업로드 id>`, Seed Audio 는 `--audio-references <로컬 파일>`.
- **프런트 코드 추적**: 프롬프트(트레이·인라인 칩·@ 피커)·캔버스(파일 놓기·에셋 끌기·생성된 오디오 카드·리스트)·제출 본문 조립 모두 `type: "audio"` 를 보존하고, `buildSpotlightCreateBody` 가 오디오에 `@AudioN`(Seed Audio 는 `audio_references`) 역할을 붙인다.

## 원인과 고친 것

- 코드 경로에서 오디오가 이미지·영상으로 바뀌는 곳은 찾지 못했다(위 「프런트 코드 추적」·「에이전트 인자」). Jay 가 본 "오디오로 안 들어간다"에 가장 가까운 실제 결함은 **Seedance 2.0·Mini 에 오디오만 이은 경우**다 — 앱은 그대로 제출하고 CLI 가 `audio_references require at least one image, video, start_image, or end_image` 로 거부한다(견적 실측 — 과금 전 거부). 오디오 4개 이상도 같다(CLI 한도 3).
- ★정정(Codex G 지적을 `agent_push.py:2879-2893` 로 확인): CLI 가 작업 id 없이 거부하면 에이전트는 카드를 실패로 끝내지 않고 **'제출 확인 필요'(수동 복구)** 로 격리한다(이미 과금됐을 수 있어 자동 실패·재시도를 안 하는 설계). 처음에 쓴 "카드가 영어 오류로 실패"(계약 `decisions` 의 why 포함)는 틀렸다.
- 고침(`a6d6fe09`): `validateSeedanceMode` 에 Seedance 2.0·Mini 오디오 규칙 두 줄. 프롬프트·캔버스·MCP 계획이 모두 `buildSpotlightCreateBody` 를 거치므로 한 곳에서 막힌다. 첫/끝 프레임은 이미지로 센다(CLI 규칙과 같음). Seedance 2.5 는 오디오만이어도 그대로 통과.

## 유료 실제 생성(2026-10-28, Jay "유료 4건 실행")

처음 시도는 자동 권한 검사가 "실제 거래"로 막아, Jay 가 이 세션에서 직접 "유료 4건 실행"이라고 한 뒤 돌렸다. R&D 공간(이 프로세스에만 `HIGGSFIELD_WORKSPACE_ID`), CLI 1.2.3, 에이전트와 같은 플래그(`--image-references`·`--audio-references`). 입력 = 앱의 ElevenLabs v4 결과 대사 mp3 앞 3.8초(남자 목소리) + 그림 1장.

합계 **14.8 크레딧**(견적 14.2 — Seed Audio 는 견적 때 짧은 글로 물어 0.1, 실제 대본이 길어 0.4).

판단:
- **Seedance(2.5·Mini) = 오디오가 결과에 반영됨.** 공급자 잡 기록에 오디오가 `audio` 역할·`audio_input` 으로 붙었고, 결과 소리가 무관한 소리(0.20)보다 레퍼런스와 잘 맞으며(0.61·0.39) 목소리 높이가 레퍼런스와 같은 대역이다. 대사를 그대로 붙인 것은 아니고 시간이 밀린 비슷한 말소리다 — 정확히 같은 말인지는 청취로 판정.
- **Seed Audio = 오디오로 접수는 되지만, 목소리를 따른다는 근거는 없다.** 높이가 오히려 멀어졌다(높이 추정은 순수 파이썬 자기상관이라 옥타브 착오 가능). `audio_references` 가 목소리 복제가 아니라 다른 용도(분위기·말투 참고)일 수 있다 — 청취 전에는 판단하지 않는다.
- 숫자 비교 방법: ffmpeg 로 8kHz 모노 → 20ms 세기 곡선 상관(±1초 어긋남 중 최대) · 40ms 창 자기상관 높이 중앙값. 결과 파일·파형 그림은 세션 스크래치에만 있다(사라질 수 있음 — 힉스필드 웹 R&D 히스토리에도 있다).
