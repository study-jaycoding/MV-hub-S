# 크게 보기 Ctrl 카드가 생성물 원본을 검게 덮음 (2026-11-06)

Jay 11-06(화면 첨부): 어셋 탭의 크게 보기에서 Ctrl 을 누르면 원본 위에 단추만 잘 보이는데, 메인 창(생성물)에서는 원본이 사라지고 어두운 판 위에 단추만 보인다.

원인(코드 확인): Ctrl 카드 겹치기(`MediaPreview.tsx` `.mp-card-layer`, `522a8f61` 11-05)는 카드의 그림·배경을 비워 원본이 비치게 하는데, 비우는 규칙(`assets.css` `.mp-card-layer .card` · `.card-thumb`)이 생성물 카드의 안쪽 틀 `.card-clip`(10-30 `d63412b5`, 배경 `var(--panel)`)을 빠뜨렸다. 어셋 칸에는 그 틀이 없어 어셋은 멀쩡했다. 틀만 비우면 그 뒤 `.card` 의 상태 색(`generations.css` `.card.st-shared:not(.selected)` 등 — 비우는 규칙보다 세다)이 카드 전체에 비치므로 둘 다 비운다.

배포 검토(`docs/status/배포후보_aac743ba_2026-11-05.md`)의 실측·시험은 Ctrl 카드의 겉모습(원본이 보이는지)을 재지 않아 놓쳤다 — main `7dd1acc6` 에 들어가 있고 릴리스 전이다.
