# 캔버스 — 생성 카드 붙여넣기 그대로 · 다운받은 그림 놓기(판 = 레퍼런스, 탭 줄 = 히스토리) (2026-11-23)

owner: Claude(조사·시안·구현) · reviewer: 묶음 검토 때(Jay '검토' 지시) · status: 검증 중(관련 시험·빌드 통과, Jay 5173 화면 확인 대기) · updated: 2026-11-23

## 1. 요청
- Jay: "생성카드를 복사하면 그대로 복사가 안되는거 같다" · "다운받은 그림을 캔버스 판에 끌어 놓으면 레퍼런스로, 탭 부분에 놓으면 지금처럼 히스토리로".
- 시안(같은 날, 세션 공유 노트 `캔버스_붙여넣기_파일놓기_시안_2026-11-23.png`)을 보고 Jay "A안이랑 바뀜이랑 새로운걸로 제작"
  = ① 붙여넣기 A안(늘 그대로) ② 판(빈 곳)에 놓기 = 늘 레퍼런스(끄는 동안 점선 자리·안내 알약) ③ 캔버스 위 탭 줄에 놓기 = 히스토리 새 탭.
  맨 위 '캔버스' 단추에 놓기(다른 해석)는 고르지 않았다.

## 2. 근거 (Claude 직접 확인, dev c629f803)
- 붙여넣기: `frontend/src/lib/sceneInteractions.ts` `clearPastedResults` 가 genId·genIds·생성 중 표식·상태를 일부러 비웠다(2026-08-18 '설정만 복제', 커밋 8692db0f).
  폴더 창 끌어 놓기(2026-10-22 `addGenerationCards`)는 같은 생성물을 여러 카드에 이미 허용하고, 생성 연결은 카드 id 로 잇는다(`features/canvas/session.ts` reserve/settle/link).
  생성 카드 그림은 카드의 상태가 아니라 생성물 자료(genData)로 그린다(`GenerationCard.tsx`).
- 파일 놓기: `useSceneClipboardDrop.ts` onDrop 이 파일 한 장·Shift 아님이면 `onDroppedGenerationFile`(App `openRecipeFromFile`) 먼저 — 각인 판독 → `openRecipe` 새 탭.
  탭 줄 `SceneBar.tsx` 에는 파일 놓기 처리가 없다(전역 지킴이가 '놓을 수 없음').

## 3. 결정
- 붙여넣기는 결과를 그대로 가져오고, 진행 중인 것만 원래 카드에 남긴다: 응답 전 생성 표식(`pendingGenerationAttempts`)과 그 번호, Comfy 실행 번호(`runId`)·실행 중 상태(`settleComfyRunning` 재사용).
- 판 놓기는 각인을 읽지 않는다(Shift 구분 없앰, `shouldRestoreRecipeFromDrop` 제거). 끄는 동안 표시는 React 상태 없이 ref 로 DOM 을 직접 옮긴다(dragover 마다 SceneBoard 를 다시 그리지 않게).
- 탭 줄 놓기는 미디어 첫 장만 히스토리로 연다. 각인이 없거나 기록을 못 찾으면 알림만(아무것도 만들지 않음).
