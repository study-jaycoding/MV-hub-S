### 구현 중 발견 — 계산 줄이 설명 칸을 다시 눌렀다

A안을 넣고 빌드 CSS 로 재니 설명 칸이 시안의 146px 이 아니라 **48px** 였다. 시안에는 없던 계산 줄(같은 날 먼저 넣음)의 '합계 14,052.4 cr'·'생성 1 · 공유 5'·'합계 21h17m54s' 가 줄 값보다 넓어 상태·크레딧·생성시간 칸을 약 100px 넓혔고, 폭이 정해지지 않은 설명 칸이 그만큼 줄었다. 같은 6줄·창 1160px 로 세 가지를 쟀다(세션 스크래치 `sum_mock\verify_cells_v1|v2|v3.png`):

| 안 | 설명 칸 | 비고 |
|---|---|---|
| v1 상태 한 줄에 하나 + 크레딧 cr 빼기 | **92px** | 노션식 '이름 값' 한 줄 모양 유지, 가로 넘침 없음 — **채택** |
| v2 이름을 값 위 줄로(두 줄) | 129px | 노션 모양에서 벗어남 |
| v3 설명 칸 최소 140px | 140px | 표 1140px > 칸 1048px — 코멘트 칸이 가로 스크롤 밖 |

- CSS: `.work-cut-privates` · 생성기간 날짜의 `::-webkit-calendar-picker-indicator` 숨김 · 설명 칸 `::placeholder` 투명.
