6. 전송 실패는 기존 `_mark_failure`로 기록한다. staging을 보존하고 재시도 시각을 유지한다.
7. manifest 부재와 같은 촬영의 Agent 또는 폴더 곁파일 존재가 함께 확인되면 중복 반환·staging 공개·outbox 등록 전에 거절한다.

10. 구판 복원에서 옛 Agent의 보관 사본이 `None`이면 교체 전에 한국어 안내가 있는 HTTP 409로 끝낸다.
11. 계정 고정, 잠금 순서, 복원 보상 처리, 정상 Agent 채택, v3 복원 의미는 유지한다.
