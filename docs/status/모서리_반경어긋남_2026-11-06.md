# 겹친 층의 모서리 반경 어긋남 — 고침과 자동 검사 (2026-11-06)

Jay 11-06(확대 화면 둘): 크게 보기에서 Ctrl 로 띄운 카드의 모서리에만 밝은 초승달 띠가 보인다. "이런 게 우리 프로그램에 많은데 해결 방법을 검토해 봐" → 시안·검사 결과를 보고 **"고침 + 검사 넣기"**.

원인(실측): 단추가 잘 보이게 위쪽을 어둡게 하는 그늘 막(`.thumb-overlay`, 위 34% 그라데이션)이 Ctrl 층의 틀 모서리로 잘리는데, 그 밑 원본 그림은 `.media-preview-body img` 의 6px 로 둥글다. 두 곡선 사이만 그늘이 빠져 밝게 보인다.
- 생성물 카드: 틀 `.card-clip` 13px vs 원본 6px(네 모서리)
- 어셋 칸: `.asset-cell.masonry` 8px vs 원본 6px(네 모서리)

검사(격리 S 서버·빌드 CSS·헤드리스 크롬, 그림·영상의 모서리와 같은 자리에 모서리가 있는 색 있는 층의 실제 반경 — 자기 반경과 같은 모서리를 자르는 조상 틀까지 — 을 비교, 위에 덮인 층은 1.5px 넘게 다르면, 밑에 깔린 층은 그림보다 덜 둥글면 적는다):
워크스페이스 격자(마우스·고름) · 크게 보기 · 생성 정보 창 · 코멘트 그림 창 · 캔버스(씬을 불러와 생성 카드 3장, 마우스·고름) · 어셋 창(시험 폴더 8장, 마우스·고름) · 어셋 크게 보기 = **0건**. 크게 보기 + Ctrl 카드 4건 · 어셋 크게 보기 + Ctrl 칸 4건 = 위 두 원인.
공유 탭은 측정 사본의 생성물이 팀 공간에 없어 카드가 뜨지 않았다(미실측) — 공유 탭 전용 CSS 는 `.gen-cell.team` 두 줄(S 보이기·작업자 이름표)뿐이고 모서리·배경·자르기를 바꾸지 않아 워크스페이스 격자와 같다(코드 확인).

고침: 원본 그림의 반경을 이름 하나(`--mp-media-r`)로 두고, Ctrl 로 띄운 카드·어셋 칸의 모서리와 자르는 틀이 같은 이름을 쓴다(한 값에서 같이 자르기). 검사 도구는 `tools/browser_measure/corner_scan.py` 로 넣어 실측 묶음에서 돈다(어긋남이 있으면 종료 코드 1).
