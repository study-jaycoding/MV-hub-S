|---|---|---|---|
| Seed Audio 1.0 | `seed_audio` | prompt*, voice_id/voice_type(선택·함께), audio_references, image_references | format(wav·mp3·pcm·ogg_opus, 기본 wav) · sample_rate(enum, 기본 24000) · speech_rate·pitch_rate·loudness_rate(int, 기본 0, 범위 미공개) |
| ElevenLabs v4 | `elevenlabs_v4` | dialogue* = `[{text, voice_id, voice_type}]`(셋 다 필수·다른 키 거부) | stability·similarity_boost(number 0~1 — stability 1 초과 거부 실측) |

- seed_audio CLI 규칙: 이미지·오디오 참고 동시 불가 · voice_id 와 voice_type 은 함께 · 목소리+이미지 참고 불가 · 목소리가 있으면 오디오 참고 2개까지.
- 무료 견적: elevenlabs_v4 대사 1줄 0.23 · turbo 0.15 · text2speech_v2 minimax 0.15. 견적은 voice_id 짝을 검사하지 않는다(가짜 id 통과). elevenlabs_v4 에 `--prompt` 만 주면 `Missing required params: dialogue`.
- 목소리: CLI `voices list` 114개(이름 모두 다름, 모델 구분·성별·미리듣기 없음). 웹은 v3·MiniMax·Seed Speech·v4 Turbo = 114 전부, **Qwen 만 47개** — 47개 이름은 모두 CLI id 로 대응된다(이름 → id, 2026-10-28).
- 지금 에이전트(`agent_push.py:807`)는 `media-v2` 를 선언한다 → 새 모델을 기존 차단 SQL(`repo/gen_requests.py` `_MEDIA_V2_GATE`)에 이름만 더하면 이번 판 에이전트가 모르는 새 모델 요청을 가져간다(Codex A1).
- 에이전트는 모든 요청에 `--prompt` 를 붙이고(`agent_push.py:2537`), 미디어 계약 검사는 `draw_to_video`·`text2speech_v2` 두 이름에 박혀 있다(`:2545~2559`).

## 설계

1. **세 가지 일 전환** — Audio 를 고르면 type 토글 옆에 `Text to Speech | Voice Change | Translate` 를 둔다(모의 화면). 이 단계에서는 Text to Speech 만 동작하고, Voice Change·Translate 는 2-B 가 연결될 때까지 눌러도 "준비 중" 안내만(제출 불가). 전환 상태는 화면 작업이며 저장·복원은 실행 키로 한다(A4).
2. **모델 7줄** — 위 표 순서. 줄마다 설명 한 줄. 텍스트 이름은 CLI 값 기반(웹 제품명 대응 추정 금지 유지). text2speech_v2 3줄은 1단계 방식 그대로(legacy·requireChoice 포함).
3. **ElevenLabs v4/Turbo** — 화면은 대본 한 칸 + 목소리 하나(웹 v4 Turbo 처럼). 저장 계약은 다른 TTS 와 같게 `prompt`=대본, `params.voice_id/voice_type` — **저장용 입력과 CLI 전송 스키마를 분리한다. 단일 dialogue 의 정방향(저장→`dialogue=[{text, voice_id, voice_type}]`)·역방향(공급자 dialogue→대본·목소리) 변환을 견적·제출·수신·복구에 적용하며 대본·목소리를 보존한다. 여러 dialogue 는 임의로 한 줄로 축약하지 않는다**(Codex C2 — 지금 서버는 저장 voice_id 를 CLI 스키마와 직접 비교하고(`cli_bridge.py:1243`), 복구는 공급자 `params.prompt` 를 요구한다(`agent_push.py:1002`)). 여러 화자 편집기는 이 계약 밖.
4. **고급** — 모델 스키마의 옵션만, 모델별 작은 표로 한국어 이름·표시값↔전송값을 둔다(A8): stability·similarity_boost 는 0~1 을 % 로 · **기본값 미확인 옵션은 '공급자 기본값'으로 표시하고 생략한다. 50%·75% 를 실제 선택값으로 표시하려면 각각 0.5·0.75 를 명시적으로 전송한다**(Codex C7) · language "자동" = 필드 생략 · format `ogg_opus` 표시 "OGG" · 확인 안 된 min/max 는 만들지 않는다(정수·유한수만 검사). number 타입 입력을 지원한다(지금 고급은 integer 만 숫자 칸).
5. **Seed Audio 참고** — 레퍼런스 칸이 Seed Audio 일 때만 열린다: 오디오 최대 3(목소리를 고르면 2) 또는 이미지 1, 동시 불가, 목소리+이미지 불가 — 프런트·서버·에이전트가 같은 규칙으로 검사. 목소리는 선택값(필수 아님).
6. **Qwen 목소리** — 전체 114 를 보이되 웹 Qwen 47개(이름→id 고정 표, 출처·날짜 주석)는 '추천' 표시·위로 정렬. 나머지를 비호환으로 단정하지 않는다(A6, Jay 결정 ①).
7. **옛 에이전트·옛 서버 보호(A1)** — 새 기능 표시 `audio-models-v1` 을 둔다. 서버는 이 4 모델 요청의 payload 에 `media_protocol="audio-models-v1"` 을 붙이고, 그 표시를 선언하지 않은 에이전트에게 **목록 조회·claim·begin-submission 모두에서** 주지 않는다. 서버는 `/api/auth/config` 의 `features` 로 이 기능을 알리고(`routers/auth.py:212` 고정 배열), 프런트는 그 뒤에만 4 모델을 고를 수 있게 한다(모르면 줄은 보이되 "서버 업데이트 필요"로 잠금). **기능 미지원 시 신규 선택뿐 아니라 저장값 복원·재생성·씬 제출도 차단한다. 신규 capability 는 기존 capability 선언을 유지하면서 추가한다**(Codex C1).
8. **견적(A2)** — 오디오 TTS 모델은 대본을 견적에 넘기고 프런트·백엔드 견적 캐시 키에 넣는다(지금 text2speech_v2 만 그렇다). 엔진·목소리 등 필수값이 비면 견적을 묻지 않는다.
9. **결과** — 모두 오디오 카드. 확장자 없는 결과 URL 의 오디오 판정은 모델 정의(오디오 모델 목록)로 한다(A4, 지금은 text2speech_v2 이름만).
10. **정의 일치** — 프런트·백엔드·에이전트가 같은 모델 목록·필수값·허용 params 를 각자 작은 표로 갖고, 셋이 같은지 시험으로 고정한다(공용 모듈 없음).
11. **관리·집계** — 그룹 허용 모델(`CreditPlanFields.tsx`)·사용량 집계에 새 모델 키가 이름과 함께 나온다. 집계는 모델 키 단위(B2).
12. **대본 가림** — dialogue 의 대본은 명령 인자·오류 응답·잘린 JSON 에서도 로그에 남기지 않는다(Codex C3 — 지금 `_args_for_log`·`_PROMPT_ECHO_RE` 는 `--prompt`·`prompt` 계열만 가린다, `agent_push.py:314·333`). 실패·타임아웃·파싱 오류 시험으로 확인한다.
