# 오디오 Voice 창 — 이름 바꾸기 · 성별·나이 거르기 · ▶ 미리듣기

요청 근거: Jay 2026-10-28 (힉스필드 목소리 창 화면과 함께) "목소리 선택을 Voice로 변경하고 목소리 선택에서 남성 여성 아이 노인 이런식으로 나눌수있나? 아니면 목소리를 먼저 들어볼수있나?" → 조사 보고(성별·미리듣기 가능, 나이·커스텀은 불가) → "이어서 진행". 덧붙임(같은 날, 힉스필드 필터 메뉴 화면과 함께): "여기서 보면 age도 있는데 우리도 넣어야한다." → 나이 거르기 추가.
진행 방식: Codex 크레딧 문제로 Claude 단독(Jay 지시 — [Codex 사후 점검 대기](Codex_사후점검_대기_2026-10-28.md)). 작은 작업(minor)이라 사전 합의 없이 진행하고 점검 대기 목록에 올린다.

## 조사(2026-10-28)

- CLI `voices list`(1.2.3): 114개, 필드는 id·name·category·status·voice_type·created_at 뿐 — **성별·미리듣기 없음.**
- 힉스필드 MCP `list_voices`: 같은 114개 + `gender`(male 44·female 70)·`preview_url`(공개 CDN mp3·wav)·`logo_url`. **나이 값은 없다**(웹 화면의 Young·Middle aged·Old 거르기는 웹 전용).
- 대조: MCP 114개 id = CLI 114개 id(빠짐·남음 0) · 미리듣기 주소 114개 HEAD 모두 200.
- **나이(덧붙임 때 조사)**: 힉스필드 웹 번들의 목소리 객체에는 `age`(`young`·`middle_aged`·`old`, 없을 수 있음) 칸이 있고, 웹은 비공개 주소 `/reference-elements/voices?age=…&gender=…` 로 거른다. 이 주소를 직접 부르는 것은 자동 권한 검사가 막았다(비공개 접근) — 우회하지 않았다. 대신 웹 목소리 창(비로그인, 한국어 화면)의 나이 필터를 하나씩 눌러 보이는 이름을 끝까지 읽었다: **청년 46 · 중년 60 · 노년 8 = 114**, 겹침 0·빠짐 0(각 두 번 읽어 같은 수). 이름은 CLI 114개에서 모두 고유해 이름 → CLI id 로 옮겼다. 노년 8개 카드의 성별 글자도 표의 성별과 같았다.
- 커스텀 목소리: CLI 에 만들기 명령이 없고, 쓰려면 `voice_type` 이 preset 이 아닌 값이 필요해 2-A 계약(preset 만) 변경 → Codex 재합의 대상. 이번 범위 밖.

## 결과(2026-10-28)

- 구현: 목소리를 안 고른 칩·칩 설명·창 머리 → `Voice`, Seed Audio 해제 단추 → `Voice 해제`. 창에 성별 단추(전체·남성·여성 — 생성창 종류 단추 `.sl-type` 모양을 창 폭에 맞춰 줄임)와 줄마다 ▶ 단추(누르면 ■ 로 바뀌고 다시 누르면 멈춤). ▶ 는 이름 단추 밖에 있어 고르기와 따로 눌린다. 한 번에 한 소리만 나고 창을 닫으면 멈춘다. 주소가 없거나(표에 없는 새 목소리) 재생에 실패한 줄은 ▶ 대신 '–'(설명 '미리듣기 없음'). 이미 멈춘 소리의 늦은 실패(멈춤이 끊은 play)는 무시한다.
- 바뀐 파일: 계약 `touched_paths` 그대로. 새 파일은 `voiceCatalog.json`(표)·`tests/voicePickerFilter.test.tsx`(5건). 기존 시험 2개는 칩 이름표(`aria-label`)만 `Voice` 로. CSS 는 새 전용 클래스만 더했다 — 수정 창이 빌려 쓰는 기본 클래스(`.sl-type-btn` 등)는 그대로(수정 창 세션 확인 요청 반영).
- 시험: 관련 4 파일 31건 · 프런트 전체 · `lint:architecture` · `build` 통과 · 표 대조 스크립트(CLI 114 id 일치·주소 114 HEAD 200) 통과 — 시험 기록 ID 는 계약 `verification`.
- 화면: 실제 `SpotlightOptionsBar` 를 jsdom 에 그린 DOM + 빌드 CSS(`index-CA2GvAlR.css`)로 헤드리스 크롬 캡처(저장소 밖). Qwen·여성 거름·재생 중 / v4·전체·안 고름 두 장면 확인. **Jay 의 5173 창에서 실제 소리 재생은 확인하지 않았다**(jsdom 은 재생을 흉내만 낸다).
- 커밋: dev `08d047db`(코드). 마무리 점검의 graft 재빌드는 2분 넘게 응답이 없어 멈췄다(쓴 파일 없음 확인) — 색인 갱신 생략.

### 덧붙임 — 나이 거르기(2026-10-28)

- 구현: 성별 줄 아래에 나이 줄(전체·청년·중년·노년 — 힉스필드 한국어 화면 이름 그대로). 두 줄은 같은 부품(`VOICE_FILTERS` 표 하나)으로 그리고, CSS 클래스는 `.sl-voice-gender` → `.sl-voice-filter` 로 이름만 바꿨다(새 전용 클래스 — 기본 클래스는 그대로). 표 `voiceCatalog.json` 은 줄마다 세 번째 값으로 나이를 더했다(`[성별, 미리듣기 주소, 나이]`).
- 시험: 나이 시험 1건 추가·표 시험에 나이 값·개수(46·60·8) 확인 추가 → 관련 4 파일 32건 · 프런트 전체 · `lint:architecture` · `build` · 표 대조 스크립트(나이 값 검사 추가) 통과. 계약을 바꿨으므로 시험 기록은 모두 새로 받았다(계약 `verification`).
- 화면: 같은 방식 캡처 — Qwen·여성·청년·재생 중 / v4·노년(8개) 확인.
- 커밋: dev `6657b8b1`(코드).
- 넣지 않은 것: 힉스필드 필터의 'Show: All / Custom'(커스텀 목소리 — CLI 미지원·2-A 계약 밖).
