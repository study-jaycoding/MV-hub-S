## 한 것

- 10-08 의 두 칸 보기(`EditTrimView`·`nearestPoint`·`shotsAt`)를 git 기록에서 되살려 지금 코드에 맞췄다: 프레임 시각 = `mediaAt`(속도·앞 자르기),
  덮개 이름 `.ed-dyn`(높이 손잡이가 `.ed-split` 을 쓴다), 재생헤드 쪽 칸 표시(`data-side`)는 없앴다 — 재생 중에는 덮개를 아예 내린다(`EditTab` 의
  `over={dynamic && !view.playing && …}`). 뷰어 판 `over` 를 되살렸다.
- `EditTab`: `linked`·`together`·`oneBar`·공용 줄을 지우고 `dynamic` — 켜면 `places = [1]`·`viewAt` = 타임라인(저장된 `views` 는 그대로), ↑↓ 는 보는
  편집점 기준, '한쪽을 틀면 다른 쪽 멈춤'은 예외 없이, 다른 보기를 고르는 `setModeAt` 은 모드를 끈다. 단축키 동작 열쇠 `linked` 는 개인 지정 키 때문에 그대로.
- `EditViewer`: `bare`·`VolumeControl` 의 `label`(공용 줄의 L·R) 지움, `TransportButtons`·`VolumeControl` 은 판 안에서만 쓰여 내보내기를 뺐다.
  CSS 의 공용 줄 규칙을 지우고 두 칸 규칙을 넣었다. 단추 설명 글 새로(영어 사전 포함 — 옛 글 키는 `(W)` 를 박은 채라 이미 영어가 안 걸리고 있었다).
- 시험: `editTimeline`(두 칸 계산 셋 — 10-08 것 되살림) · `editCutFolder`(새 셋: 켜기·두 칸·↑↓·재생 = 한 화면·멈추면 두 칸·⊗·단추 / 타임라인 판이 안 보이던
  화면·싱글·돌던 소스 멈춤·판 메뉴 하나 / 타임라인을 튼 채 판을 소스로 바꾸면 그 시계도 멈춤(옛 시험에 섞여 있던 Codex 36회차 확인을 따로 남김)) ·
  옛 공용 줄 시험 둘 지움. 편집 탭 시험 전부 · `tsc -b` · `lint:architecture` · 코드 지도 · 목록 확인 통과.
