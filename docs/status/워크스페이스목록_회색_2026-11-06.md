# 계정 메뉴 — 고르지 않은 워크스페이스 줄은 회색, 마우스를 올리면 밝게 (2026-11-06)

Jay 11-06: "추가된 워크스페이스들도 선택이 되어있지 않으면 회색처리가 되어있게하자. 시안부터 보여줘" → 시안 G(격리 서버 실제 화면, 가짜 워크스페이스 10개) → "G안으로".

바꾸는 것(`frontend/src/styles/app-shell.css` 의 계정 메뉴 워크스페이스 줄 규칙 옆, CSS 만):

- 고르지 않은 줄(`.acct-item:not(.on)`): 이름 `--muted`(언어·모션의 고르지 않은 칸과 같은 회색) · 크레딧·역할 `--muted2` · 배지 테두리·글자 흐리게.
- 마우스를 올리면 그 줄은 지금처럼 밝게(이름 `--text` · 크레딧·역할·배지 원래 색). 설정 단추 시안 E(평소 회색, 마우스를 올리면 색)와 같은 규칙.
- 고른 줄(`.on`)은 그대로 — 연한 라임 바탕 · 라임 배지 · 흰 이름.

`.acct-item` 은 워크스페이스 줄에만 쓰인다(`AccountMenu.tsx` 의 두 갈래 단추 — 로컬 허브 라이브·공유 서버 보고값) — 다른 메뉴 줄에 번지지 않는다(grep 확인). 컴포넌트·동작은 그대로.

확인: 빌드 · 빌드한 실제 화면(격리 S 서버, `/api/account/hf` 응답만 페이지 안에서 가짜 목록)에서 글자색을 직접 읽는 판정(고르지 않은 줄 이름 = `--muted`, 마우스를 올린 줄·고른 줄 이름 = `--text`) — 판정 스크립트는 저장소 밖(세션 스크래치 `ws_color_check.py`).

결과: 빌드 통과(빌드 CSS 에 새 규칙 있음) · 색 판정 5가지 모두 통과 — 고르지 않은 줄 이름 `rgb(139, 144, 156)`(--muted) · 고른 줄 이름 `rgb(243, 244, 246)`(--text) · 고른 줄 배지 바탕 `rgb(196, 232, 74)`(라임) · 고르지 않은 줄 9개 · 마우스를 올린 고르지 않은 줄 이름 `rgb(243, 244, 246)`. 찍은 화면이 시안 G 와 같다.
