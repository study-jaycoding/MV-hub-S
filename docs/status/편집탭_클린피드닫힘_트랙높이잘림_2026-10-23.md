# 편집 탭 버그 둘 — 클린 피드 창이 뜨자마자 닫힘 · 트랙 높이를 키우면 아래가 잘림 — 2026-10-23 (Jay 보고)

owner: Claude 총괄 · reviewer: Codex(묶음 검토 때) · status: 완료(dev 커밋 — Jay 화면 확인 남음) · touched_paths: 아래 계약 · updated: 2026-10-23

Jay: "비디오 클린 피드를 실행했는데 화면이 뜨는거 같더니 갑자기 사라지면서 결국은 작동을 안한다." · "시프트 휠로 크기 조정하는데 밑에 부분이 뭔가에
가려져서 짤려서 보인다."(그림 2장)

원인(확인):
- **클린 피드** — 개발 화면(5173)은 React StrictMode 로 돈다(`main.tsx`). StrictMode 는 처음 그릴 때 효과를 '붙임 → 뗌 → 다시 붙임'으로 한 번 더 돌리는데,
  `EditCleanFeedWindow` 의 효과가 **뗄 때 창을 닫는다** → 창이 뜨자마자 닫히고, 다시 붙은 효과의 감시(0.5초)가 '창이 닫힘'을 보고 끈다. 시험은 StrictMode 없이
  돌아 못 잡았다. 설치 앱(빌드)은 StrictMode 의 두 번 돌림이 없어 이 일이 없다(코드 판단 — 설치 앱에서는 재 보지 않음).
- **트랙 높이** — `.ed-tl`(세로 스크롤 칸, flex 가로줄) 안의 `.ed-scroll` 이 기본 늘이기(stretch)로 **칸 높이에 묶이고** `overflow-y: hidden` 이라, 줄이 칸보다
  높아지면 아래(V1·A1)를 잘랐다. 머리 칸은 넘친 채 스크롤돼 줄과도 어긋난다. 헤드리스 크롬 실측(실제 `edit-tab.css`): 줄 영역 245px · 줄 내용 580px · 끝까지
  내려도 A1 안 보임 → `.ed-scroll { align-self: flex-start; min-height: 100% }` 이면 580px · A1 보임.
