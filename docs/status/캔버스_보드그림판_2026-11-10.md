## 설계안 v2 (Claude)

1. **켜는 조건** — 개발 표식 `localStorage["ch.canvas.boardDraw"] === "1"` 일 때만(기본 끔. Jay 가 같은 카메라 나란히 사진을 보고 승인하면 기본 켬 한 줄). 그리고 **쉼 정리 때 확정한** 배율이
   툴바 25% 이하(`SCENE_LOD_PCT`, 기존 '멀리서 단순화'와 같은 경계)일 때. 휠·이동 도중에는 모드를 바꾸지 않는다(몸통 수백 개를 제스처 도중 붙이지 않게) — `useSceneViewport` 가
   쉼 정리에서 바뀔 때만 알리는 `lodLow` 상태를 낸다(data-lod-low 속성은 지금처럼 즉시).
2. **그릴 카드** — `renderCards` 중 일곱 종류이면서 예외가 아닌 것. 예외(DOM 몸통): 선택·편집·끄는 중(moveDraw)·Comfy 대기·높이 미측정(keepIds 의 이유와 같음)·
   마우스 올림(`hoverId`, 틀의 pointerenter/leave 로 보드 상태)·포커스 든 카드(`focusin/out`)·그 카드의 열린 창(태그 편집·S 확인)·영상 재생 중·연결 중(`.wiring`)·자르기 중(`.cutting`) 동안은 전부 DOM.
   **가림 전파**: 예외 카드와 겹치면서 배열에서 그보다 뒤(위에 그려지는) 카드도 DOM(그림판은 모든 틀 아래 한 장이라, 그대로 두면 예외 카드 몸통이 앞 카드를 덮는다).
3. **틀** — 그림 카드도 지금 틀 div(키·class·data-id·data-linked·크기·더블클릭)는 그대로, 몸통 컴포넌트만 안 붙이고 `cv` class(배경 투명·고정 폭/높이 = `widthOf`/`heightOf`, 자동 높이 카드는 잰 높이).
   선택 테두리·glow 는 틀이 그린다(그림 카드는 선택이면 예외라 DOM). 연결선 좌표는 지금도 카드 좌표로 계산(포트 DOM 무관).
4. **그림판 요소** — `components/scene/BoardCanvas.tsx`(memo) 하나. `.scene-canvas`(카메라 transform 층) 안, 연결선 SVG 뒤·카드 틀 앞, `pointer-events: none`.
   덮는 범위 = 컬링 사각형(`cullRect`, 뷰포트 + 1500 세계 px). 뒷면 = 세계 크기 × 확정 배율 × DPR(상한 긴 변 8192·면적 상한 넘으면 배율을 낮춤).
   **요소 크기·자리는 범위가 바뀔 때만** 바꾸고, 같은 크기면 다시 할당하지 않는다(시험판의 Layerize 증가 원인). 휠 도중엔 합성기가 늘리고 줄인다(확대 쪽 흐림은 쉼 뒤 다시 그려 회복).
5. **다시 그리기** — rAF 로 모아 프레임당 한 번. 이유 = 그릴 카드 집합·각 카드의 보이는 입력(카드 객체·생성 결과·서버 판정 버전·어셋 버전)·범위·배율 확정·그림 로드 끝.
   그림 = `HTMLImageElement` 보관(지금 썸네일 주소 함수 그대로 — 브라우저 캐시 적중), 로드 끝나면 다시 그리기 예약, 실패 = 자리표시. 보관은 모드·씬 왕복 때 비운다.
6. **종류별 그리기**(25% 화면에 보이는 정보만, `boardCanvasDraw.ts` 순수 함수 — 시험은 기록하는 가짜 2D 문맥):
   레퍼런스(한 장/여러 장 격자 배치는 지금 카드와 같은 규칙·영상 ▶·오디오 ♪·서버에 없음 빨간 빗금·'이 PC 에만' 마크) · 리스트(모은 썸네일 격자·빈 칸·빗금) · 글(배경·잘린 글줄 — 기존 `cutTextForView`) ·
   모델(이름·옵션 글줄) · 머리글(글씨 크기·색) · 세트(이름) · 생성(완료 = 결과 그림·S/★·색 띠·흐림 / 대기·실패·삭제 = 상태 색·글). Comfy·View·Input·Output·Render 는 DOM 그대로.
7. **접근성** — 그림 카드 틀에 `aria-label`(종류·이름)·지금 tabIndex 그대로, 포커스가 들어오면 예외(DOM 몸통)라 안의 단추로 Tab 이 간다.
8. **시험** — 그리기 함수(종류별 호출·빗금·마크) · 보드(표식 켬 + 확정 25% 이하: 그림 카드는 몸통 DOM 없음·canvas 하나 / 선택·올림·포커스·편집·가림 전파 카드는 몸통 DOM / 표식 끔이면 지금과 같음 / 제스처 도중 모드 안 바뀜).
9. **실측(조건)** — 같은 실제 씬 사본·고정 빌드·표식 켬 vs 끔: CPU 4배 휠 축소 메인 30% 넘게 감소·33ms 초과 감소 · 휠 확대·이동 나빠지지 않음 · 25% 경계를 넘는 확대에서 쉼 정리 한 프레임(몸통 붙이기) 측정·기록 ·
   모드·씬 왕복 뒤 그림 보관 회수. 그리고 같은 카메라 나란히 사진(표식 끔/켬)을 Jay 에게.

## Codex 1차 검토(`01a1c576…`, `gpt-6-astra`, 읽기 전용) → 수정 요청

P1 ① 틀에 tabIndex 가 없고 Tab 대상은 몸통 안이라 몸통을 빼면 키보드로 들어갈 길이 없다(Tab 은 노드 선택기) ② '배열 뒤 카드로 가림 전파'는 실제 쌓임(선택 z5·glow z4)과 다르고, 그림판끼리도 아래 카드 틀의 테두리·그림자가 위 카드 그림 위에 놓인다.
P2 ③ 쉼 정리(`settleNow`)는 컬링 집합이 같으면 돌아가 25% 경계·확정 배율을 놓친다 ④ `cullRect` 는 새 카드가 없으면 안 바뀌어 큰 카드가 그림판 밖으로 잘릴 수 있다 ⑤ 범위 선택 미리보기는 틀·`.linb-node` class 를 직접 바꿔 그림 카드에서 사라진다 ⑥ 잰 높이를 무조건 고정하면 같은 개수 다른 레퍼런스·머리글(폭도 자동)이 낡는다 ⑦ 몸통을 떼면 글 칸 스크롤 같은 로컬 상태가 사라지고, 영상 재생·세트 폴더 드롭은 몸통 이벤트에 기댄다 ⑧ 썸네일 실패 → 원본 재시도 → 최종 실패(재조회)를 '자리표시'로 줄이면 안 되고, 다시 그리기 입력이 카드 객체보다 넓다(연결 입력·필터·fill 등). 그리고 몸통 떼기와 그림 갱신이 다른 프레임에 보이면 안 된다.

## 설계안 v3 (Claude — 위 지적을 가장 단순한 쪽으로)

v2 와 다른 것만:

- **겹치는 카드는 그리지 않는다**(②): 그림 카드는 다른 어떤 보이는 카드(DOM 전용 종류 포함)의 사각형과도 겹치지 않아야 한다 — 사각형을 16 세계 px 넓혀서(포트 돌출·그림자) 판정. 그러면 그림 카드끼리·그림 카드와 DOM 카드 사이에 쌓임 순서가 생기지 않는다. 선택·glow 카드는 DOM. 겹침 판정은 카드·높이가 바뀔 때만(정렬 후 훑기).
- **키보드**(①): 카드 안에 초점이 들어가 있는 동안(보드의 focusin/focusout, `relatedTarget` 이 아직 카드 안이면 유지)은 **그림판 모드 전체를 끈다**. Tab = 노드 선택기 동작은 그대로. 그림 카드 틀에 `aria-label`(종류·이름).
- **쉼 확정**(③): `useSceneViewport` 가 배율이 바뀔 때마다(휠·버튼·맞춤·씬 전환 어느 길이든 applyTransform 에서 배율 비교) 200ms 타이머를 다시 걸고, 끝나면 `{ lodLow, zoom }` 상태를 한 번 낸다. 같으면 안 낸다. 컬링 쉼 정리와 독립.
- **덮는 범위**(④): 그림판 = 그릴 카드들의 외곽 상자(컬링 사각형 아님) — 그린 카드는 늘 통째로 덮인다. `cullRect` 가 없으면(초기·컬링 꺼짐) 그림판 모드 끔. 뒷면 상한 넘으면 배율을 낮춘다.
- **범위 선택·연결·자르기 중**(⑤·Q3): 시작부터 끝·취소까지 그림판 모드 끔(전부 DOM). 시작 한 프레임 비용은 실측해 기록.
- **크기**(⑥): 그리는 카드는 크기가 정해진 것만 — 고정 폭·높이 카드, 자동 높이 레퍼런스는 **잰 높이가 지금 내용으로 잰 것일 때만**(잴 때 refs 의 경로·종류를 이은 열쇠를 함께 보관, 다르면 DOM 으로 다시 잼). 머리글(폭도 자동)은 그리지 않음 → 그릴 종류 여섯(레퍼런스·리스트·글·모델·세트·생성).
- **로컬 상태·몸통 이벤트**(⑦): 안을 스크롤한 카드(틀의 onScrollCapture)는 씬을 바꿀 때까지 DOM. 마우스 올림 = 틀의 pointerenter/leave, 바깥 끌어 넣기 = 틀의 dragenter → DOM(다음 이벤트부터 몸통이 받음). 브라우저 실측에 영상 재생·세트 폴더 드롭·첫 더블클릭 포함.
- **그림 실패**(⑧): 그림판에서 썸네일을 못 읽은 카드는 **DOM 몸통으로 돌린다**(기존 MediaThumbnail 의 원본 재시도·최종 실패·재조회 그대로). 다시 그리기 = BoardCanvas(memo) props(그릴 카드·`cardsById`·`genData`·`resolvedEdges`·필터·fill·폴더 표시) 변화 + 서버 판정·어셋 버전 직접 구독. 그림 보관은 주소 열쇠, 씬 전환·모드 끔 때 비우고 늦은 로드 콜백은 세대 번호로 버림.
- **같은 프레임**(⑧ 끝): 모드·예외 변화로 인한 다시 그리기는 rAF 가 아니라 같은 커밋의 `useLayoutEffect` 에서 동기로 그린다(몸통 붙이기·떼기와 같은 프레임). rAF 는 그림 로드 끝에만.

## 설계안 v4 (Claude — v3 에서 바뀐 것만)

- **그릴 종류 다섯**: 레퍼런스(그림만 — 영상·오디오 ref 가 하나라도 있으면 DOM, 썸네일 없는 미디어도 여기 걸림) · 리스트 · 글 · 모델 · 생성. 세트(태그 편집·폴더 놓기)·머리글(자동 폭)은 DOM.
  → 영상 마우스 올림 재생·세트 폴더 놓기·세트 태그 키보드 진입 문제가 생기지 않는다.
- **키보드 첫 진입**: 노드 선택기가 Tab/Shift+Tab 을 쓰지 않고 양보하는 그 자리(useSceneKeyboardShortcuts·SceneBoard 의 Tab 양보 분기)에서 보드에 `onTabYield` 를 부르고, 보드는
  `flushSync` 로 '키보드 모드'(그림판 전체 끔)를 켠다 — keydown 처리 안에서 몸통이 붙으므로 브라우저 기본 초점 이동보다 먼저다. 키보드 모드는 보드에서 포인터를 누를 때까지 유지(카드 사이 Tab 이동 중 되돌아가지 않음).
- **쉼 확정**: `useSceneViewport` 의 `requestSettle()` = 200ms 타이머(다시 부르면 다시 검). 부르는 곳 = applyTransform 에서 배율이 바뀌었을 때·가운데 버튼 손 뗌·화면 맞춤 전환 끝(250ms 전환 뒤)·툴바 배율 단추.
  타이머가 끝날 때 팬·맞춤 전환이 살아 있으면 다시 미룬다. 씬 전환은 예약을 지우고 새 씬의 값으로 바로 확정. 보드는 끌기 동안 그림/DOM 나눔을 끌기 시작 때 것으로 얼린다(끄는 카드만 DOM 예외).
- **다시 재기**: 자동 높이 레퍼런스는 DOM 으로 잴 때 `structSig` 를 함께 보관하고, 지금 `structSig` 와 같을 때만 그린다. 다르면 DOM → 기존 측정 effect(structSig 의존)가 다시 재고, **높이가 같아도** 보관 sig 를 갱신. `cv` 틀(그림 카드)에서 잰 값은 높이·sig 어느 것도 갱신하지 않는다.
- **그림 실패 기억**: 그림판이 못 읽은 썸네일 **주소** 집합 — 그 주소를 쓰는 카드는 DOM(기존 MediaThumbnail 재시도·재조회). 모드 끔·마우스 올림 왕복으로 지우지 않고 씬 전환 때 비움. 주소가 바뀌면 자연히 새로 시도.
  그림 로드 끝 rAF 는 실행 시점의 최신 그릴 집합(ref)으로 그린다 — 그사이 DOM 으로 돌아간 카드는 칠하지 않는다.
- **16px 문구 정정**: "16px 넓힌 사각형으로 일반 카드 겹침을 그리지 않는다 · 돌출 UI(glow 그림자 26px·편집 창·배지)의 쌓임은 그 카드가 선택·glow·편집 예외로 DOM 이라 기존대로이며, 비교 사진(선택·glow·창 포함)으로 확인한다".
- **성능 판정(실측 전 고정)**: 같은 빌드·씬·카메라·자료, 표식만 끔/켬, 준비 실행 뒤 AB/BA 번갈아 5쌍, 구간 = 입력 시작 ~ 마지막 입력 뒤 1초(쉼 확정 포함).
  CPU 4배 휠 축소: 메인 중앙값 30% 넘게 감소·33ms 초과 중앙값 감소 / 휠 확대·이동(맞춤·25%)·마우스 올림 왕복·범위 선택·연결 시작: 메인 중앙값 +5% 이하·긴 프레임 중앙값 +1 이하 /
  최대 프레임은 회차별로 보고 평균으로 상쇄하지 않음 / 경계 결과는 원시 5쌍 보존·판정 보류(유리한 회차 추가 금지). 이 PC 그대로(1배)는 기록만.

## Codex 3차 검토 → 수정 요청(그룹 끌기의 새 겹침 · Tab 양보 경로 전부 · 레퍼런스별 측정 열쇠 · 생성 영상 카드)

## 설계안 v5 (Claude — v4 에서 바뀐 것만)

- **끌기·크기 조절 동안 전부 DOM**: 카드·그룹 이동(선택 안 된 그룹 멤버 포함)·크기 조절이 시작되면 그림판 모드를 끄고, 끝·취소 뒤 최신 위치로 다시 나눈다(v4 의 '나눔 얼림' 철회).
- **Tab 양보 경로 전부**: `onTabYield` 는 노드 선택기 반환값뿐 아니라 Tab/Shift+Tab 이 기본 초점 이동으로 가는 모든 양보 경로(입력 요소 조기 반환·의도 없음·Shift+Tab)에서 기본 이동 전에 부른다.
  모달·씬 전환 차단은 그대로. 키보드 모드는 보드 포인터 누름에서 풀리되, 카드 안 초점·편집 예외는 그대로 DOM.
- **레퍼런스별 측정 열쇠**: 보드 전체 `structSig` 와 별도로 레퍼런스 카드마다 `refs` 의 경로·종류를 이은 열쇠를 DOM 으로 잴 때 보관. 지금 열쇠와 같을 때만 그린다.
  다르면 DOM → 그 카드가 붙은 커밋 뒤 그 카드를 재고 **높이가 같아도** 열쇠 갱신. `cv` 틀에서 잰 값은 높이·열쇠를 갱신하지 않는다.
- **미디어 예외 넓힘**: 실제로 보일 미디어가 영상·오디오이거나 필요한 그림 주소가 없는 카드는 종류와 상관없이 DOM(레퍼런스·리스트 항목·생성 결과 모두 — 생성 영상의 마우스 올림 재생 포함).
- **성능 판정 보탬**: 비악화 대상에 카드·그룹 이동·크기 조절의 시작/끝 프레임을 더한다. 새 순간 멈춤(최대 프레임이 기준보다 뚜렷이 김)이 보이면 통과로 치지 않고 판정 보류·원인 확인.

## Codex 4차 검토 → 합의 (확정 문구)
