# 크게 보기 Ctrl 카드 단추 · 머리줄 정리 · 카드 C → 새 코멘트 창 (2026-11-05)

## 정한 동작

- 크게 보기 머리줄 = **[🖌 Edit] [⧉ History]** 만(이미지·영상 같은 이름). C·다운로드는 뺀다 — Ctrl 단추에 같은 것이 있다. `c` 키(코멘트 모드)는 그대로.
- **Ctrl 을 누르고 있는 동안** 원본 위에 격자 카드에 마우스를 올렸을 때와 같은 단추가 뜬다.
  - 생성물 = 라이브러리 카드 부품(GenerationCard) 그대로: S·T·C·⠿·ⓘ·⤓·@·↻·계보·폴더 이름표. C = 이 창의 코멘트 모드.
  - 어셋 = 어셋 칸 부품(AssetCell) 그대로: S(소스)·T·C·ⓘ·📋·📂·⤓. C 는 ② 전까지 지금의 어셋 코멘트 창(크게 보기를 닫고 연다).
  - 떼면 사라진다. 단, 뜬 단추를 한 번 누르면(태그 입력·공유 메뉴 등) 그 장을 벗어나거나 단추 밖을 누를 때까지 남는다.
  - 영상은 아래 단추 줄·이름표를 재생 막대 위로 올린다. Ctrl+우클릭(바로 캡쳐)·Ctrl+휠은 그대로(단추 밖은 누름이 원본으로 간다).
  - ⓘ·계보·폴더 이름표·↻ 는 크게 보기를 닫고 연다(정보 창은 크게 보기 아래 겹이라).
- **카드의 C**(라이브러리·공유 격자, 캔버스 노드·결과 모아보기, 편집 탭 풀) = 이번 코멘트 창(그리기). 그림을 모르는 허브·오디오·미디어 없음은 종전 작은 창.
  알림에서 여는 코멘트는 종전 그대로.

## 구현 기록

- 머리줄: `MediaPreview` 의 C·다운로드 단추를 빼고 [🖌 Edit] [⧉ History]. 머리줄 C 의 코멘트 수 조회(commentCounts)와 그 CSS(`.cm-cbtn`)도 함께 뺐다.
- Ctrl 카드 단추: 생성물은 `GenerationCard` 를 원본 사각형(코멘트 그림 겹치기와 같은 측정)에 겹치고 그림만 감춘다(`assets.css .mp-card-layer`). 생성물은 뜰 때 `getGeneration` 으로 읽고 `libraryChanged`·`generationTagsSettled`·코멘트 저장 때 다시 읽는다. 어셋은 `AssetsView` 가 `registerAssetPreviewCard` 로 칸(AssetCell)을 그려 준다(대상 url 이 그 화면의 것과 같을 때만).
- ⓘ·폴더·작은 코멘트 창·어셋 C 는 크게 보기가 실제로 닫힌(언마운트) 뒤에 연다 — 닫기가 기록 뒤로가기(비동기)라 먼저 열면 꼬인다. 계보 단추는 머리줄 [History] 와 같은 길.
- 카드 C: App `openCardComment` → `cardCommentOpensDrawing` 이면 `AppOverlays` 가 `CommentDrawModal` 을 띄운다(격자·공유 격자·캔버스 노드·결과 모아보기·편집 풀). 알림의 코멘트는 종전 작은 창.
- 범위 보정: 기존 초점 시험(`modalFocusWindows`)이 머리줄 다운로드를 '첫 단추'로 썼다 → 닫기 단추로. 지운 `.cm-cbtn` CSS 때문에 `comment-draw.css` 를 범위에 더했다.
- 확인: 시험 기록 4건 + 프런트 전체 시험 510개 파일·6,162건 통과(2026-11-05, 시험 기록 아님). 화면 실측 전 — Jay 5273 확인 남음.
