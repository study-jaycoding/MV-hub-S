### 이번 작업에서 밟은 함정 (다음 세션용)

1. **bash heredoc 은 본문 바이트가 크면 종결자가 잘려 `unexpected EOF`** — 한글 많은 스크립트는 파일로 써서 실행한다.
2. **Python 삼중따옴표 안의 `" + BS + "` 는 문자 그대로 들어간다** — 백슬래시는 문자열 밖에서 `chr(92)` 로 이어 붙인다(P4-09 로 실제 유입, Codex 가 잡음).
3. **`git ls-files` 는 한글 파일명을 8진수로 이스케이프** — `-c core.quotepath=false` 없이는 존재 검사가 실패한다.
4. **finding 을 문서로 옮길 때 과장·확장** — "약 3.5초", "이벤트 로그", "요청→완료", 엔드포인트 이름을 근거 없이 넓혀 11건이 재지적됐다. 코드 근거 file:line 의 문자 그대로만 옮긴다.
5. **`git archive` 스냅샷에는 미추적 파일·`.git` 이 없다** — 리뷰어가 인계 노트·커밋 해시를 못 보므로 별도로 넘긴다.
