## C안(그림 그대로)

- 머리줄 오른쪽에 머리줄 높이를 꽉 채우는 칸(폭 92px) — 아이콘 위·글자 아래. 머리줄 글은 오른쪽 104px 비움.
- 상태 넷:
  - ① 기본 — 라임 바탕·검은 글자, 저장 아이콘 + "저장".
  - ② 저장 중 — 흐린 라임, 도는 표시 + "저장 중" + 작은 줄에 단계("NAS 3/8" · "정리" · "검사"), 누를 수 없음.
  - ③ 저장됨 — 어두운 초록 바탕·라임 글자, 체크 + "저장됨" + 저장 시각, 3초 뒤 ①.
  - ④ 막힘 — 어두운 빨강 바탕·빨간 글자, 경고 + "남은 빈 N"(검사에 걸림) 또는 "저장 안 됨"(NAS 옮기기 실패·그 밖) + 작은 줄 "다시 저장". 걸린 빈 목록은 머리줄 상태 줄 아래에 펼침(빈마다 '내 것/다른 허브'·개수·쓰는 중·어떻게 풀리는지). 다시 누르면 다시 저장.
- 걸린 빈 목록은 머리줄에만 보인다(전에는 알림 목록에도 넣었다 — 두 번 보이지 않게 뺌). 상태 줄 글(저장했습니다 — …)은 그대로.
- 저장 흐름 자체(쓴 것 NAS·안 쓴 것 정리·검사 뒤 저장)는 바꾸지 않는다.
