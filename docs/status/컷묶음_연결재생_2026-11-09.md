# 공유 & 리뷰 탭 컷 카드 — 고른 컷 묶음 + [▶ N컷 연결 재생] (2026-11-09)

owner: Claude(구현) · reviewer: Codex(묶음 검토 때) · status: 구현 중 · touched_paths: 아래 계약 · updated: 2026-11-09
위 속성의 `active`는 이 작업의 진행 기록이라는 문서 위상이며, 구현 완료·검토 완료·배포 승인을 뜻하지 않는다.

## Jay 가 정한 것 (2026-11-09, 시안으로 확정)

시안 그림은 세션 임시 폴더에서 만들었다(저장소에 두지 않음). 결정만 옮긴다.

- 그리드 보기에서 **붙은 컷(같은 줄의 이웃)** 을 둘 이상 고르면 카드마다의 라임 선택 테두리 대신 **라임 선 하나로 한 판**에 묶는다. 사이 틈도 같은 판으로 메운다. 카드 아래 왼쪽에 번호 1·2…(재생 순서 = 격자 순서).
- 묶음 가운데에 **알약 단추 `▶ N컷 연결 재생`**(C안 — 비교한 원·유리·세로 고리·나뉜 고리·작은 원+배지는 기각).
- **떨어진 카드(Ctrl)·다른 줄 = "마지막 고른 카드 위"**: 카드마다 지금의 라임 테두리 + 번호, 알약은 마지막으로 고른 카드 표지 가운데. (기각: 점선으로 잇기, 화면 아래 가운데 알약)
- 컷 카드를 고를 때 화면 아래 **"N컷 선택 · 모아보기 · 선택 해제" 막대는 띄우지 않는다** — 묶인 모양이 선택 표시, 빈 곳 클릭·Esc 로 풀린다.
- 알약을 누르면 아래로 펼치지 않고 **지금의 모아보기 창 그대로**, 처음부터 **[연결]** 로 열려 1번 컷부터 재생한다.

## 내가 정한 것 (Jay 미확인)

- 알약은 고른 것이 **2장 이상이고 모두 컷(하위 폴더 없음)** 일 때만. 한 장이면 두 번 클릭이 그대로 모아보기.
- 이번 범위는 **그리드 보기만**. 리스트·표 보기는 지금 그대로(선택 막대 포함) — 한 줄에 하나라 '옆' 이 없고 줄 높이가 알약보다 낮다.
- 선택 막대를 숨기는 것은 **컷(잎)만 골랐을 때**. 에피소드 카드(하위 폴더 있음)를 고르면 알약이 없으니 막대의 [모아보기]를 남긴다.
- 알약으로 연 [연결]은 그 한 번만이다 — 저장해 둔 보기 방식(`cutReelMode`, 두 번 클릭·막대가 여는 방식)은 바꾸지 않는다. 창 안에서 전환하면 지금처럼 저장.
- '마지막 고른 카드' = 방향키·클릭이 남긴 자리(`cursorRef`). 마퀴·Ctrl+A 처럼 자리가 없으면 고른 것 중 격자의 마지막 카드.
