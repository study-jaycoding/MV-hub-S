# 접힌 '자료 관리' 제목 줄의 '복원 보류 N' (2026-11-14)

Jay 11-14 "넣기". 저장 1C-1 화면 시안 2판(Jay 11-13 "진행")의 남은 한 가지 — 접힌 '자료 관리' 묶음 제목 밑 줄에 '복원 보류 N' 을 주황으로 보인다. 1C-1 때는 `SettingsPanel.tsx` 가 범위 밖이라 빠졌다([1C-1 기록](저장통합_1C_복원세대_2026-11-13.md)).

- N = 펼친 칸의 '복원 전에 남겨 둔 것' 개수 합(캔버스 보관본 + 편집 문서 + 카드 정리 대기). 같은 계산 함수를 두 곳이 쓴다.
- 보류가 0 이면 보이지 않는다. 자리는 시안대로 백업 세트 뒤·서버 상태 앞.

## 결과

- `CanvasArchiveSection.tsx`: 보관본 읽기를 `useStorageRecovery()`, 개수 셈을 `heldRecoveryCounts()` 로 떼었다(동작 그대로). `SettingsPanel.tsx`: 같은 둘로 '복원 보류 N' 을 접힌 줄에 넣고 순서는 `dataFoldParts()` 가 정한다.
- 시험: 펼친 칸(캔버스 1·편집 1·카드 1)과 접힌 줄 셈이 같다(3) · 다른 계정이면 0 · 순서와 0 일 때 빠짐. 설정 창·캔버스 관련 기존 시험 10개·build·lint:architecture 통과(시험 기록 14, 아래).
- 실제 화면 확인은 안 했다(보류 자료가 있어야 보임). 리뷰는 dev 묶음 리뷰 때.
