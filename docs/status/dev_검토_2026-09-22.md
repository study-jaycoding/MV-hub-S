- **아이콘 크기는 옛 글자의 잉크 높이로 역산한다**(크기 = 잉크높이 × 24 ÷ (뻗침 + 선 굵기), 짝수로). 단추 바깥 크기는 CSS 로 고정한다 — `padding:0` 이 없으면 전역 button 여백이 되살아난다(씬 팝업 ×: 37x30 → 40x28).
- **화면 배율**: 8배 캡처 값은 배율 1·1.25·1.5·2 에서 같았다. 대조 실험(예전 15px 아이콘을 페이지 안에서만 되살림)도 배율 1·2 모두 0.5px 로, 이 치우침이 배치 단계에서 생긴다는 뜻이다. 배율 그대로 찍으면 1.25·1.5 에서 **모든 단추가 기기 픽셀 격자 때문에 ±0.5px 안팎 흔들린다 — CSS 로는 못 고친다.**
- **소수 좌표의 잔여**: Library 카드(0.64~0.83)·씬 변형 팝업 속 카드(0.47)·관리자 창(0.46)·설정 그룹(0.5)·부분 수정(0.45)은 **그 카드·창이 소수 좌표에 놓여서**다. 정수 좌표인 설정·계정 관리·단축키 창은 0 이다. 단추 쪽에서 없앨 수 없다.

## 5. 남은 것

- **실제 Resolve 미검증**: `already_open` 경로와 라이브러리 연결(Connect) 자동 클릭은 실제 Resolve 로 돌려 보지 않았다. 절차 조건(Codex): 저장된 프로젝트일 것 · 이름이 라이브러리에서 하나뿐일 것 · 격리 서버 환경을 먼저 확인할 것 · 저장 여부는 `Project.db` 수정 시각이 아니라 화면(저장 창 없음·재로딩 없음)으로 볼 것. Connect 는 Resolve 등록 목록을 바꾸므로 별도 승인.
- **미러 안내 문구**: 드라이브 대응을 모를 때도 "같은 렌더 폴더를 쓰는 다른 프로젝트가 N개"라고 말해 실제(판정 불가)보다 강하다. 문장은 `routers/manage.py` 가 만드는데 그 파일을 다른 세션이 고치는 중이라 두었다 — [EXPORT_SYNC_DESIGN.md](../EXPORT_SYNC_DESIGN.md) 남은 한계 ⓪-다.
- **가운데 정렬 창의 반 픽셀**(3절) — 창 배치의 성질이라 별건으로 둔다.
