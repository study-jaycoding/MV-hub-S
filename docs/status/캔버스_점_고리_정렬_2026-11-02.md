# 캔버스 — 연결점 고리 안의 점이 위로 치우치던 것 (2026-11-02)

owner: Claude · reviewer: (묶음 리뷰) · status: 구현 완료(dev 커밋 · Jay 화면 확인 남음) · touched_paths: 아래 계약 · updated: 2026-11-02

Jay 스크린샷(캔버스 약 2.5배 확대): 레퍼런스 카드의 파란 고리 안 회색 점이 위로 치우쳐 보였다. 픽셀로 재니 가로는 맞고 세로만 고리가 점보다 1.4화면px 아래였다.

원인: 레퍼런스 카드는 폭 152px·그림 4:3 이라 높이가 늘 115px(홀수)이고 가운데가 57.5px 다. 고리는 CSS 상자라 크롬이 정수 칸(58px)에 붙이고, 점은 SVG 라 57.5px 에 남는다. 0.5px 차이가 확대 배율만큼 벌어진다.

재현: 임시 크롬에 실제 `scene.css` 를 걸고 2.5배로 잼. 높이 115px 은 1.0화면px 어긋나고, 높이 116px 은 0.04화면px, 높이 115px 에서 점을 정수로 반올림하면 0.1화면px 미만(카드 y 가 소수여도 같음). 앱 화면 실측은 아니다.

고친 것: `SceneBoard.tsx` 의 연결선 끝(`edgeEnds`)과 임시 연결선 시작을 `Math.round` 로 정수 칸에 놓는다. 접힌 그룹 막대 연결은 점이 없어 그대로 둔다.

남은 한계: 자동 높이 카드(레퍼런스 여러 장·Input·Output)는 측정값 `offsetHeight` 가 이미 정수라, 실제 높이가 소수면 고리와 1px 안쪽으로 어긋날 수 있다(계산, 미실측). 한 장 레퍼런스는 높이가 115px 정수라 해당 없다.
