## 1. 무엇을

힉스필드는 워크스페이스 **전체 잔액**만 보여 준다. 그룹에 한도를 줘도 개인은 "내가 얼마를 쓸 수 있는지"를
못 본다. 우리 앱이 그 칸을 채운다 — **내 몫 · 내 사용 · 내 남은 양**을 보여 주고, 사용량을
시/일/주/월 · 모델 · 개인 · 그룹 · 프로젝트로 갈라 본다.

Jay 결정(2026-09-23):

| 결정 | 값 |
|---|---|
| 개인 할당량 | 그룹 한도 ÷ 인원이 기본, 사람별 덮어쓰기 가능 |
| 할당량 초과 | 화면 경고만 (실제 강제는 힉스필드 그룹 한도) |
| 정기 충전 | 손 입력 우선, 비면 프로젝트 '매월 예산' 합에서 파생 |
| 개인 '남은 양' | **이번 기간 내 몫만.** 그룹 이월은 '그룹 여유분'으로 따로 표시 |
| 그룹 이동 | 이전 사용량도 **지금 속한 그룹**으로 친다(화면에 '현재 소속 기준' 명시) |
| 환불 | 개인 사용량에 **반영하지 않는다**(팀 거래 장부에만) |

## 2. 계산 규칙

기호: 그룹 한도 `L`(NULL=무제한), 주기 `P`(day/week/month), 사람별 덮어쓰기 `o_i`(NULL=자동),
이번 기간 내 사용 `U_i`.

```
고정분  F   = Σ o_i (덮어쓴 사람들)
자동몫  a   = (L − F) / (자동인 사람 수)       # 분자가 음수면 0, 자동 인원 0명이면 a = null
내 몫   Q_i = o_i 있으면 o_i, 없으면 a
내 남음 R_i = Q_i − U_i                        # 음수면 "초과"로 표시(막지 않는다)
```

**경계 (전부 인수 시험으로 고정한다)**

| 경우 | 결과 |
|---|---|
| 자동 인원 0명(모두 덮어씀) | `quota_auto = null` — 나눗셈을 하지 않는다 |
| 그룹 멤버 0명 | 그룹 카드만, 개인 값 없음 |
| `L = 0` | 자동 몫 0 · 모두 "쓸 몫 없음" |
| `L = NULL`(무제한) | 자동 몫 없음. **덮어쓴 사람만** 그 값이 몫이 된다(개인 목표치). 나머지는 "제한 없음" |
| `F > L` | 자동 몫 0 + 그룹 카드에 "덮어쓴 합이 한도를 넘음(F/L)" 경고. 저장은 막지 않는다 |
| 소수 (100÷3) | 반올림하지 않는다. 화면은 둘째 자리까지 `≈` 로 표시하고, 합이 한도와 0.01 어긋나도 경고하지 않는다 |
| 입력값 | 유한한 0 이상 숫자만. NaN·무한대·음수는 400 |

**기간과 시계**

- 기간은 그룹 주기 `P` 를 따르고, 달 경계는 충전 기준일(`topup_day`)을 쓴다 — 그룹 카드와 같은 시계.
- 시계는 **KST 고정**이다(2026-09-23 구현 완료, §5 P0-2). 서버 OS 가 UTC 여도 경계가 안 밀린다.
- **개인 몫에는 이월이 없다.** 기간이 바뀌면 `U_i` 가 0 부터 다시 센다. 그룹 카드의 이월은 지금 그대로 두고
  화면에서 **'그룹 여유분'** 으로 따로 보여 준다(Codex 지적 ①-3: 두 숫자가 다른 돈을 가리키면 안 된다).
- 한도를 올리면 즉시 반영된다. `Q_i` 는 저장값이 아니라 그때의 `L`·인원·덮어쓰기로 매번 계산한다.
  Jay 예시: `L=4,000`·자동 1명 → `Q=4,000`, `U=4,000` → `R=0`. `L` 을 5,000 으로 올리면 `R=1,000`. ✓

**개인 사용량이 실제 차감과 다를 수 있는 자리 (화면에 그대로 밝힌다)**

- **미상**(실제·견적 둘 다 없는 생성물)은 0 으로 세고 건수만 센다 → 남은 양이 실제보다 커 보인다. 건수를 함께 표시.
- **환불**은 개인에 반영하지 않는다(Jay). 팀 거래 장부(`ledger`)에만 있다.
- **긴급 충전**은 그룹·개인 몫을 늘리지 않는다(풀 카드 표시용) — 늘리려면 매니저가 한도를 올린다.
- **날짜 없는 삭제분**(tombstone with no `created_at`)은 기간 집계에서 빠진다 → 그룹 카드의 '미분류'로 표시.

## 3. 데이터 모델 (추가만)

| 테이블 | 추가 칸 | 뜻 |
|---|---|---|
| `workspace_credit_group_member` | `quota REAL NULL` | 사람별 덮어쓰기. NULL=자동 몫 |
| `workspace_credit_plan` | `recurring_topup REAL NULL` | 정기 충전 손 입력. NULL=프로젝트 '매월 예산' 합에서 파생 |

**★저장 규칙 — 조용히 지워지지 않게 (Codex 치명 ①-2)**

현재 `save_settings` 는 워크스페이스의 멤버 배정을 **전부 지우고 다시 넣는다**. `quota` 열만 더하면
구버전 앱 저장·그룹 색 저장·'추정 맞추기'(`remaining_override`) 저장에도 quota 가 사라진다.
→ 저장 전에 기존 행을 `email → {group_id, quota}` 로 읽고, **본문에 `quota` 키가 없으면 읽어 둔 값을 그대로
다시 넣는다.** 시험으로 고정할 경로: ①구버전 전체 본문 ②그룹 한 칸 저장 ③그룹 이동 ④그룹 삭제 ⑤추정 맞추기.

## 4. API 계약

### 4-1. 세 상태(키 없음 / null / 값) — Codex 치명 ①-1

Pydantic 기본값 `None` 은 "키 없음"과 "명시적 null"을 구분하지 못한다. `model_fields_set`(또는
`model_dump(exclude_unset=True)`)로 **키가 왔는지**를 보존하고, 저장소는 sentinel 로 3상태를 받는다.

- `quota`: 키 없음=유지 · `null`=자동으로 되돌림 · 숫자=덮어쓰기
- `recurring_topup`: 키 없음=유지 · `null`=파생으로 되돌림 · 숫자=손 입력

### 4-2. 읽기 모델

- `groups[]` 에 추가: `quota_fixed`(고정분 합) · `quota_auto`(자동 몫, 없으면 null) · `quota_over`(F>L)
- `members[]` 에 추가: `quota`(원본) · `quota_effective` · `used_period` · `remaining` · `unknown`
- 멤버 응답 `my_group` 에 추가: `my_quota` · `my_remaining` · `my_quota_source`(`manual`|`auto`|`none`) ·
  `group_carryover`(그룹 여유분, 이월분)
- `pool` 에 추가: `monthly_topup_source`(`manual`|`derived`)

### 4-3. 공통 사용량 필터 (Codex 치명 ①-5, 과함 ④-2)

`_agg_where` **한 곳**에 필터 계약을 두고 `team-overview`·`team-timeseries`·내보내기 2종이 그대로 재사용한다.

| 파라미터 | 뜻 |
|---|---|
| `date_from`·`date_to` | 없으면 **전 기간**(기본) |
| `time_from`·`time_to` | 시 단위 선택일 때만. 지금은 timeseries 에만 있다 → 네 곳 모두로 |
| `project_id`·`creator_uid`·`model` | 기존 |
| `account_email` | **신규** — 사람 단위 드릴(quota·그룹과 같은 키) |
| `group_id` | **신규** — `workspace_id` 와 함께일 때만. 서버가 그룹 소유를 확인하고 이메일 집합으로 바꾼다 |

권한: `group_id`·`account_email` 은 **매니저(read_all)만**. 일반 멤버 요청은 지금처럼 서버가 본인으로 강제하고
받은 값은 무시한다. 이메일 집합이 비면 "결과 없음"(전체로 폴백하지 않는다).

## 6. 화면

1. **내 몫 카드**(`CreditPoolSection`): `내 몫 / 사용 / 남음` + 게이지, 미상 건수, 초과 경고.
   그룹 이월이 있으면 **'그룹 여유분'** 을 한 줄 아래에 따로 표시한다(내 몫과 섞지 않는다).
2. **관리 표 '크레딧' 시트**: 사람 행에 `몫` 칸(비우면 자동). 그룹 행에 고정분 합·자동 몫·초과 경고.
3. **기간을 대시보드 전체에** 적용: 지금은 막대 차트에만 걸린다. 기본값은 **전 기간**(현 동작 보존).
4. **드릴 완료 조건**: 멤버·프로젝트·그룹 중 하나를 고르면 **상단 통계 · 모델 · 프로젝트 · Yield · 기간 차트 ·
   내보내기 · 내 몫 카드**가 **모두 같은 필터 상태**를 읽는다. 잔액 추이는 워크스페이스 값이라 드릴 대상이 아니다.
5. **내보내기**: 현재 기간·드릴·모델을 CSV 에 그대로 반영한다("엑셀 연동"의 뜻 = 화면과 같은 조건의 CSV).
6. 잔액 추이의 달 세로선은 1일이 아니라 **충전 기준일**에 긋는다.
