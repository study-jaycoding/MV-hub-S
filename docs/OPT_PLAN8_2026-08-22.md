- BK-2 quiet-dirty 백업 실패 삼킴 후 dirty 소거 → _backup_once 성공 반환·성공시만 정산. ★독립 diff
- MDB-1 elapsed_by_job_ids 가 부재 manage_hub.db 를 생성(빈 DB→백업 검증 실패) → mode=ro URI.
- AST-1 capture/ref-import 커밋 후 취소 시 트리 캐시 무효화 생략 → commit_attempted+finally 선례 적용.

- DB-1 풀 컨텍스트가 Exception 만 롤백 → BaseException(취소 시 미완료 트랜잭션 풀 잔류 차단).
- MDB-2 team_overview 다중 SELECT 시점 불일치 → 명시 읽기 BEGIN(단일 WAL snapshot).

## 웨이브 2 — 중위험 (7건, 각 독립 diff)

- TR-1+TR-2 삭제 tombstone·복원 dirty 를 본체와 한 transaction-root 로(같은 content DB 라 가능,
  caller-supplied connection helper, 중첩 get_connection 금지).
- BK-1 백업 due 판정 scope 를 실행까지 전달(재캡처 창 제거)+전환 시 상태 재설정.
- GMC-1+GMC-2 다운로드 세마포어를 event-loop 귀속 공유로(프로세스 상한 6, 모듈 전역 금지)
  + gather return_exceptions=True 전체 회수 후 재전파(형제 즉시 취소 금지).
- DB-2 기존 계정 DB 파일도 init_db(path) 멱등 마이그레이션(비활성 계정 스키마 누락 해소).
- LC-1 lifespan cleanup 경계를 첫 start 전으로 확장+각 cleanup 끝까지 시도 후 원예외 재전파.
