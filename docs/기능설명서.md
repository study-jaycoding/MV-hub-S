# Content Hub — 기능 설명서

> Higgsfield 로 만든 영상·이미지를 팀이 **한곳에 모아 보고·정리·검색·공유·재사용·계보추적** 하는 도구.
> 이 문서는 **기능별 상세 매뉴얼**이다. 빠른 시작만 필요하면 [사용설명서.md](사용설명서.md),
> 서버 운영 상세는 [SERVER.md](SERVER.md), 코드 구조는 [ARCHITECTURE.md](ARCHITECTURE.md) 를 본다.
>
> 기준 포트 **8010** · 로그인 기본 **ON**

---

## 0. 핵심 개념 한 장

- **서버 한 대 + 브라우저 접속**: 팀원은 설치 없이 브라우저로 주소만 친다.
- **서버는 생성하지 않는다**: 생성·재생성은 **각자 본인 PC 의 Higgsfield CLI**(본인 크레딧). 생성 결과는 **내 허브(로컬)** 에 쌓이고, 서버는 **팀에 발행한 것**을 모아 보여준다.
- **토큰은 내 PC 밖으로 안 나간다**: 서버는 Higgsfield 자격증명을 저장하지 않는다.
- **두 가지 로그인 구분**:
  - **허브 로그인**(브라우저 계정) = 신원·권한·"내 작업" 분리.
  - **Higgsfield CLI 인증**(각 PC) = 실제 생성 주체.

## 1. 역할별 시작하기

### 1-A. 서버 운영자 (서버 PC 1대)

```
.\MV_server.bat
```

- 기존 프론트 빌드를 확인한 뒤 백엔드를 기동. dist가 없을 때만 잠금 파일 기준 의존성 설치와 빌드를 수행한다.
- 기본 **포트 8010**, **로그인 ON**(`CONTENT_HUB_AUTH=1`).
- 접속:
  - 같은 PC: `http://127.0.0.1:8010` (★ `localhost` 는 IPv6 폴백으로 ~200ms 느림 → `127.0.0.1` 권장)
  - 같은 네트워크(팀원): `http://<서버 PC IP>:8010` (IP 는 서버에서 `ipconfig` → IPv4)
- 사전 요건: Python(`pip install -r backend/requirements.txt`), Node.js.
- 로그인 끄기(개인/개발, 모두 "나"): bat 의 `CONTENT_HUB_AUTH` 를 `0` 으로.

### 1-B. 팀원 (각자 PC — 로컬 허브 + 에이전트)

작업자 PC 는 **릴리스 설치본**을 쓰고, 실행은 배치 하나가 전부다:

```
.\MV_agent.bat
```

- 로컬 허브(브라우저 화면)와 push 에이전트를 함께 띄운다 — 허브의 내 생성요청을 내 CLI 로
  실행하고, 내 새 결과물을 **내 로컬 허브**에 넣는다(롱폴 이벤트 방식이라 **즉시** 반응.
  팀에게 보이는 것은 내가 발행한 것만이다.
  구버전의 `--watch 30` 숫자는 이제 무시된다 — 30초 폴링이 아니다).
- 창을 닫으면 관련 프로세스가 전부 함께 종료된다(Job Object 보호).
- 전제: 본인 PC 에 `higgsfield auth login` 으로 CLI 가 로그인돼 있어야 한다.
- 개발 클론에서 에이전트만 따로 돌릴 때: `python agent_push.py --server http://<서버IP>:8010 --email <내이메일>`.
- 에이전트를 안 켜도 **탐색·정리·공유는 가능**(생성만 **생성중** 카드로 남았다가 켜면 실행됨).

### 1-C. 일반 사용자 (브라우저만)

주소 접속 → (로그인 모드면) 회원가입/로그인 → 라이브러리 사용.

## 2. 화면 구성

```
┌──────────────────────────────────────────────────────────┐
│ ⬡ MV Hub  작업 공간 공유 & 리뷰 캔버스  검색 ⬚Assets ▦ 🔔 👤 │ ← 상단바
├────────────┬─────────────────────────────────────────────┤
│ 프로젝트    │                                             │
│ 컬러        │            결과물 썸네일 그리드               │ ← 라이브러리
│ 전역태그    │                                             │
│ 생성자      │                                             │
│            │   │ 프롬프트 입력 (하단 도크, Ctrl/⌘+K)    │  │
└────────────┴───┴─────────────────────────────────────┴──┘
```

- **상단바**: 로고(⬡ MV Hub, 클릭 시 관리자 창) → 탭 → 검색 → Assets → 보드 → 알림 벨 →
  이니셜 아바타(계정 메뉴). **워크스페이스 표시·전환은 계정 메뉴 안**에 있다.
- **탭**: **작업 공간**(내 생성물) / **공유 & 리뷰**(공유된 것) / **캔버스**(씬 캔버스 + 히스토리 보기).
- **좌측 사이드바**: 프로젝트 · 컬러 · **전역 태그** · **생성자** 필터.
  (공유 여부는 사이드바가 아니라 **상단 툴바의 S 버튼**으로 거른다.)
- **가운데 그리드**: 무한 스크롤. **그리드는 클릭=선택 · 더블클릭=미리보기**,
  리스트 보기는 클릭=미리보기. 양쪽 다 휠(중간)클릭=정보 팝업.
- **하단 도크**: 프롬프트 입력 → 생성.

## 3. 라이브러리 (탐색·정리)

### 보기
- **무한 스크롤**(키셋 기반) + 가상 스크롤로 대량도 가볍게. **그리드/리스트** 토글, **날짜 그룹**.
- **카드**: 썸네일(영상은 호버 시 재생), 상태 표시(생성중/완료/실패 — 대기·실행 단계는 툴팁·정보창), 컬러 마커, 타입 배지, 작성자.

### 분류 (선택 후 단축키)
| 키 | 동작 |
|---|---|
| `r` / `g` / `b` | 컬러 마커 빨강/초록/파랑 |
| `s` | (Assets 분리창 전용) 소스로 등록(@소스명) — 생성 라이브러리에서는 비활성 |
| `#` | 태그 입력 |
| `c` / `h` | 코멘트 열기 / 히스토리 보기 |
| 카드 휠클릭 | 정보 팝업(프롬프트·소스·크레딧·소속 프로젝트 — **표시 전용**) |

### 벌크(여러 개 한꺼번에)
- 선택: 카드 클릭·**Shift/Ctrl**·**Ctrl+A**·**마퀴 드래그**·날짜 그룹 헤더 선택.
- 일괄: 삭제 / 복원 / 영구삭제 / 공유 / 프로젝트 귀속.

### 검색
- 상단 검색창에 **프롬프트·태그 부분일치**. 3자 이상은 FTS5(빠름), 미만은 LIKE 폴백.

### 필터(사이드바)
- **컬러·전역 태그·생성자·프로젝트**(사이드바)와 **공유 여부**(툴바 S). 여러 필터는 AND 로 합성.

## 4. 생성 / 재생성

- **생성**: 하단 도크에 프롬프트 입력 + 모델/비율 선택 → 생성. `Ctrl/⌘+K` 로 도크 표시/숨김(표시될 때 자동 포커스).
  - **실행은 `Alt+Enter` 만**. 그냥 `Enter`·`Shift+Enter`·`Ctrl+Enter` 는 모두 줄바꿈이다
    (오입력으로 크레딧이 나가는 것을 막는다 — `lib/spotlightPromptKeyboard.ts`).
  - `@` 입력 → 소스(레퍼런스) 피커, `#` → 태그/프롬프트 조각 피커.
- **재생성**: 카드 오버레이의 ↻ — 같은 프롬프트·레퍼런스로 다시. 원본과 `derived` 계보가 남고 같은 프로젝트로 자동 귀속.
- **동작 방식**(중요): 버튼은 **서버에 요청만** 남긴다 → 카드가 즉시 **생성중** 으로 뜨고 → 내 PC 에이전트(`--watch`)가 가져가 **내 CLI 로 실행** → 완료되면 카드가 채워진다.
  - 에이전트가 꺼져 있으면 **생성중** 인 채로 남았다가 켜는 즉시 실행. 결과·크레딧은 실행한 사람 것.
  - ⚠️ **생성은 유료**(크레딧 소모). 텍스트·URL·`asset:` 레퍼런스는 OK(에이전트가 허브 인증으로 받아 CLI 에 넘긴다). **베어 로컬 파일 경로**만 아직 못 푸는 한계.

## 5. 프로젝트 (작업 묶음)

여러 작업이 섞이지 않게 결과물을 묶는 **팀 공통 분류**(개인 컬러·태그와 별개).

| 하고 싶은 것 | 방법 |
|---|---|
| 만들기 | **보드 아이콘 → 관리창 → 대시보드**의 프로젝트 관리 패널 |
| 그 프로젝트만 보기 | 이름 클릭(다시 클릭=해제), **미분류** 항목도 있음 |
| 결과물 담기 | 카드 선택 → 하단 **📁 프로젝트에 담기** |
| 생성과 동시에 담기 | **특정 프로젝트로 필터한 상태에서 생성** → 자동 귀속 |
| 한 개만 옮기기 | 카드 선택 → **📁 담기** 메뉴(정보 팝업은 소속 표시 전용) |
| 이름변경·보관·삭제 | **관리창 → 대시보드**의 프로젝트 관리 패널 |

> 프로젝트를 삭제해도 **결과물은 안 지워지고 '미분류'로** 돌아간다. 보관(archived)은 콜드 분리.

## 6. 공유 & 리뷰 · 등급(골드)

- **공유(발행)**: 카드 오버레이의 **S** — 단일클릭=공유/해제, 더블클릭=**최종(골드)** 지정.
  - 최종(골드)은 그 프로젝트의 **supervisor**(또는 전역 `admin`)만 지정 가능 — **PM 은 제외**.
    골드는 공유 잠금.
- **공유 & 리뷰 탭**: 공유된 결과물 갤러리. 가져오면 로컬 복제 + 계보 기록.
- **번들 내보내기/가져오기**: 단일 DB 를 팀이 함께 쓰는 서버 모드에서는 불필요해 **제거**됐다.
  사용자가 호출할 수 있는 번들 내보내기·가져오기 HTTP API 는 **없다**. 번들 직렬화·병합은
  공유 발행 흐름 내부(`POST /api/share/publish-bundle`)와 repo 계층에만 남아 있다.
- **동기화**: 공유 서버의 주기 동기화는 `MV_server.bat` 에서 **기본 꺼짐**(`CONTENT_HUB_SERVER_SYNC=0`)이다
  — 서버에는 자기 CLI 로그인이 없어 매 주기 실패만 남기 때문. 명시적으로 켜면 20초 간격으로 Higgsfield 잡(다른 기기·웹 포함)을
  흡수한다. 각 PC 의 push 에이전트와는 별개 경로다.

## 7. 캔버스 탭 — 씬 캔버스 · 히스토리 보기(계보)

**캔버스 탭** 안에 두 가지 뷰가 있다: 자유 배치용 **씬 캔버스**와 계보 트리용 **히스토리 보기**
(상단 씬 바에서 전환·씬 추가).

- **씬 캔버스**: 빈 캔버스에 결과물 카드를 자유 배치하고 카드끼리 **연결선·태그**를 편집하는
  작업판. 여러 개의 씬을 만들 수 있다. 저장 원본은 **이 브라우저 로컬**(localStorage)이고,
  계정별 로컬 DB 로 **자동 미러 백업**돼 브라우저 캐시가 지워져도 복구된다.
- 캔버스에서 **ComfyUI 워크플로 카드**를 만들어 파라미터를 노출·실행할 수 있다(§14-C).
- **히스토리 보기** = 원본 → 파생을 가로 트리로 그리는 **계보 보드**(`HistoryBoard`).
  - 엣지 종류: **실선 `derived`**(재생성·가져오기, 강한 1부모) · **점선 `reference`**(@소스로 만듦, 약한 다부모).
  - 무한 캔버스(휠 줌·미들클릭 팬), 마퀴 선택·비교·정보·다운로드·재생성·드래그 이동.
  - 단축키: **`d`** 비활성화(회색), **`a`** 자동 정렬. 최종(골드) 강조.
- 한 카드의 연결된 가계는 **캔버스 탭의 히스토리 보기**(`HistoryBoard`)에서 본다.
  (별도 '가계 패널'·미니 트리는 진입로가 없어 제거됐다.)

## 8. 코멘트 & 알림

- 공유된 결과물에 **코멘트 스레드**(답글 지원). 카드의 **C** 는 항상 코멘트 버튼이고,
  **내가 확인하지 않은 코멘트가 있을 때만 강조 표시**가 붙는다.
- **C 강조가 켜지는 경우는 둘뿐**: ① **내가 만든 생성물**에 달린 코멘트, 또는 ② **내 코멘트에 달린 답글**.
  (상단 알림 벨의 알림 센터는 코멘트 외에 **프로그램 업데이트·서버 공지**도 함께 모아 보여준다.)
  - 그 외 코멘트는 패널에서 볼 수 있지만 내 C 뱃지를 켜지 않는다.
- **확인 방식**: 카드 C 클릭 → 패널에서 **NEW** 표시된 코멘트를 클릭(또는 답글)하면 그것만 확인 처리. 모두 확인하면 C 뱃지가 꺼진다(코멘트 단위 seen).
- 새 글/삭제는 실시간(WebSocket)으로 즉시 반영.

## 9. Assets 분리창 (파일 브라우저)

- 임의 폴더를 **마운트**해 파일을 브라우징하는 별도 창(`/?embed=assets`).
- 파일별 **메타(소스·태그·컬러·노트)는 계정별 개인 소유**, **코멘트 스레드는 공유**.
- 생성본 라이브러리(생성 파트)와는 별개 영역.

## 10. 계정 · 등급 · 관리자 창

좌측 상단 **⬡ 로고 클릭 → 관리자 창**.

- **멤버 · 전역 역할**: 작성자 목록에서 **역할 칩**을 눌러 켜고 끈다(드롭다운 아님).
  - 전역 역할: `admin` / `product_manager` / `production_director` / `member`
  - 프로젝트 역할: `project_manager` / `supervisor` / `creator`
    — **관리자 창에서는 전역 역할만** 준다. 프로젝트 역할은 **관리창 → 대시보드 →
    프로젝트 관리 패널의 👥** 에서 부여한다.
  - (`product_director` 는 `product_manager` 로, `editor` 는 `creator` 로 이름이 바뀌었다 — `backend/app/rbac.py`)
- (프로젝트 생성·이름변경·보관·삭제는 관리자 창이 아니라 **관리창 → 대시보드**의 프로젝트 관리 패널)
- **프로젝트 멤버 자동 편입**: 팀원의 에이전트가 워크스페이스 접근을 보고하면, 그 워크스페이스가
  지정된 **기존 활성 프로젝트에도 기본 역할로 자동 추가**된다(상주 에이전트는 10분 주기로 재보고).
  단 👥에서 **✕로 뺀 멤버는 자동 편입이 되살리지 않는다**(제외 기록) — 다시 넣으려면 +추가(수동)만.
  힉스필드 워크스페이스에서 빠진 사람도 프로젝트에서는 자동 제거되지 않는다(수동 ✕만).
- **승인**(로그인 모드일 때): 가입 대기 계정 **승인/거부**, 등급 부여.
- **공유 서버**(관리자만): 서버 이름·주소 저장 → **[팀에 공지]**(이사 안내), 업데이트 공지 등록·재공지 —
  [SERVER_RELOCATION.md](SERVER_RELOCATION.md)·[UPDATE_ANNOUNCEMENTS.md](UPDATE_ANNOUNCEMENTS.md).

### 로그인 보안 모드
- 기본 ON(`CONTENT_HUB_AUTH=1`). **첫 가입자 = 관리자**, 이후 가입자는 **승인 대기 → 관리자 승인** 후 로그인.
- 로그인 안 하면 결과물·미디어·실시간 갱신 전부 차단. 우측 상단 계정 칩으로 로그아웃.
- 비밀번호는 해시 저장, 세션은 위조 불가 서명 토큰. 끄려면 `CONTENT_HUB_AUTH=0`(데이터는 그대로).

## 13. 운영 · 백업

- 서버 PC 의 데이터는 `backend/data/`(DB·미디어·공유)에 모인다. 미디어는 `data/media/<sha[:2]>/...` 샤딩.
  단 **작업자 PC 의 로컬 허브도 자기 `backend/data/`(계정별 DB 포함)를 따로 가진다** — 서버 폴더만
  백업하면 작업자 로컬 원본은 포함되지 않는다.
- **자동 백업**: 하루 1회 + 서버 시작 시. 단 **가장 최근 백업이 `min(백업 주기, 1시간)` 보다 최근이면
  시작 백업을 생략**한다(재기동 난립 방지 — `backup.py` 의 `_STARTUP_SKIP_IF_YOUNGER`).
  기본 주기(24시간)에서는 1시간이 기준이고, `CONTENT_HUB_BACKUP_INTERVAL` 을 1시간보다 짧게 두면 그 값이
  기준이 된다. 기준과 정확히 같은 시각이면 생략하지 않고 백업한다. 최근 7개 보관. 수동은 `POST /api/backup`.
- **개인 메타데이터 연속성**: 생성물·태그·캔버스·에셋 색인은 변경 뒤 자동으로 서버에
  업로드됩니다. 자동 다운로드는 하지 않으며, 설정의 **메타데이터 동기화**에서 PC·시각·요약을
  확인하고 선택한 버전만 현재 PC에 적용합니다. 빈 새 PC와 다른 PC의 오래된 버전은 기존 최신본을
  자동으로 덮지 않습니다.
- 다른 디스크/NAS 권장: PowerShell 은 `$env:CONTENT_HUB_BACKUP_DIR = '\\NAS\backup'`,
  cmd 는 `set CONTENT_HUB_BACKUP_DIR=\\NAS\backup`.
- **변경 반영**: 백엔드 코드 변경 → **서버 재시작 필수**(`--reload` 금지). 프론트 변경 → `npm run build` + 브라우저 **Ctrl+F5**.
- **DB 초기화**: 서버 기동 시 자동으로 적용된다(`init_db()`). `python -m app.db init` 을 손으로
  실행하지 않는다 — 격리 환경변수 없이 돌리면 **실제 사용자 DB** 를 열어 마이그레이션을 적용한다.
- ⚠️ 서버 PC 에 `register_autostart.bat`(부팅 자동시작)을 등록한 뒤에는 **`MV_server.bat` 을
  수동으로 실행하지 않는다**(포트 충돌 — [SERVER_RECOVERY.md](SERVER_RECOVERY.md)).
- DB 는 SQLite 단일 지원(PostgreSQL 런타임은 제거·차단 상태 — `deploy/POSTGRES.md` 첫 줄 참조).

## 14. 최근 추가 기능 (2026-06 이후)

### 14-A. 프로그램 업데이트 버튼 (작업자 PC)
**설정 → 프로그램 업데이트**. 릴리스 서버에 새 버전이 있으면 버튼이 활성화되고, 누르면
진행 중 생성·Comfy 작업·Resolve 전송이 없는지 확인한 뒤 안전하게 종료 → 검증된 릴리스 설치 → 자동
재시작까지 한 번에 된다. 작업 파일·로컬 DB 는 건드리지 않는다. 유료 작업이나 Resolve 전송이 돌고 있으면
"생성 N건 · Resolve 전송 N건 완료 후 업데이트"로 잠긴다. 수동 경로는 `update_release.bat`.

### 14-B. DaVinci Resolve 연동
- **설정의 DaVinci Resolve 섹션**: 연동 스크립트 설치/상태 확인, Resolve 연결 상태.
- **"◆ Resolve로 보내기"**(라이브러리·캔버스·생성 결과 팝업 선택바): 선택한 결과물의
  원본을 프로젝트 렌더 폴더로 저장하고 Resolve Media Pool 의 `MV Hub` 빈으로 가져온다.
- Resolve 무료판처럼 외부 스크립팅이 막힌 환경은 Resolve 안 **Workspace → Scripts → MVHub_Importer**
  로 수동 가져오기(같은 결과, 멱등 — 이미 가져온 파일은 중복되지 않음).
- **연결 Python 자동 선택**: Resolve 연결 부품(fusionscript)은 Resolve 버전에 따라 호환되는
  Python이 다르다(실측: Resolve 20.3=3.14 호환, Resolve 21=3.14 크래시·3.11 필요). MV Hub는
  내장 런타임으로 먼저 연결하고, 실패하면 PC에 설치된 64비트 Python(3.9 이상)으로 자동
  재시도해 성공한 것을 기억한다. 연결·가져오기 모두 별도 프로세스에서 실행되어 비호환
  크래시(0xC0000005)가 나도 앱 서버는 죽지 않는다. 진단의 "실제 연결"이 계속 실패하면
  64비트 Python을 '모든 사용자'용으로 설치하면 된다.
- **Python 자동 설치(반자동)**: 호환 Python이 없어 연결이 실패하면 진단 패널에
  "◆ Python 자동 설치" 버튼이 나타난다. 누르면 공식 python.org 설치 파일(3.11.9 x64,
  SHA256 고정 검증)을 받아 질문 없는 모드(/passive, 모든 사용자)로 실행 — 사용자는
  관리자 권한(UAC) 승인만 하면 되고, 설치 후 진단을 다시 누르면 자동으로 연결에 쓰인다.

### 14-C. ComfyUI 연동 (캔버스)
- **설정의 ComfyUI 연결**: 로컬 ComfyUI 또는 Comfy Cloud 주소·API 키 설정.
- 캔버스에서 **comfy 카드**를 만들어 워크플로 JSON 을 불러오면 파라미터가 노출되고,
  연결된 미디어(이미지·영상)가 슬롯에 자동 주입돼 실행된다. 결과는 **작업 공간** 탭 라이브러리로
  저장 가능. 동시 실행 수는 설정의 comfy_concurrency 로 제한(배치 안전).

### 14-D. PM 관리 대시보드 (분리창)
상단바 **보드 아이콘** → 관리창. 작업/완료 탭은 전원. **대시보드 탭도 전원에게 열리며**, 워크스페이스 전체 통계는 권한자만,
일반 멤버는 자기가 참여한 프로젝트 범위만 본다.
- **작업**: 선택한 워크스페이스의 공유 서버 생성 기록으로 만든 프로젝트×폴더별
  칸반·테이블·캘린더, 일정. 사용자 PC의 실제 폴더 목록을 직접 읽는 화면은 아니다.
  (수동 담당자 배정은 2026-08-21 폐기 — 생성자는 실제 만든 컷에서 자동 파생.)
  오래된 자동 작업은 삭제하지 않고 프로젝트 설정의 기간(기본 30일) 뒤 **과거 기록**으로
  분리하며, 상단 토글로 다시 볼 수 있다.
- **완료본 저장**: 최종(골드) 결과물의 원본 바이트를 이 PC 의 지정 렌더 폴더로 저장(원자·멱등).
- **대시보드**: 작업자×프로젝트별 크레딧·시간·건수 집계(팀 텔레메트리 — 자동 메타 push),
  워크스페이스 사용량, 월간 캘린더, 내보내기.
- 프로젝트 설정에서 **예산 한도**를 지정하면 크레딧 게이지 분모(§11)에 쓰인다.
- 프로젝트 설정의 **과거 기록 전환** 값은 생성에서 자동으로 생긴 작업의 보관 시점만 조절한다.
  수동 작업, 메모, 일정은 자동 삭제하지 않는다.

### 14-E. 워크스페이스
- 생성 시 현재 선택된 Higgsfield 워크스페이스가 결과물에 스탬프되고, 팀 워크스페이스
  프로젝트에는 같은 워크스페이스에서만 생성할 수 있다(잘못된 크레딧 과금 방지 게이트).
- 등록부에 유령 행(힉스필드에서 지웠다 재생성한 옛 id)이 생기면
  `.\run_py.bat tools\cleanup_workspace_registry.py` 로 정리([WORKSPACE_DATA_CONTRACT.md](WORKSPACE_DATA_CONTRACT.md)).

## 15. 자주 묻는 것

**Q. 팀원이 설치해야 하나요?**
브라우저 접속만으로 탐색·정리·공유 OK. 단 **본인 결과를 올리거나 허브에서 생성을 돌리려면** 본인 PC 에 릴리스 설치본을 깔고 `MV_agent.bat` 을 켜야 한다.

**Q. 생성은 누구 계정으로 되나요?**
각자 본인 PC 의 Higgsfield CLI 계정으로. 서버는 토큰을 갖지 않고 결과만 모은다.

**Q. 허브엔 oz1 으로 로그인했는데 동기화는 jay 로 잡혀요.**
허브 로그인과 그 PC 의 CLI 계정은 별개다(§0). 그래서 각자 본인 PC 에서 본인 CLI + 에이전트로 push 하는 모델이다.

**Q. 화면/갱신이 안 떠요.**
서버가 켜져 있는지, 방화벽에서 포트 **8010** 이 열렸는지 확인. 같은 PC 는 `127.0.0.1:8010` 권장.

**Q. 실서버로 옮기려면?**
이 폴더째 복사 → `.\MV_server.bat`(또는 동등 명령). 상대경로 기반이라 무변경 작동. 상세는 [SERVER.md](SERVER.md).
