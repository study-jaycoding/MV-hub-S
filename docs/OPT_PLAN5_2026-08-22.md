## transaction-root 계약(신규 BEGIN IMMEDIATE 함수 공통)

1-C·1-H·1-I·1-J·2-A·2-F·2-H(+2-0) 공개 함수는 트랜잭션 최상위 전용 — 내부에서 다른
get_connection() 함수 호출 금지, 조합 필요 시 caller-supplied conn private helper.
중첩 진입은 sqlite "cannot start a transaction within a transaction" 으로 fail-fast.
★풀 ON(운영 기본) 회귀 테스트 필수 — conftest 전역은 풀 OFF 라 중첩이 가려진다.
현재 호출 그래프는 코덱스가 7경로 전부 최상위 확인 완료.
