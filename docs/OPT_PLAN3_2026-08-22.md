  (15s 리로드·10s 스로틀 폴링, WS 무관)이 담당함을 코드로 증명 후 구현. 상세는 열림
  동안만, 릴리스 60초 확인 유지.

## 웨이브 1 — 저위험 소형 (각 독립 커밋)

1-A. **C-4 known set 제자리 갱신** — 새 thumb 원본마다 전체 set 복사(O(N²)) → add().
1-B. **A-2 due 이중 조회 제거** — 주기 루프는 run_now() 판정에 위임.
1-C. **A-3 요약 테이블 존재 1회 조회** — sqlite_master 8회→1회.
1-D. **C-1 완성 파일 판정 stat 1회화** — is_file+stat → stat 1회(regular 판정 포함,
  symlink 추종 의미 유지).
1-E. **B-3 mutation 도메인 공통 게이트 1회 평가** — helper 공개 계약 불변.
1-F. **C-5 다운로드 완료 stat 재사용** — 완료 판정의 size 를 쿼터에 전달.

## 웨이브 2 — 중위험 (전용 테스트 선행)

2-A. **A-1 상태 DB 스키마 1회 보장** — (프로세스, STATE_DB 경로)별 1회. synchronous=FULL
  등 커넥션별 설정은 유지. 경로 교체·동시 최초 진입·자식 --drain-one 검증.
2-B. **A-5 비정상 자식 복구 1회화** + **A-6 taskkill 회수** — 복구 정확히 1회 행렬,
  kill 후 bounded wait.
2-C. **C-3 eviction 재-stat 축소(최소형)** — 2차 스캔의 size 그대로 합산(단일 snapshot
  단정은 하지 않음 — 외부 생성 계약 보존).
2-D. **B-1 계정별 구독자 보조 인덱스** — broadcast_all 만 전체 순회. 수거 경로 인덱스
  불변식 테스트(decoy·다탭·AUTH-off None·재등록·timeout/overflow).
