## 웨이브 1 — 저위험 소형 (각 독립 커밋)

1-A. **C-4 known set 제자리 갱신** — 새 thumb 원본마다 전체 set 복사(O(N²)) → add().
1-B. **A-2 due 이중 조회 제거** — 주기 루프는 run_now() 판정에 위임.
1-C. **A-3 요약 테이블 존재 1회 조회** — sqlite_master 8회→1회.
1-D. **C-1 완성 파일 판정 stat 1회화** — is_file+stat → stat 1회(regular 판정 포함,
  symlink 추종 의미 유지).
1-E. **B-3 mutation 도메인 공통 게이트 1회 평가** — helper 공개 계약 불변.
1-F. **C-5 다운로드 완료 stat 재사용** — 완료 판정의 size 를 쿼터에 전달.

## 웨이브 2 — 중위험 (전용 테스트 선행)

2-A. ✅**A-1 상태 DB 스키마 1회 보장**(91a15573) — _STATE_SCHEMA_READY set+lock, 존재
  프로브(not exists())로 삭제-재생성 커버. synchronous=FULL 은 매 연결 유지. 경로 교체
  재보장 테스트 포함.
2-B. ✅**A-5 비정상 자식 복구 1회화** + **A-6 taskkill 회수**(10de9bea) — recovered
  플래그로 복구 스레드 정확히 1개(FailedChild 5조합 parametrize + 스레드 수 단정),
  killer.kill() 후 wait_for(wait(), 5) 회수(OSError/Timeout suppress).
2-C. ✅**C-3 eviction 재-stat 축소(최소형)**(91a15573) — 생존자 목록의 size 그대로 합산
  (파일당 3번째 stat 제거). 단일 snapshot 단정은 하지 않음 — 외부 생성 계약 보존.
2-D. ✅**B-1 계정별 구독자 보조 인덱스**(3ffd83ed) — _by_account + track/untrack 단일
  경로(재등록 시 옛 버킷 정리·빈 버킷 즉시 제거), broadcast_all 만 전체 순회. 스코프
  일치 필터는 최후 방어선으로 유지(어긋나면 ERROR 로그 후 skip — 누출 불가).
  불변식 테스트 5종(decoy·다탭·AUTH-off None·재등록·timeout/overflow 수거).
